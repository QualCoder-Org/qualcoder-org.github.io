# Attributs

Les attributs sont des variables associées aux fichiers, aux cas ou aux journaux. Ils peuvent s'avérer utiles pour apporter du contexte lors de l'interprétation de votre analyse. Ouvrez la boîte de dialogue « Gérer les attributs ». Vous pouvez ajouter, supprimer ou renommer des attributs, ainsi que leur associer des mémos. Vous pouvez convertir un attribut numérique en attribut de type « Caractère » par un clic droit, mais l'inverse n'est pas possible.

Les seules options disponibles pour les attributs sont « Numérique » et « Chaîne de caractères ». Il n'y a pas d'options pour les types booléens, de date ou d'heure, ni pour des types numériques spécifiques tels que les entiers.  Toutefois, si vous exécutez des requêtes SQL, vous devrez peut-être convertir l'attribut numérique en entier ou en nombre réel, ex. `cast(my_var as integer)`.

Les attributs peuvent être ajoutés dans le gestionnaire d’attributs, de fichiers cas ou journaux, en cliquant sur le bouton (x), présent ci-dessous. Les attributs peuvent être importé depuis un fichier d’enquête, mais également un projet REFI-QDA. À noter que l’import de projet REFI QDA n’est pas garanti.

QualCoder n’est pas conçu pour effectuer des analyses statistiques des attributs. Il est préférable d’utiliser un logiciel statistique tel que [R](https://www.r-project.org).

Les attributs peuvent également être ajoutés ou supprimés à l'aide de l'option Gestion > Gestion des attributs :

![image](/images/513af5f1-a94e-4606-b4d0-54011a8607da.png)

Dans cette section, vous pouvez supprimer des attributs. Cependant, même si vous pouvez supprimer des attributs de référence, nous vous recommandons de ne pas le faire, sauf si vous êtes certain que toutes vos références ne sont plus nécessaires. Ces attributs sont préfixés par « Ref_ » et sont associés à des références importées, qui sont liées à une référence spécifique. Voir le Gestionnaire de références pour importer et lier des références aux fichiers.
