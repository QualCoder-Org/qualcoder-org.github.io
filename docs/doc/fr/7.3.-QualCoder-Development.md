# Autres informations et licences

QualCoder est actuellement développé sur Windows 11.  QualCoder est écrit en Python 3 et utilise QT6 pour l’interface graphique.

Après la version 4.0, l’un des axes de développement consistera à revoir l’aspect visuel et l’interface utilisateur de QualCoder. L’objectif est de rendre l’interface plus moderne et plus attrayante.

## Structures de données

**Le dossier de projet qda** Contient des dossiers pour les documents importés, les images et l’audio et la vidéo. Il contient également la base de données sqlite, nommée data.qda, pour stocker les données de codage. Lorsque l’IA est activée, il existe un dossier ai_data contenant une base de données sqlite d’historique de conversation et un vectorstore. Un vector store est une représentation numérique de mots, de phrases et d’expressions utilisée par le modèle de langage IA. Le vectorstore utilise faiss, qui sert aux recherches de similarité par l’IA.

**Le dossier de travail .qualcoder** QualCoder crée les fichiers QualCoder.log et QualCoder_settings.txt à l’intérieur d’un dossier .qualcoder dans votre répertoire personnel. Le fichier de paramètres contient le nom du codeur actuel, un répertoire de travail par défaut, la police, les langues et d’autres options. Le fichier journal enregistre les erreurs du programme et certaines actions de l’utilisateur. Il peut y avoir plusieurs fichiers journaux successifs (à rotation). Vous ne devez placer aucun fichier dans ce dossier, car il est utilisé comme zone de stockage des paramètres de travail du programme QualCoder.

## Operating systems used

QualCoder a été utilisé sur Windows 11, macOS, Ubuntu 24, Lubuntu, Fedora, Linux Mint, Arch Linux, Fedora et ZorinOS. L’utilisation de l’audio/vidéo avec QualCoder sur Fedora fait planter QualCoder. Debian avec Gnome et l’option de fenêtres en mosaïque — réduit la taille de la fenêtre QualCoder. La meilleure option consiste à désactiver le placement des fenêtres en mosaïque dans les paramètres de Gnome.
