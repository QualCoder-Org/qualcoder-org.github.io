# Codage du texte

Sélectionnez Coder le texte dans le menu Codage. Une fois les segments de texte codés, passez la souris sur le codage pour afficher le nom du code sous forme d'info-bulle. Cliquez sur le segment codé pour afficher également le nom du code. 

![image](/images/6f26284e-0802-4bd8-a75d-6b0e6562901c.png)

Le texte codé peut être mis en évidence à l'aide d'un soulignement ou d'un style de surlignage :

![image](/images/50bb8b05-73e9-41d8-9844-1ada6378d8a7.png)

![image](/images/750bb5f3-5c81-493a-a4ee-85a94874070b.png)


_Sélectionner un fichier_

Sélectionnez un fichier à coder dans la liste de sélection à gauche. La liste de sélection des fichiers contient des boutons qui vous permettent de passer au fichier suivant, d'accéder au fichier le plus récemment codé et d'aller à une position marquée dans un fichier. Il existe également un bouton permettant d'afficher la note du fichier.

_Créer un code_


Cliquez-droit sur un code pour afficher un menu proposant plusieurs options : ajouter une note à un code, supprimer un code, renommer, ajouter un nouveau code, ajouter une nouvelle catégorie, afficher les codes sous un autre nom, déplacer un code ou une catégorie, ajouter une catégorie, trier.


_Coder un texte_

La manière la plus simple de coder du texte consiste à sélectionner une partie du texte, puis à cliquer avec le bouton gauche de la souris sur un code dans l'arborescence des codes. Vous pouvez également sélectionner une partie du texte, cliquer avec le bouton droit de la souris pour ouvrir un menu et marquer le texte à l'aide d'options telles que le code actuel, les codes récents, un nouveau code ou le codage in vivo.

Passez le pointeur de la souris sur le texte codé pour afficher les informations relatives au code et à tout mémo. Le texte codé peut être décodé en cliquant sur le segment de texte et en appuyant sur le bouton « Démarquer ».

Les segments de texte codés peuvent être mémorisés via le menu contextuel, en appuyant sur la touche « M » ou en cliquant sur le bouton « bloc-notes et crayon » situé à l'extrême droite. Le texte codé et mémorisé est affiché en italique.

Les textes codés importants, tels que les exemples pour un rapport, peuvent être marqués comme importants à l'aide du menu contextuel lorsque vous vous trouvez sur le texte codé et en sélectionnant l'option Important. Le bouton étoile situé sous l'arborescence des codes permet d'afficher soit tous les textes codés, soit uniquement les textes codés marqués comme importants.

_Codes se chevauchant_

Les codes qui se chevauchent peuvent être difficiles à voir clairement. Les sections qui se chevauchent sont soulignées. En passant la souris dessus, vous verrez apparaître le texte codé, y compris les chevauchements. Vous pouvez appuyer sur « O » après avoir cliqué sur une section qui se chevauche pour faire défiler les codes à cet endroit.

## Annotations

Ajoutez une annotation (une note pour un segment de texte) à une sélection de texte. Elles sont utiles pour expliquer les acronymes et le jargon, par exemple. Le texte sera mis en gras pour marquer la position de l'annotation. Pour rouvrir une annotation, sélectionnez une partie du texte en gras et Cliquez-droit de la souris pour obtenir l'option Annoter. Vous pouvez également cliquer sur l'icône du bloc-notes et du crayon à gauche, ou appuyer sur la touche « a ».

![img](/images/104526a8-1bba-4dae-8bcd-43d2ddc5f9c8.png)

## Auto-codage

En haut à droite de la boîte de dialogue se trouvent des boutons permettant d'auto-coder le texte : 


![boutons de codage automatique](/images/d689c833-505f-49e4-938c-e392d4a2cc14.png)


Vous pouvez :

* auto-coder le texte exact. Une fenêtre supplémentaire vous demandera quels fichiers vous souhaitez auto-coder. Voir la notice concernant QualCoder 3.8.
* auto-coder des phrases à partir d'un fragment de texte. Une fenêtre supplémentaire vous demandera quels fichiers vous souhaitez auto-coder.
* auto-coder le fichier actuel à l'aide de marques de début et de fin de texte. Vous pouvez utiliser « \n » comme caractère de fin de ligne. Le texte de la marque de début est inclus dans la section codée.
* Annuler le codage automatique précédent
* Une case à cocher pour activer Regex. Il s'agit d'une fonction spéciale permettant d'appliquer un codage automatique plus flexible basé sur des caractères génériques et d'autres fonctions. Voir [ce mémo](https://techearl.com/regex-cheat-sheet).

Le codage automatique est sensible à la casse. Vous devez également définir la fin d'une phrase. Le paramètre par défaut est un point suivi d'un espace. Vous pouvez également utiliser \n pour indiquer un caractère de fin de ligne.

Pour le codage automatique de correspondances textuelles exactes, plusieurs sections de texte peuvent être attribuées à un code automatique à l'aide du symbole « | ». Par exemple, politics|politicians peut être attribué au même code en même temps (uniquement pour les correspondances textuelles exactes du codage automatique). Il existe une option « Annuler » pour annuler le codage automatique récemment effectué. Cependant, si le projet est fermé puis rouvert, l'option « Annuler » sera perdue.

Les boutons « Code automatique du texte exact » et « Code automatique du fragment de texte » disposent d'un menu contextuel pour plus d'options. Par défaut, tout le texte est codé automatiquement. Il existe des options permettant de ne coder automatiquement que le premier texte correspondant ou le dernier texte correspondant dans le document. Une autre option consiste à n'appliquer le code automatique que s'il apparaît dans un autre code (par exemple dans un texte codé spécifique d'un⋅e intervenant⋅e). Les boutons « Code automatique du texte exact » et « Code automatique du fragment de texte » vous demandent quels fichiers vous souhaitez coder automatiquement.

Un bouton « Annuler » permet de supprimer les derniers codages automatiques appliqués.

**Emojis, émoticones dans le texte et l'autocodage**

Les caractères emoji bruts peuvent compter pour un seul caractère dans une chaîne, mais occupent deux positions ou plus dans l'éditeur visuel, ce qui entraîne des calculs erronés. L'application de la conversion automatique *pourrait* entraîner un décalage des positions des caractères lors de l'application de cette conversion au texte.

 Exemple de codage automatique du mot « music » : chaque emoji est affiché comme un seul caractère, mais en réalité, il s'agit de deux caractères. Il en résulte un décalage, comme illustré ci-dessous :
 
![image](/images/8ac5bcf5-fae4-4da3-a1dd-8dccf12d585b.png)


## Auto-codage des intervenant⋅es

La fonction « Marquer les intervenant⋅es » crée des codes pour chaque intervenant⋅e dans un entretien ou une discussion de groupe, et attribue automatiquement les interventions. Cela permet d'obtenir des rapports plus ciblés, en ne considérant que certains intervenant⋅es à la fois. Vous pouvez accéder à cette fonction via le menu contextuel du fichier ou le bouton suivant de la barre d'outils : 

![grafik](/images/645f0a43-4814-466e-a8a0-10758b910bb0.png)

- Le nom de l'intervenant⋅e doit figurer au début d'une nouvelle ligne et comporter moins de 64 caractères. Les formats suivants sont détectés : « Nom : », « {Nom} » ou « [Nom] ».
- Vous pouvez sélectionner les noms que vous souhaitez inclure et même modifier l'étiquette :

![speaker selection dialog](/images/67c14d0f-2c9a-4e99-8907-9c16a32b6285.png)

- Chaque intervenant⋅e recevra son propre code dans la catégorie spéciale « 📌 Intervenant⋅es » tout en bas de l'arborescence du code. Les couleurs par défaut sont issues de la gamme des gris, afin de les rendre moins distrayantes.
- Cependant, vous pouvez toujours choisir de masquer ces codages dans la fenêtre de texte, afin qu'ils ne vous distraient pas dans votre propre codage analytique. Pour ce faire, cliquez sur le bouton « ... » situé juste à côté du nom du codeur en haut à gauche de la barre d'outils. Dans la boîte de dialogue suivante, sélectionnez l'entrée « 📌 Codage des intervenant⋅es » et réglez la visibilité sur « masqué ».

## Maximiser la zone d'écran
Pour masquer le panneau de contrôle supérieur, cliquez dans la zone de texte et appuyez sur la touche « h ». Pour afficher le panneau supérieur, appuyez à nouveau sur « h ».

## Méthodes pratiques pour charger des fichiers texte dans le volet de la liste des fichiers.

Certains projets peuvent comporter de nombreux fichiers texte et la boîte de dialogue d'affichage des fichiers peut présenter trop de fichiers à ouvrir. Cliquez-droit de la souris sur les fichiers dans l'arborescence des fichiers pour passer au fichier suivant, aller au fichier marqué d'un signet ou aller au fichier avec les derniers codages : 

* Le fichier suivant par ordre alphabétique, 

* Sélectionner le fichier qui a été codé le plus récemment, 
* Aller à un emplacement marqué d'un signet dans un fichier. Pour créer un signet, Cliquez-droit de la souris sur un texte lors du codage et sélectionnez l'option « Signet ». Le signet ne fonctionne que pour un seul projet à la fois. Si vous ouvrez un autre projet, le signet sera incorrect ou ne fonctionnera pas du tout.

### Boutons pratiques sous la liste des fichiers

* Charger le fichier suivant
* Charger le fichier contenant le dernier codage
* Accéder au fichier actuellement marqué d'un signet
* Ouvrir le mémo du fichier sélectionné
* Utiliser une fonction de filtrage pour afficher uniquement les fichiers qui répondent à certains critères. Ceux-ci peuvent provenir des attributs du fichier ou du fait que les fichiers sont associés à certains cas. (Image ci-dessous)

## Modification des positions du code

Cliquez-droit sur un code et sélectionnez « Redimensionner ». Les poignées situées à chaque extrémité du segment codé peuvent être repositionnées.

![image](/images/8b9e09f0-03e0-4ad1-8042-f7aa5ce12b31.png)

Vous pouvez également cliquer sur un code avec la souris (attention, le code ne doit pas chevaucher un autre code à cet endroit). Appuyez sur les combinaisons de touches suivantes pour agrandir ou réduire le segment de texte codé.


* Maj + flèche gauche            Étend le texte codé vers la gauche
* Maj + flèche droite          Étend le texte codé vers la droite
* Alt + flèche gauche               Réduit le texte codé de droite à gauche
* Alt + flèche droite            Réduit le texte codé de gauche à droite

Il est toujours préférable d'enregistrer une copie du projet avant de modifier le texte, afin d'éviter d'avoir à modifier les positions de codage, au cas où celles-ci seraient décalées de manière incorrecte après la modification du texte. Les combinaisons de touches ci-dessous peuvent aider à rétablir les positions correctes. (QC version 3.4 et supérieure)

* Symbole dièse  \#     Affiche la position du caractère sur lequel on a cliqué.
* Symbole dollar $   Décale les positions du code à partir de la position du caractère sur lequel on a cliqué. Cela peut s'avérer nécessaire après modification du texte (ajout ou suppression) pour décaler les segments de code suivants d'un certain nombre de caractères.


## Autres raccourcis clavier pour le codage de texte

* A. Annoter le texte sélectionné

* B. Ajouter un signet à l'emplacement actuel dans le fichier texte en cours. Appuyez sur Maj + B pour accéder au signet.

* C. Dans la zone de texte. Créer une catégorie.

* Ctrl + E pour entrer et sortir du mode Édition.

* H. Masquer et afficher la partie supérieure des commandes à l'écran. Cela permet de disposer d'une zone plus grande pour visualiser le texte et coder.

* I. Sur une section codée pour marquer ce code comme important. Utile pour identifier des exemples types. Les marques d’importance peuvent être supprimées avec un clic-droit et en sélectionnant « Supprimer la marque importante ». Les codes marqués comme importants apparaissent en gras.

* L. « Afficher les codes similaires », pour afficher une liste restreinte dans l’arborescence des codes.

* M. Ajouter une note à un code. (Il faut cliquer sur un segment de texte codé)

* N. Dans la zone de texte. Créer un nouveau code.

* O. Parcourir les codes qui se chevauchent in situ. (Il faut cliquer sur un segment de texte comportant des codes qui se chevauchent – indiqué par une ligne au-dessus du texte).

* Q. Code rapide avec le code le plus récent. (Une sélection de texte est requise)

* R. Sélectionner les codes récents. (Une sélection de texte est requise)

* Ctrl + R. Inverser le sens du texte. Cela peut être nécessaire pour l’arabe ou d’autres langues s’écrivant de droite à gauche.

* S. Rechercher du texte.

* R. Ouvre la liste des codes récemment utilisés pour le codage du texte.

* U. Supprimer le marquage d’un ou plusieurs codes à l’emplacement du texte sur lequel on a cliqué. (QC version 3.4)

* V. Coder le texte sélectionné avec un nouveau code créé à partir du texte sélectionné. Également appelé codage *in vivo*.

* Ctrl Z. Rétablit le dernier codage dont le marquage a été supprimé.

## Recherche de texte

La boîte de dialogue de codage de texte contient une fonction de recherche de texte en haut au milieu, avec des cases à cocher pour la recherche sensible à la casse et pour la recherche dans tous les fichiers texte. Dans la zone de texte, sélectionnez du texte et appuyez sur la touche de raccourci « s » pour remplir la zone de recherche et mettre en surbrillance le bouton fléché « suivant » afin de rechercher rapidement le texte sélectionné dans le document. La recherche nécessite au minimum 3 caractères par défaut. Cliquez-droit de la souris pour modifier la valeur par défaut et la passer à 5 caractères ou pour effectuer la recherche uniquement après avoir appuyé sur la touche Entrée. La case à cocher « Sensible à la casse » limitera la recherche à la casse. La case à cocher « Tous les fichiers » poursuivra la recherche dans les autres fichiers texte.

La recherche utilise les fonctions Regex. 

* Un point « . » est utilisé comme caractère générique, par exemple « .ears » correspondra à « bears » et « years ». 
* Un « ? » après un caractère correspondra à une ou aucune occurrence de ce caractère, par exemple « bears? » correspondra à « bear » et « bears ».
* Un « * » après un caractère correspondra à zéro ou plusieurs occurrences.
* « \. » correspondra au symbole du point, « \? » correspondra au point d'interrogation. « \n » correspondra au symbole de fin de ligne. Ce [mémo Regex](www.rexegg.com/regex-quickstart.html) peut vous aider.
* \b limite de mot, « \bbound\b » recherchera le mot complet « bound », mais pas « boundary ».

## Parcourir le texte pour un code sélectionné

Sous l'arborescence des codes se trouvent les boutons : avant, arrière et un bouton en forme de grille (pour quitter la fonction).

Sélectionnez un code, puis cliquez sur les flèches avant et arrière. Celles-ci permettent désormais de parcourir le document texte en affichant le texte codé sélectionné. Tous les autres codages sont masqués. Pour restaurer et afficher tous les codes, cliquez sur le bouton en forme de grille désormais coloré.

## Afficher uniquement le texte codé important

Sous l'arborescence des codes se trouve un bouton avec un symbole en forme d'étoile. Ce bouton permet de basculer entre l'affichage de tout le texte codé et l'affichage du texte codé marqué comme important.


## Exporter des rapports

Exportation au format ODT, compatible avec LibreOffice et Microsoft Office. Soit avec la mise en évidence des codes, soit avec des commentaires en marge. Le rapport au format ODT contient des informations détaillées sur les codes utilisés, leur fréquence d'apparition, les annotations, les notes et le texte codé. D'autres options sont disponibles, notamment l'exportation au format texte brut, HTML et sous forme de grilles de codages.


## Volet latéral droit

Le côté droit du volet de texte codé comporte un autre volet caché. Pour l'ouvrir, cliquez et faites glisser à partir du côté droit de la fenêtre, ou appuyez sur le bouton situé à côté du bouton Aide. Ce volet contient des options utiles pour le codage. L'un des boutons permet, lorsque vous cliquez sur un code, d'afficher le nom du code, la règle du code (mémo) et des exemples aléatoires de texte codé provenant du projet. L'autre bouton affiche le mémo du projet.

# Modification du texte en mode « Codage » - Texte de code

Le texte peut être modifié même après avoir été codé, annoté ou attribué (en totalité ou en partie) à un cas. Certaines sections du fichier texte ou du fichier audio/vidéo transcrit seront soulignées en vert (cas attribué), en jaune (annotation) ou en rouge (codé) par TOUS les codeur⋅euses. 

!!! note
    BONNE PRATIQUE : enregistrez une copie du projet avant de modifier un fichier texte déjà codé. Cela permet d'éviter que les positions des codes ne soient repositionnées de manière incorrecte.

Lorsque vous passez en mode édition, l'intégralité du fichier est chargée pour être modifiée. Les autres fonctions, telles que l'arborescence des codes et la liste des fichiers, sont désactivées.

Vous pouvez sélectionner du texte qui n'est pas souligné et le copier/remplacer sans problème. Vous pouvez cliquer sur une position (sans sélectionner de texte) pour ensuite taper, supprimer ou coller du texte. Cela peut se produire dans des emplacements de texte soulignés (codés, annotés, assignés à un cas) ou non soulignés (non codés/annotés/assignés à un cas). Vous verrez les soulignements se déplacer à mesure que du texte est ajouté ou supprimé.

Il existe certaines restrictions : il est préférable d'éviter de sélectionner des passages de texte à supprimer (ou sur lesquels on souhaite taper ou coller du texte). Cela pose particulièrement problème si l'un de ces passages a été souligné (codé, annoté ou associé à un dossier). Cela peut également s'expliquer par le fait que les positions des codes, annotations ou associations de cas sous-jacents risquent de ne pas correspondre correctement comme prévu.

Si vous avez effectué une modification qui, selon vous, a eu un impact négatif sur ces positions codées/annotées/attribuées à un cas, quittez la fenêtre d'édition de texte. Ensuite, **avant toute autre action**, appuyez sur le bouton Annuler (flèche de retour) situé à côté du bouton Modifier le texte.

![image](/images/d9496b21-a494-433f-84a5-cbac8419449f.png)

!!! note
    Remarque importante : les modifications sont effectuées dans le texte stocké dans la base de données. Le fichier texte d'origine n'est PAS modifié.
