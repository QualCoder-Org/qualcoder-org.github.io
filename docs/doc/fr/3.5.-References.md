# Références

Accédez à « Gestion > Références » pour importer une bibliographie. Celle-ci doit être au format texte brut RIS ou NBIB. Le fichier peut avoir les extensions .txt (for.ris), .ris ou .nbib

![image](https://github.com/user-attachments/assets/caff300e-f3e6-47c1-a8a1-ff4ff74281b2)

Cliquez sur le bouton « Importer », puis sélectionnez un fichier bibliographique (.txt, .nbib, .ris).

Le journal des actions indiquera le nombre de références importées.

Vous pouvez désormais associer (ou dissocier) des références à des fichiers. Vous pouvez modifier manuellement une référence importée. Vous pouvez supprimer une référence.
Dans la fenêtre « Gestion les fichiers », quatre nouvelles colonnes d'attributs apparaîtront : Ref_Authors, Ref_Title, Ref_Type, Ref_Year

![image](https://github.com/user-attachments/assets/3d85d09f-926c-46df-87cb-867ad8dce4c1)

Les fichiers associés à des références afficheront des informations détaillées dans ces colonnes.

Les références peuvent être affichées dans les analyses, par exemple dans Analyse - Recherche de codes.
