# Références

Allez dans Gérer > Références pour importer une bibliographie. Le fichier doit être au format texte brut (RIS ou NBIB). Il peut porter l’extension .txt, .ris (format RIS) ou .nbib. Vous pouvez également importer des références depuis Zotero ; pour cela, assurez-vous d’abord que Zotero est ouvert et en cours d’exécution, et activez l’API locale dans les paramètres de Zotero afin de permettre à QualCoder de communiquer avec le logiciel.

![image](/images/caff300e-f3e6-47c1-a8a1-ff4ff74281b2.png)


Cliquez sur le bouton d’importation et sélectionnez un fichier bibliographique (.txt, .nbib ou .ris).

Cet exemple provient d’un fichier texte contenant une référence au format RIS. Vous avez le choix d’importer toutes les références, uniquement les nouvelles ou des références spécifiques. Si des pièces jointes sont présentes (comme lors d’une importation depuis Zotero), elles peuvent également être importées.

![img](/images/650842457-6a209439-d45c-4e13-8138-5c4dae03e8bd.png)


Vous pouvez désormais associer des références à des fichiers (ou dissocier les deux). Il est possible de modifier manuellement une référence importée ou de la supprimer.

Dans l’écran de gestion des fichiers, quatre nouvelles colonnes d’attributs apparaîtront : Ref_Authors (Auteurs), Ref_Title (Titre), Ref_Type (Type) et Ref_Year (Année).


![image](/images/3d85d09f-926c-46df-87cb-867ad8dce4c1.png)


Les fichiers associés à des références afficheront des informations dans ces colonnes.

Les références peuvent être affichées lors de l’analyse, par exemple dans la fonction « Analyse - Recherche de codes ».
