# Importation d’enquêtes

Ouvrez la page **Gérer** > **Fichiers** et cliquez sur le bouton « Importer une enquête ».

![image](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

Un questionnaire peut être importé à partir d’un fichier CSV (valeurs séparées par des virgules) ou d’un fichier Microsoft Excel (xlsx). **La première ligne doit contenir les en-têtes des attributs et des données de texte libre. La première colonne doit contenir l’identifiant unique de chaque participant à l’enquête.**

Vous trouverez quelques exemples de questionnaires dans le dossier « Examples ». Ces éléments seront utilisés dans un guide pas à pas sur l’importation d’enquêtes :

## Importer survey456

Cliquez sur le bouton « Importer l’enquête » et sélectionnez le fichier dans le dossier « Exemples ».

![image](/images/gh-c777dc45-5aec-4c2e-a705-8ef8abc7418a.png)

L’assistant d’enquête lit le fichier CSV et affiche les noms des colonnes à gauche.

![image](/images/gh-a17388a6-db2f-423b-8b6d-69f8c59d172a.png)

L’identifiant du participant, appelé « Case » dans cette enquête, peut être affecté à la section Cas/Participants. Les colonnes de données Âge, Genre et Centres d’intérêt peuvent être affectées aux attributs. La colonne champ libre peut être affectée à textes qualitatifs. Dans cet exemple, nous affecterons les attributs aux fichiers et nous ne procéderons pas au codage automatique du texte qualitatif portant le nom de colonne  champ libre. QualCoder déterminera si les colonnes d’attributs sont de type numérique ou texte. Pour les colonnes numériques, chaque cellule doit contenir un nombre, car même les entrées vides seront considérées par défaut comme des caractères.

![image](/images/gh-44838a3e-5d0b-4aac-aef5-ae6b6b6c4758.png)

Appuyez sur OK pour lancer l’importation.

![image](/images/gh-e806f734-8b04-4487-bc0d-7a3fe3c0eca6.png)

Les attributs ont été attribués à chaque fichier texte. L’ouverture du fichier texte permet d’afficher le détail du texte. Le texte est souligné en vert, ce qui signifie que l’intégralité du texte est associée à un dossier correspondant. Sur l’image ci-dessous, le fichier Survey_ID4.txt a été associé à un dossier nouvellement créé, intitulé ID4.

![image](/images/gh-5cc455fe-a401-47cc-ba1f-08d0c752ba8b.png)

Dans l’écran Gestion > Cas, ela s’affiche comme suit, avec un fichier texte attribué à chaque cas :

![image](/images/gh-a35b341a-40e6-4d38-9647-179f6bc25d5e.png)



## SECTION BEING DEVELOPED

### Anciennes versions de QualCoder (par exemple, QualCoder 3.5)

Chaque réponse à une question qualitative était ajoutée à UN seul fichier texte. La réponse était précédée d’un texte supplémentaire ajouté par QualCoder pour indiquer à quel cas elle se rapportait.

Sous ce format : *\[identifiant unique\] Le texte qualitatif.*

Ouvrez « Gérer les fichiers », puis affichez ce fichier : vous verrez le texte d’attribution au cas, mis en surbrillance en vert.
