# Importation d’enquêtes

Ouvrez la page **Gérer** > **Fichiers** et cliquez sur le bouton « Importer une enquête ».

![image](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

Un questionnaire peut être importé à partir d’un fichier CSV (valeurs séparées par des virgules) ou d’un fichier Microsoft Excel (xlsx). **La première ligne doit contenir les en-têtes des attributs et des données de texte libre. La première colonne doit contenir l’identifiant unique de chaque participant à l’enquête.**

Vous trouverez quelques exemples de questionnaires dans le dossier « Examples » :

## à réviser

QualCoder déterminera si les autres colonnes (attributs) sont de type numérique ou alphabétique. Pour les colonnes numériques, chaque cellule doit contenir un nombre ; les entrées vides seront considérées comme alphabétiques par défaut.

QualCoder ne peut pas déterminer quels attributs correspondent à des données qualitatives. Vous devez faire un clic-droit et modifier le type de champ, en le faisant passer de « caractère » à « qualitatif », pour les champs qui doivent être de type qualitatif.

![image](/images/ae540730-b58c-484e-9beb-8aa40093e94d.png)

Par défaut, chaque réponse qualitative de chaque ligne sera stockée dans une entrée distincte du fichier texte de la base de données QualCoder. Chaque fichier sera associé à son cas (chaque ligne de l’enquête, avec son identifiant unique).

Lorsque vous cliquez sur le bouton OK, les cas et leurs attributs seront ajoutés.

## Comprendre les fichiers CSV

Les fichiers d’enquête au format CSV sont délimités par des virgules ; il est possible de choisir un autre délimiteur. Pour les fichiers délimités par des tabulations, saisissez "ta", "tb" ou "tab" dans le champ « Délimiteur » afin que QualCoder sache que le fichier CSV est délimité par des tabulations.

Le format de mise entre guillemets des données CSV peut être "NONE", "MINIMAL" ou "ALL". Vous trouverez ci-dessous des exemples de chaque format ; veuillez ouvrir votre fichier CSV avec un éditeur de texte ou un outil similaire pour vérifier comment il a été préparé.

```
NONE
colin, 44, male
MINIMAL
"colin", 44, "male"
ALL
"Colin", "44", "male"
```

### Anciennes versions de QualCoder (par exemple, QualCoder 3.5)

Chaque réponse à une question qualitative était ajoutée à UN seul fichier texte. La réponse était précédée d’un texte supplémentaire ajouté par QualCoder pour indiquer à quel cas elle se rapportait.

Sous ce format : *\[identifiant unique\] Le texte qualitatif.*

Ouvrez « Gérer les fichiers », puis affichez ce fichier : vous verrez le texte d’attribution au cas, mis en surbrillance en vert.
