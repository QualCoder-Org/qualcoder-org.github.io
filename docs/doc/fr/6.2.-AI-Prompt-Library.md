# Bibliothèque d’instructions IA

- Les instructions (prompts) jouent un rôle essentiel dans tout type d'analyse de données qualitatives utilisant de grands modèles linguistiques. Ils indiquent à l'IA comment analyser vos données et répondre à vos requêtes. Rédigés en langage naturel, ils sont faciles à comprendre pour les non-programmeurs.

- Dans QualCoder, les prompts qui sous-tendent les fonctionnalités d'IA sont accessibles depuis l'interface utilisateur. Ils peuvent être personnalisés pour s'adapter à votre approche méthodologique et à vos questions de recherche.

- Nous avons déjà intégré certaines instructions intéressantes proposées par d'autres chercheurs en qualité et publiées dans diverses revues. Nous espérons que l'utilisation croissante de l'IA dans la recherche qualitative s'accompagnera d'une culture de développement, de partage et de discussion autour d'instructions sophistiquées au sein de la communauté scientifique, afin que nous puissions tous apprendre les uns des autres et améliorer les nouvelles méthodes émergentes dans ce domaine.


## La structure d'une instruction

Dans son sens le plus basique, une instruction ressemble à la question que vous tapez dans l'interface web de ChatGPT. Mais même dans ce cas, c'est un peu plus complexe. En arrière-plan, ChatGPT accompagne votre question d'une « instruction système » invisible qui demande à l'IA d'être un assistant utile et bienveillant, de ne pas donner de conseils médicaux ou juridiques, etc.

De manière similaire, les instructions dans QualCoder sont **modulaires** et se composent de plusieurs éléments, certains modifiables et d'autres non.

Voici la structure de base :

![](/images/b77df95d-f5b3-4ffa-8d3a-a511c82ef9ab.png)

Cette structure comprend :

- **des éléments fixes** (affichés ici en blanc sur bleu) définis dans le code source de l'application,
- **des informations contextuelles** (en vert) que vous entrez à divers endroits de l'interface utilisateur de QualCoder, comme les noms de codes et les mémos, ou le mémo de projet contenant des informations importantes sur votre recherche,
- **des données empiriques** (en jaune), sélectionnées de différentes manières,
- et l'**instruction analytique** (en orange), que vous pouvez modifier et adapter à vos besoins.


## Instructions analytiques

Les instructions analytiques sont **au cœur des fonctionnalités d'IA de QualCoder**. Elles indiquent à l'IA comment analyser vos données. Ces instructions peuvent être simples, mais aussi devenir des directives complexes avec des descriptions détaillées de chaque étape que l'IA doit suivre pendant l'analyse, y compris le contexte méthodologique, etc. (voir Lieder & Schäffer, 2024)<sup>1</sup>.

QualCoder propose un ensemble d'instructions analytiques prédéfinies. Vous pouvez également définir les vôtres, soit en cliquant sur le bouton **« Modifier »** à côté de la sélection d'instruction, soit en accédant à la **« Bibliothèque d'instructions »** située dans le menu **« IA »**. Cela ouvrira la fenêtre suivante :

![](/images/530f0c1e-f1c3-4827-9dad-1295ea70c18b.png)

Les instructions sont divisées en plusieurs catégories :

1) **Type**
   - Les instructions **« Recherche »** sont utilisées dans le [codage assisté par IA](4.2.-AI-Assisted-Coding),
   - Les instructions **« Code, Thème et Analyse de texte »** sont utilisées dans la fenêtre de chat IA.

2) **Portée**
   - Les instructions **« Système »** sont définies au niveau de l'application et ne peuvent pas être modifiées directement. Si vous souhaitez modifier une instruction système, vous devez d'abord la dupliquer.
   - Les instructions **« Utilisateur »** sont définies par l'utilisateur et stockées sur son ordinateur. Elles sont disponibles pour tout projet ouvert sur cet ordinateur.
   - Les instructions **« Projet »** sont spécifiques à un projet et stockés avec les fichiers du projet. Si vous ou quelqu'un d'autre ouvrez le même projet sur un autre ordinateur, ces instructions y seront également disponibles.

3) **Nom et description de l'instruction**
   Ces informations s'affichent à plusieurs endroits de l'interface utilisateur où vous pouvez sélectionner une instruction analytique. Les noms doivent être uniques dans chaque portée.

4) **Texte de l'instruction**
   Ce sont les instructions réelles qui seront envoyées à l'IA (la zone orange dans l'image ci-dessus). Si vous souhaitez partager votre instruction avec quelqu'un d'autre, c'est l'information la plus importante à transmettre.


!!! note "Une note sur les langues"
    Toutes les instructions prédéfinies dans QualCoder sont rédigées en anglais. Cependant, elles peuvent également être appliqués à des données dans d'autres langues. Il n'y a aucun problème à rédiger des instructions analytiques dans d'autres langues que l'anglais et à les utiliser avec QualCoder. La plupart des grands modèles de langage sont assez flexibles en matière de mélange de différentes langues.
