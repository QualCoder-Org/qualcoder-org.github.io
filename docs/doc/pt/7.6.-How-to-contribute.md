# Como contribuir

## Contribuir para o código

Por favor, leia o [Orientações para as contribuições](https://github.com/ccbogel/QualCoder?tab=contributing-ov-file)

## Contribuir para a tradução
### Traduzir a documentação

Você pode traduzir a documentação criando/modificando os arquivos de marcação em documentos/doc em [o repositório do site](https://github.com/QualCoder-Org/qualcoder-org.github.io).

### Traduzir o software

QualCoder suporta funcionalidade multilingue usando dois tipos de arquivos de tradução:

- Arquivos Gettext (.po ou .mo), que contêm a tradução de software;
- Arquivos de idioma QT (.ts ou .qm) correspondentes à interface do usuário.

Para traduzir:

 1. Criar um ficheiro de idioma (se já não existir) utilizando este comando: ```python rebuild_lang.py --create --lang LANGUAGE_CODE``` Por favor, note que os nomes dos seus arquivos de idioma devem cumprir com o [ISO 639-1](https://fr.wikipedia.org/wiki/Liste_des_codes_ISO_639-1) formato.
 2. Se um arquivo de idioma já existe, você pode atualizar as traduções usando ```python rebuild_lang.py --update --lang LANGUAGE_CODE```.
 3. Você pode editar as traduções dos arquivos .po e .ts na pasta src/i18n usando o [Poedit](https://poedit.net/) software.
 4. Uma vez concluído o trabalho, compile para o formato de máquina usando este comando: ```python rebuild_lang.py --compile --lang LANGUAGE_CODE```.
