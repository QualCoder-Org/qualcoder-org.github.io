# Visão geral

As instruções descrevem como instalar e usar o QualCoder. A informação aqui se refere à versão mais recente do QualCoder.

## O que é o QualCoder?

QualCoder é livre, software de código aberto para análise de dados qualitativos.
Com o QualCoder você pode codificar texto, imagens, áudio e vídeo, escrever notas de diário e memorandos. Você pode organizar códigos em um esquema de categorização tipo árvore. Vários relatórios podem ser gerados. A maioria dos relatórios pode ser exportada como html, texto de documento aberto (ODT), texto simples ou arquivos Excel.

As versões recentes contêm recursos auxiliares de IA opcionais que usam GPT-4 ou outros Modelos de Língua Grande para ajudar a explorar, analisar e interagir com dados de formas inovadoras. Familiarize-se com novos dados por [explorar tópicos ou conceitos amplos](5.1.-AI-chat-based-analysis#topic-analysis-chat) numa conversa interactiva com a IA. Mergulhar mais em aspectos específicos com [Codificação assistida por IA](4.2.-AI-Assisted-Coding) e [análise de texto](5.1.-AI-chat-based-analysis#text-analysis-chat)E se você chegar ao ponto em que você deve sintetizar e consolidar seus resultados, [discuti-los em um chat de código](5.1.-AI-chat-based-analysis#code-analysis-chat) com a IA.

QualCoder é projetado para ser usado como software baseado no cliente para ser usado por uma pessoa de cada vez. (Um segundo codificador pode usar o mesmo projeto no mesmo computador, ou a pasta do projeto pode ser transferida para o computador do segundo codificador). QualCoder não é projetado para ser multi-acessado ao mesmo tempo. Aceder ao projeto em uma localização na nuvem não é recomendado, ele pode corromper o banco de dados se uma conexão de banco de dados for perdida durante qualquer processo de atualização de banco de dados.
