# Instalação e execução

## INSTALAÇÃO

Para as instalações manuais (usando a linha de comando ou terminal) Uma versão de lançamento específica pode ser mencionada, por exemplo a versão 4.0. Por favor, verifique o [página de lançamentos](https://github.com/ccbogel/QualCoder/releases) para a versão mais atual, como pode ser mais recente.

### Pré-requisitos
VLC é opcional para codificação de áudio/vídeo. Opcionalmente, instale ffmpeg para exibição de forma de onda, veja [phenixnap.com/kb/ffmpeg-janelas](https://phoenixnap.com/kb/ffmpeg-windows). Nota, o QualCoder trava no Linux Fedora Fedora ao tentar mostrar ou codificar áudio/vídeo.

=== "Janelas"

    Escolha o [última versão](https://github.com/ccbogel/QualCoder/releases/latest).

    Você tem duas opções para executáveis criados no Windows 11:

    Opção 1: Um instalador do Windows na página de lançamento.

    Opção 2: Versão portátil que não requer instalação. Você pode executar o arquivo baixado diretamente. Pode levar até 30 segundos para o programa abrir.

    No primeiro uso, o Windows irá avisá-lo que o QualCoder é de um editor desconhecido. Clique em "Mais informações > Corre de qualquer maneira". Custa muito dinheiro para obter um certificado de editora confiável - de modo que isso não será possível para o futuro previsível. Se você está desconfortável com estes avisos instalar a partir da fonte como detalhado próximo.

    Alternativamente, instale a partir do código fonte:

    Usar um ambiente virtual (comandos no ponto 6 abaixo). Não usar um ambiente virtual pode afetar outro software Python que você possa ter instalado.

    1. Baixe e instale a linguagem de programação Python. Por favor, use uma versão recente no Windows.  [Python3](https://www.python.org/downloads/). Baixe o mais recente "Windows installer (64-bit)" (ou o que corresponde à sua arquitetura) para uma das versões Python acima mencionadas.

    IMPORTANTE: na primeira janela da instalação marque a opção "Adicionar Python ao PATH"

    2. Baixe o software QualCoder de: https://github.com/ccbogel/QualCoder do botão Código Verde. Este é o mais novo, mas ainda não oficialmente liberado código (ocasionalmente erros de codificação craw in). Clique no botão verde "Código", e em seguida "Download ZIP". ** Alternativamente**, escolha o zip de lançamento mais recente, veja o lado direito desta página para o link para Releases.

    3. Descompactar a pasta para um local (por exemplo, downloads). (Dica, remova a extração de pasta duplicada QualCoder-master\QualCoder-master quando perguntado onde extrair. Apenas QualCoder-master).

    4. Use o prompt de comando do Windows. Digite "cmd" no motor de busca Windows Iniciar, e clique no software preto "cmd.exe" - o console de comando para Windows. No tipo ou pasta do console, usando o botão direito do mouse copiar e colar (ctrl+v não funciona)

    5. No prompt de comando, mover (usando o `cd` comando) na pasta QualCoder. Você deve estar dentro da pasta QualCoder-master ou usando uma versão (a pasta Qualcoder-4.0). Por exemplo:

    ```bash
    cd Downloads\QualCoder-master
    ```

    5a. Em vez dos próximos comandos abaixo, execute o arquivo bat que executará todos esses comandos abaixo, digitando isso e pressionando Enter:

    `run_from_source_Windows.bat`

    Se você tiver erros usando um arquivo bat, execute os comandos abaixo.

    6. Instale o ambiente virtual e módulos python necessários.



    A instalação pode levar até 10 minutos. Em alguns sistemas Windows você pode precisar substituir o comando  python  por  py  ou  python3  abaixo:

    ```bash
    python -m venv env
    env\Scripts\activate
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt
    ```

    7. Iniciar o QualCoder movendo- se pela primeira vez para a pasta interna do src:

    ```bash
    cd src
    python -m qualcoder
    ```


    8. Se executar o QualCoder em um ambiente virtual, para sair do tipo de ambiente virtual:

    `deactivate`

    O prompt de comando irá então remover o texto *(env)*.

    ** Para iniciar o QualCoder novamente**

    Se você não estiver usando um ambiente virtual, desde que esteja na mesma letra da unidade, por exemplo, C:

    `python -m qualcoder`

    Se você estiver usando um ambiente virtual:

    `cd` para a pasta src dentro da pasta QualCoder-master (ou pasta de lançamento Qualcoder):

    ```
    env\Scripts\activate
    cd src
    python -m qualcoder
    ```

=== "MacOS"

    **Instalar a partir de pacotes de aplicativos:**

    Certifique-se de ter instalado quaisquer atualizações do macOS antes de iniciar a instalação. Vá para o aplicativo Configurações do sistema no Mac. Clique em Geral na barra lateral (você pode precisar rolar para baixo), em seguida, clique em Atualização de Software.

    Instale o QualCoder: Clique duas vezes no arquivo dmg baixado. Arraste o QualCoder para o link para suas aplicações.

    Inicie o QualCoder a partir do seu Launchpad ou clicando duas vezes no aplicativo dentro da pasta de aplicativos.
    Atualmente, não somos capazes de assinar os pacotes de aplicativos, então quando você tentar executar o programa pela primeira vez, você pode obter um aviso pop-up de que o QualCoder é de um desenvolvedor não registrado ou "O QualCoder não pode ser aberto porque a Apple não pode verificar por software malicioso." Dependendo do seu processador, você pode ver um destes:

    Se você ver "Apresentar no Finder" ou OK. Clique em Ok.

    Se vires "Feito" ou "Mova-se para o lixo". Clique em Concluído.

    Em seguida, acesse Configurações e selecione Privacidade e Segurança. Desça até que você veja uma mensagem afirmando que o QualCoder foi impedido de começar. Clique em "abrir de qualquer maneira". Você pode ser solicitado a digitar sua senha e pode precisar clicar em "Abrir" novamente. Depois de inserir sua senha, basta esperar o programa para abrir. Pode levar vários segundos.

    A partir de agora, o QualCoder deve começar sem problemas.

    Você pode instalar o QualCoder sem o administrador direito. Você deve copiar os binários no diretório /Users/mylogin/Applications. Você deve excluir o atributo no diretório da aplicação, digitando no terminal:
    ```xattr  -d com.apple.quarantine /Users/mylogin/Applications/QualCoder.app```

    **Install from source code:**

    Use a virtual environment (commands in point 6 below). Not using a virtual environment may affect other Python software you may have installed.

    1. Download and install the Python programming language. Please use Python 3.10, 3.11 or 3.12 on Windows, other versions may cause issues  [Python3](https://www.python.org/downloads/macos/). Download the latest "macOS 64-bit universal2 installer" for one of the above mentioned Python versions and open it to install Python.

    2. Download the QualCoder software from: https://github.com/ccbogel/QualCoder from the Green Code button. This is the newest, but not yet officially released code (occasionally coding errors creep in).  Click the green button "Code", and then "Download ZIP". **Alternatively**, choose the most recent release zip, see the right-hand side of this page for the link to Releases.

    3. Unzip the folder to a location (e.g. downloads) by double-clicking it.

    4. Use the Terminal app (`Applications -> Utilities -> Terminal`).

    5. In the terminal, move (using the `cd` command) into the QualCoder folder. You should be inside the QualCoder-master folder or if using a release (e.g. Qualcoder-4.0 folder). e.g.

    ```bash
    cd Downloads/QualCoder-master
    ```

    6. Install the virtual environment and required python modules.

    The `python3` command uses the most recent installed version of Python. You can use a specific version on your macOS, if you have many Python versions installed, e.g. `python3.10`. To verify you are using the correct Python version type `which python3`, which should output: `/Library/Frameworks/Python.framework/Versions/3.<version>/bin/python3`. If the output is `/usr/bin/python3`, don't continue, since this is your system's Python and it is discouraged to use.

    The install may take up to 10 minutes.

    ```bash
    python3 -m venv env # isso cria o ambiente virtual com o nome "env" em seu diretório atual
    fonte env/bin/ativar # isso ativa o ambiente virtual "env", (env) deve aparecer na frente de seu prompt
    pip3 install -- upgrade pip # opcionalmente; pip e pip3 são equivalentes com um ambiente virtual
    pip3 install -r requirements.txt
    ```

    7. Run QualCoder from the command prompt

    ```bash
    cd src
    python3 -m qualcoder # python e python3 são equivalentes a um ambiente virtual
    ```

    8. If running QualCoder in a virtual environment, to exit the virtual environment type:

    ```bash
    desactivar
    ```

    The command prompt will then remove the *(env)* wording.

    **To start QualCoder again**

    If you are not using a virtual environment:

    ```bash
    cd Downloads/QualCoder-master
    cd src
    python3 - m qualcoder
    ```

    If you are using a virtual environment:

    ```bash
    cd Downloads/QualCoder-master
    env/bin/activar fonte
    cd src
    python3 - m qualcoder
    ```


=== "Linux"

    If you are using a Debian-based system (Debian, Ubuntu / Lubuntu / ZorinOS, Linux Mint), there is an executable file available on the release page. Download and double click to run. You might first need to right-click on the file and go to Properties, then check the Executable checkbox.

    If you are using a different operating system, please install from the source code. The procedure is set out below.

    Note: Fedora uses Wayland which may not work well with the Qt graphical interface. It is suggested you also install Xwayland.

    To install from source code below, inside a virtual environment.

    Depending on your operating system, you will need to download Python and its dependencies. Here are the commands for your operating system:

    - If you are on **Debian based system (Debian, Ubuntu / Lubuntu / ZorinOS, Linux Mint)** :
      Install pip. This is a tool that downloads extra python modules :  `sudo apt install python3-pip`
      If you are using audio or video, install VLC (download from site) or: `sudo apt install vlc`
      If you are using the alternative Ubuntu Desktop manager **Xfce** you may need to run this: `sudo apt install libxcb-cursor0`
    - If you are on **Fedora** : **There is a problem with using VLC from python. The software crashes, we are unable to find a solution to this. So audio and video cannot be used within a QualCoder project on Fedora.**
    - If you are on **Arch/Manjaro Linux** : If you are using audio or video, install VLC (download from site) or: `sudo pacman -S vlc` and Install pip and venv: `sudo pacman -S python python-pip python-virtualenv`


    1. Download and unzip the QualCoder folder.

    2. Then `cd` to the QualCoder folder.

    For example, you may now be in this folder, where you unzipped QualCoder:

    yourcomputer:~Downloads/QualCoder-4.0

    3a. Instead of the commands from 3b. onwards, run the shell file which will run all these below commands. Make this file executable (Right-click and go to Properties), then type the below command and press Enter:

    `./run_from_source_Linux.sh`

    3b. Set up virtual environment and install python modules. The virtual environment will be in its own folder called env. Installing required modules takes a while.

    ```
    python3 - m venv env
    env/bin/activar fonte
    pip install -- upgrade pip
    pip install -r requirements.txt
    ```

    5. Move to the inner src folder, then:
    ```
    cd src
    python3 - m qualcoder
    ```

    6. After using QualCoder deactivate the virtual environment.

    `deactivate`

    **Usage any time after the install, move to the QualCoder folder then:**

    ```
    env/bin/activar fonte
    cd src
    python3 - m qualcoder
    ```

    To exit the environment:

    `deactivate`

    You can also make a .desktop file for launching QualCoder:

    Create a .Desktop file for launch, enter this command (adapt it according to the location of the source code folder):

    `bash -c 'cd ~/.local/share/qualcoder/src/ && ~/.local/share/qualcoder/env/bin/python3.12 -m qualcoder'`
