# Importações de Inquérito

Abra a página ** Gerenciar** > **Arquivos** e pressione o botão Importar pesquisa.

![imagem](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

Uma pesquisa pode ser importada de um arquivo CSV (valores separados por vírgulas) ou do arquivo Microsoft Excel (xlsx). **A primeira linha deve conter os cabeçalhos para os atributos e para os dados de texto livre. A primeira coluna deve conter os identificadores únicos para cada entrevistado.**

## Importando o arquivo survey456.csv

Pressione o botão importar pesquisa e selecione o arquivo na pasta Exemplos.

![imagem](/images/gh-c777dc45-5aec-4c2e-a705-8ef8abc7418a.png)

O assistente de pesquisa lê o arquivo CSV e mostra os nomes das colunas à esquerda.

![imagem](/images/gh-a17388a6-db2f-423b-8b6d-69f8c59d172a.png)

O identificador do participante, denominado Caso nesta pesquisa, pode ser atribuído à seção Casos/Participantes. As colunas de dados Idade, Gênero e Interesses podem ser atribuídas aos atributos. A coluna freetext pode ser atribuída aos Textos Qualitativos. Neste exemplo, atribuiremos os atributos aos arquivos, e não iremos autcode o texto qualitativo com o nome da coluna 'freetext'. QualCoder determinará se as colunas de atributos são Numéricas ou Caracteres. Para colunas numéricas, cada célula deve conter um número ou estar vazia, caso contrário os itens serão predefinidos como Caracter.

![imagem](/images/gh-44838a3e-5d0b-4aac-aef5-ae6b6b6c4758.png)

Pressione OK para aprovar a importação.

![imagem](/images/gh-e806f734-8b04-4487-bc0d-7a3fe3c0eca6.png)

Os atributos foram atribuídos a cada arquivo de texto. A abertura do ficheiro de texto mostra o detalhe do texto. O texto é sublinhado em verde, o que significa que todo o texto é atribuído a um caso correspondente. Na imagem abaixo, Survey ID4.txt foi atribuído a um caso recém-criado chamado ID4.

![imagem](/images/gh-5cc455fe-a401-47cc-ba1f-08d0c752ba8b.png)

Na Gerenciar > Tela de casos é mostrado assim, com um arquivo de texto atribuído por caso:

![imagem](/images/gh-a35b341a-40e6-4d38-9647-179f6bc25d5e.png)

![imagem](/images/gh-03a07b75-d7bf-496d-952c-cb397ebab8f7.png)

Isto tem duas colunas qualitativas diferentes:

![imagem](/images/gh-f48d1b04-26a9-45eb-a88a-f86ffb8716f4.png)

Pressione OK

![imagem](/images/gh-79b7a8e5-0bf6-4a80-9acf-ace6965acca7.png)

Os novos arquivos qualitativos foram adicionados, e os atributos do arquivo agora são estendidos com as três novas respostas da pesquisa.
A diferença aqui é que os novos arquivos tinham diferentes componentes qualitativos. Ambas as colunas de resposta qualitativa foram coladas em um arquivo de texto para cada caso.

![imagem](/images/gh-e5920d18-10e5-47d5-af59-dfd7dced11e1.png)
