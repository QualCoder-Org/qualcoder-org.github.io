# Importações e exportações
Menu do Projeto contém a maioria das importações e exportações.

![imagem](/images/gh-c2551513-0bb0-437b-9b24-002b357bcbe1.png)

Projetos e codebooks podem ser exportados usando o padrão REFI-QDA. Os livros de códigos podem ser exportados para ODT ou texto simples.

![imagem](/images/gh-d2d1f30f-4058-4533-a568-b814a1b72e82.png)

As pesquisas são importadas através de um botão na janela Gerenciar arquivos. [Ver Importações de Inquérito](6.2.-Survey-Imports)

##  Exportação do livro de códigos

Esta é uma opção no Menu Projeto > Exportações.

Um livro de códigos é uma lista dos seus códigos. Cada memorando de código deve detalhar as razões para a finalidade de cada código. O livro de códigos pode ser exportado para um arquivo de texto. O livro de códigos também mostra a frequência dos códigos utilizados (de todos os codificadores). Uma vez que os códigos e categorias são colocados numa estrutura semelhante a uma árvore, o duplo menos «–» indica os códigos e categorias subordinados dentro de uma categoria.

## Importação do livro de códigos

Importar um livro de códigos como um arquivo de texto simples (.txt) ou como um arquivo .csv. Use dois maiores que símbolos para separar categoria e código. Use três maiores que símbolos para definir um código sob um código.

### Codebook - Importação de texto simples

Criar um arquivo de texto simples (.txt). Use a aba para adicionar um memorando.

```
code1

category1>>category2>>code2	memo

category1>>code3

category3>>code4

code5>>>code6>>>code7
```

### Codebook - arquivo CSV

Crie um arquivo CSV no LibreOffice Calc ou MicrosoftOffice Excel. As categorias e códigos estão na primeira coluna, e configurados da mesma forma que para um arquivo de texto simples. Quaisquer memorandos de código estão na segunda coluna.
```
code1

category1>>category2>>code2

category3>>code3
```

## REFI-QDA
[Iniciativa Formato de Intercâmbio de Roterdão (REFI)](https://www.qdasoftware.org)  é um padrão aberto para exportação e importação de codebooks e projetos de e para diferentes softwares de análise de dados qualitativos assistidos por computador.

Atualmente, o QualCoder é capaz de importar um codebook desde que ele esteja usando o:QDA-XML:livro de códigos:1.0" versão. QualCoder também exporta nesta versão.

A exportação de um projeto e a importação de um projeto são funcionais. **Não garantimos que a Qualcoder atenda ao padrão REFI-QDA completo.** Algumas experiências foram realizadas com arquivos de projeto Nvivo, Atlas.ti, Quirkos e MAXQDA REFI QDA. A importação para MAXQDA parece exigir um caractere adicional de fim de linha em relação à codificação de texto - esta é uma opção na exportação do projeto REFI-QDA da QualCoder. Importar para o Atlas.ti mudou os códigos por um caractere após cada linha terminar, e ainda não foi resolvido. A importação de atributos do QualCoder não funciona para Atlas.ti, MAXQDA, os atributos de caso não foram importados para Quirkos.

Características como conjuntos e gráficos não podem ser importados, pois esta funcionalidade não está dentro do QualCoder. Outros formatos de dados não são preservados, por exemplo data ou booleano seria convertido para dados de texto.

Para áudio e vídeo, a importação de transcrições e pontos de sincronização não é testada. A importação/ligação de arquivos relacionados não foi testada.

Para importar, feche primeiro qualquer projeto atualmente aberto. Em seguida, escolha um novo nome do projeto QualCoder e selecione o arquivo de importação qdpx.

Se nenhum dado codificado estiver visível, você pode precisar alterar o nome do codificador atual em Configurações. Tente a caixa de nomes do codificador.

Este é agora antigo (Fev 2021), mas um usuário testou a importação de um arquivo de projeto REFI-QDA gerado pela QualCoder e importado para MAXQDA, Quirkos, Atlas.ti. Apenas texto e imagens foram testados. Um PDF dos resultados do teste está aqui: [Teste de importação de arquivos do projeto REFI-QDA para Atlas, MAXQDA, Quirkos PDF](https://qualcoder.files.wordpress.com/2021/02/refi-qda-project-import-quirkos-maxqda-atlas.pdf)

## Importação Taguette
Projetos criados com [Taguette](https://www.taguette.org/) pode ser importado do arquivo sqlite. Todos os seus dados de codificação serão transferidos.

Fecha qualquer projecto aberto. Em seguida, no Menu Principal do Projeto, clique em Taguette Project import. Você será solicitado a criar um novo projeto, então digite um nome. Em seguida, você será solicitado a selecionar o arquivo de projeto Taguette (geralmente com uma extensão .sqlite3). O QualCoder irá então proceder à importação dos dados.

Se não vir quaisquer dados codificados, poderá necessitar de alterar o nome do codificador actual nas Definições. Tente usar o nome do codificador.

## Importação do Sonal π (Sonal Pi)

Projetos criados com  [Sonal Pi](https://www.sonal-info.com) um software de análise de dados qualitativo desenvolvido em francês pode ser importado.

## Importação RQDA
Projectos realizados com [RQDA](http://rqda.r-forge.r-project.org/) pode ser importada diretamente. Todos os dados, exceto as categorias de arquivos, são importados.

Fechar qualquer projeto aberto. Em seguida, no menu principal em Projeto clique em RQDA Project import. Você será solicitado a criar um novo projeto - então digite um nome. Então você será solicitado a selecionar o arquivo de projeto RQDA. O QualCoder irá então importar os dados.

Se nenhum dado codificado estiver visível, você pode precisar alterar o nome do codificador atual em Configurações. Tente a caixa de nomes do codificador.

## Ajuda - Funções Especiais

### Conteúdo de texto de atualização dinâmica

Isso é útil para atualizar arquivos de texto, como extratos de posts do blog, que mudam ao longo do tempo. Atualizar um arquivo de texto enquanto tenta manter os segmentos de texto codificados existentes. Selecione o arquivo de texto que precisa ser substituído e selecione o arquivo de substituição. Clique no botão engrenagens para executar a atualização. Esta função funciona encontrando o texto correspondente idêntico no arquivo de substituição como ele analisa através do texto do arquivo. Pode produzir segmentos erroneamente codificados.
