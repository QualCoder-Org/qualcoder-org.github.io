# Configurações

A tela de configurações permite que você altere vários recursos, incluindo idioma, nome do codificador e tipo de fonte e tamanho da fonte, bem como opções para a integração de IA.

![imagem](/images/baec9b31-e0bd-4607-85c2-65e141f040d6.png)

### Nome do codificador

Vários codificadores podem codificar e anotar o mesmo texto. O seu nome de codificador actual é mostrado no topo da janela de configuração.

![imagem](/images/gh-04951ae2-c5ab-41e7-854f-dad9819183f4.png)

Este nome será usado para identificar suas contribuições para o projeto. Clique no botão "Alterar" para alterar sua identidade ou para criar, renomear ou mesclar outros codificadores no projeto atual. Ler [Trabalhando em uma equipe](2.4.-Working-in-a-Team#important-considerations-regarding-coder-names) para mais informações.

### Configurações gerais

O idioma padrão do QualCoder é o inglês. Francês, alemão e espanhol são línguas alternativas regularmente atualizadas. Outras línguas não foram cuidadosamente revisadas para precisão. Para outras línguas comunitárias, [baixar o relevante.zip](/community) arquivo e colocá-lo no `.qualcoder/i18n` pasta, em seguida, selecione seu idioma nas configurações.

Verificando a caixa Mostrar IDs exibe os IDs numéricos para arquivos de códigos casos e muito mais. Estes IDs podem ser úteis ao escrever consultas sql.

Há poucas opções para alterar a aparência geral do QualCoder.

Para transcrever áudio e vídeo, o formato de tempo e o tipo de suporte podem ser selecionados.

### Cópias de segurança

O backup do projeto pode ser configurado para backup automático a cada hora, ou sem backup. QualCoder mantém os backups mais recentes com data e hora. O nome de backup é:  projectname BKP yyyymmdd hh.qda  Onde é 24 horas. Isso também significa que vários backups não são feitos dentro de uma hora. Assim, um novo backup não pode substituir outro backup criado na mesma hora. Um número limitado de backups são mantidos, ** backups mais antigos são excluídos**. A opção de configuração permite que você escolha entre 1 a 10 backups.

Recomendamos que você faça um backup antes de fazer qualquer alteração substancial, como reorganizar códigos e categorias, fundir projetos ou mesclar códigos. O QualCoder realiza backups por hora (mantendo até os cinco mais recentes) se os backups estiverem definidos nas configurações.

Renomear ou mover para outro local backups específicos que você precisa manter. Quando os backups são definidos, uma opção adicional é escolher fazer backup dos arquivos de áudio/vídeo. Para a completude dos backups é recomendável fazer backup de áudio e vídeo, no entanto, isso pode retardar a abertura do software se você tiver muitos arquivos grandes. Alternativamente, você pode vincular a arquivos de áudio/vídeo grandes ao invés de importá-los na pasta do projeto. O diretório padrão do projeto é onde muitas operações de arquivos serão padrão, para exportação ou procurando importar arquivos.

Em sua pasta pessoal QualCoder criará uma pasta .qualcoder com um arquivo QualCoder.log para registrar eventos e um arquivo config.ini que conterá muitas configurações, como o nome do codificador atual, fontes preferenciais, idioma e um diretório de trabalho preferido. Não tenha certeza de quaisquer dados ou projetos dentro da pasta .qualcoder. O único arquivo que você deve colocar aqui são palavras-chave. arquivo txt, somente se você precisar aplicar um conjunto diferente de palavras-chave para as funções de nuvem de palavras e contagem de palavras. Esta pasta é apenas para o software QualCoder para usar como ele está em execução.
