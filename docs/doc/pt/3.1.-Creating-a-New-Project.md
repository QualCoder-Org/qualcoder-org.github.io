# Criar um Novo Projecto

Você pode **criar um novo projeto no menu ‘Projeto’.**

Se você nomeá-lo "Teste", o projeto será salvo como Test.qda. Test.qda é na verdade uma pasta com subpastas contendo o banco de dados, documentos empíricos e outros arquivos. Se você quiser enviar e-mail do projeto para outra pessoa, feche a pasta inteira.

## Tela principal

A aba Action Log na janela principal exibe várias alterações que são feitas ao usar o QualCoder. A janela principal tem uma barra de menu no topo cheio de opções. Existem cinco abas para:  action log ,  manage ,  reports ,  coding  e  AI chat . Mudar diretamente entre tabulações é geralmente OK. Mas se você estiver adicionando, renomeando, excluindo arquivos em Gerenciar arquivos ou alterando códigos ou categorias de código na área de codificação, é melhor atualizar cada guia selecionando a opção relevante na barra de menu no topo da tela. Por exemplo, alterar arquivos em Gerenciar arquivos, em seguida, fazer codificação ou relatórios - selecione uma opção no Menu para codificação ou relatório, em vez de clicar diretamente na guia para codificação ou relatórios. Isto acontece porque algumas alterações de gestão podem não se actualizar.

![imagem](/images/dcb4d4e7-a39b-424b-84c4-d2915098914f.png)


**Não execute seu projeto a partir de uma localização em nuvem** (OneDrive, Dropbox, etc.). As razões são: às vezes os arquivos não podem ser importados para o projeto. Aceder a um projeto armazenado na nuvem de diferentes computadores é especialmente perigoso, pois pode causar problemas de sincronização e até corromper o banco de dados. Ver [esta página para estratégias seguras para trabalhar em uma equipe e em vários computadores](2.4.-Working-in-a-Team). Da mesma forma, **Não execute seu projeto a partir de um pendrive USB (flash)**, como a corrupção do banco de dados pode ocorrer.

!!! tip "Boas práticas de gestão de dados"
    Para qualquer projeto, mantenha boas práticas de gerenciamento de dados, como ter backups armazenados regularmente e, idealmente, backups armazenados em diferentes locais (por exemplo, nuvem, pastas de computador diferentes, discos rígidos, pendrives USB).

## Escreva um memorando de projeto

Isto é **especialmente importante se você quiser usar os recursos baseados em IA** no QualCoder. O memorando do projeto é usado para fornecer algumas informações contextuais sobre o projeto atual e o tipo de documentos empíricos com os quais estamos lidando. Esta informação, que está incluída em cada consulta, ajuda a IA a produzir respostas muito mais direcionadas e úteis. Você pode acessar o Memo do Projeto > Memo do Projeto.

![Imagem Exemplo do Projecto Memo](/images/c4c44cbe-9195-4cd3-a1f6-e9efccceb45d.png)

QualCoder fornece um modelo para as informações mais importantes. Você não precisa seguir esse modelo exatamente, mas tente ** manter a descrição do projeto curta** (entre 300 e 700 caracteres). Você também pode adicionar notas sobre seu referencial teórico, mas tenha cuidado para não "preformatar" a perspectiva da IA demais.

Se você também quiser usar o memorando do projeto para outras notas que não devem ser compartilhadas com a IA, você pode inserir a tag "######" no texto. Qualquer coisa abaixo desta marca não será enviada para a IA (isso funciona com qualquer memorando em QualCoder).

Se não quiser que o memorando do projecto seja enviado para a IA, desactiva- o na janela de Configuração.
