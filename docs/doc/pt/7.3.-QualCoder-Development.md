# Outras Informações e Licenças

Atualmente, o QualCoder é desenvolvido no Windows 11. QualCoder é escrito em python 3 usando Qt6 para a interface gráfica.

Após a versão 4.0, uma área de desenvolvimento será revisar a presença visual, a interface do usuário, da QualCoder. O objetivo é tornar a interface mais moderna e atraente. Outra área de melhoria será fornecer mais documentação de governança, para apoiar o uso da QualCoder em grandes instituições.

## Sistemas operativos utilizados

QualCoder foi usado no Windows 11, macOS, Ubuntu 24, Lubuntu, Fedora, Linux Mint, Arch Linux, Fedora, NixOS e ZorinOS.

* Usando áudio ou vídeo com QualCoder no Fedora falha QualCoder.
* Debian com o Gnome e a opção janela em azulejo - encolhe o tamanho da janela QualCoder. A melhor opção é desligar o revestimento da janela nas configurações do Gnome.

## Estruturas de dados

** A pasta de projeto qda** Contém pastas para documentos importados e o banco de dados sqlite para armazenar dados de codificação. Quando a IA está habilitada, existe uma pasta ai data contendo um histórico de chat sqlite e um vetorstore. Uma loja vetorial é uma representação numérica de palavras, frases e frases utilizadas pelo modelo de linguagem de IA.
**A pasta de trabalho .qualcoder** em sua pasta pessoal. QualCoder cria arquivos QualCoder.log e configuração. Não coloque nenhum arquivo dentro desta pasta, pois ele é usado como uma configuração de trabalho e área de armazenamento para o QualCoder. A pasta **.qualcoder ai** na pasta pessoal contém detalhes de configuração para uso de IA.
