# Estrutura de dados SQLite

A estrutura de dados v8 atual é descrita para auxiliar no desenvolvimento de buscas (_queries_) sql. Esta estrutura é usada pela QualCoder 3.2.+ Estruturas de banco de dados mais antigas são alteradas quando abertas para corresponder a este formato.

As tabelas estão listadas alfabeticamente.

## Table: annotation[*](7.4.-SQlite-Data-Structure#493) {#table-annotation}

**anid** _integer_[1](7.4.-SQlite-Data-Structure#494) Um número único gerado automaticamente

**fid** _integer_ Links para o source.id para identificar o arquivo de texto. As anotações são apenas para arquivos de texto.

**pos0** _integer_ A posição do caractere inicial no arquivo de texto.

**pos1** _integer_ A posição do caracter final no arquivo de texto.

**memo** _text_[2](7.4.-SQlite-Data-Structure#495) Contém o texto da anotação.

**owner** _text_ O codificador que criou a entrada.

**date** _text_ A data e hora em que entrada foi criada, formato`yyyy-mm-dd hh:mm:ss`

## Table: attribute {#table-attribute}

**attrid** _integer_ Um número único gerado automaticamente.

**name** _text_ O nome do atributo. Isto irá corresponder a _name_ em [**attribute_type**](7.4.-SQlite-Data-Structure#43).

**attr_type** _text_ Isto é 'caso' ou 'arquivo'

**value** _text_ Isto armazena o valor do atributo como texto, mesmo que seja um valor numérico. Você pode precisar _cast_(_value_ como _real_[3](7.4.-SQlite-Data-Structure#496))

**id** _integer_ Este campo representa um ID de fonte ou um ID de caso.

**owner** _text_ O codificador que criou a entrada.

**date** _text_ A data e hora em que a entrada foi criada, formato`yyyy-mm-dd hh:mm:ss`

## Tabela: atribute_type {#table-attribute-type}

**name** _text_ O nome único do atributo.

**owner** _text_ O codificador que criou a entrada.

**date** _text_ A data e hora em que a entrada foi criada, formato`yyyy-mm-dd hh:mm:ss`

**memo** _text_ Contém um memorando sobre o tipo de atributo.

**CaseOrFile** _text_ Isto é 'caso' ou 'arquivo'

**valuetype** _text_ Isto é 'caractere' ou 'numérico'

**pos0** _integer_ A posição do caractere inicial no arquivo de texto. _Null_ se não for um arquivo de texto.

**pos1** _integer_ A posição do caracter final no arquivo de texto. _Null_ se não for um arquivo de texto.

**memo** _text_ Contém o texto do memorando.

**owner** _text_ O codificador que criou a entrada.

**date** _text_ A data e hora em que a entrada foi criada, formato`yyyy-mm-dd hh:mm:ss`

## Quadro: project {#table-project}

Deve conter uma linha.

**datebaseversion** _text_ Atualmente v1, v2 ou v3. O QualCoder irá atualizar para a versão mais recente (adiciona colunas para tabelas).

**date** _text_ A data e hora em que a entrada foi criada, formato`yyyy-mm-dd hh:mm:ss`

**memo** _text_ Um memorando global sobre o projeto

**about** _text_ Deve descrever a versão atual QualCoder usada. Por exemplo, QualCoder 2.5

**bookmarkfile** _integer_ O ID do arquivo de texto fonte. Usado para saltar para o marcador.

**bookmarkpos** _integer_ A posição do carácter no ficheiro de texto. Usado para saltar para o marcador.

** codername** text O nome actual do codificador.

** recentemente used codes** text Código ids contidos de códigos de texto usados recentemente, espaço delimitado.

## Tabela: source {#table-source}

**id** _integer_ Um número único gerado automaticamente.

**name** _text_ O nome com de arquivo a extensão do arquivo. A extensão do arquivo ajuda a determinar se o arquivo é texto, imagem ou A/V. Se o arquivo tiver '.transcribed' como sufixo, ele está associado com o arquivo A/V correspondente.

** Texto completo** texto O texto completo de um arquivo de texto, na codificação UTF-8. _Null_ se uma imagem ou arquivo A/V.

**memo** text Contém o texto do memorando.

**owner** texto O codificador que criou a entrada.

**date** _text_ A data e hora em que a entrada foi criada, formato`yyyy-mm-dd hh:mm:ss`

**mediapath** _text_

**av_text_id** _integer_ Um link para uma fonte de áudio/vídeo para a transcrição do arquivo de texto correspondente.



Se o mediapath estiver vazio, ele é um arquivo de texto armazenado internamente dentro da pasta do projeto.

Se o mediapath começa com 'docs:' é um link para um arquivo de texto externo. O texto completo ainda será carregado em 'fulltext' para uso.

Se o mediapath começa com: '/images/' , '/audio/', '/video/' a imagem, áudio ou arquivo de vídeo é armazenado internamente na pasta do projeto.

Se o mediapath começa com: 'images:' , 'audio:', 'video:' a imagem, áudio ou arquivo de vídeo está ligado externamente. O caminho completo para o arquivo é armazenado.
