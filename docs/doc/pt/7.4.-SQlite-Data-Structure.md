# Estrutura de dados SQLite

A estrutura de dados v8 atual é descrita para auxiliar no desenvolvimento de consultas sql. Esta estrutura é usada pela QualCoder 3.2. As estruturas de banco de dados mais antigas são alteradas quando abertas para corresponder a este formato.

As tabelas estão listadas alfabeticamente.

## Quadro: anotação

**anid**  integer  Um número automático único

**fid**  integer  Links para o source.id para identificar o arquivo de texto. As anotações são apenas para arquivos de texto.

**pos0**  integer  A posição do caracter inicial no arquivo de texto.

**pos1**  integer  A posição do caracter final no arquivo de texto.

**Memo**  text  Contém o texto de anotação.

** proprietário**  texto  O codificador que criou a entrada.

**data**  texto  A data e hora da entrada foi criada, formato `yyyy-mm-dd hh:mm:ss`

## Tabela: atributo

**attrid**  integer  Um número automático único.

** nome**  texto  O nome do atributo. Isto irá corresponder ao nome no tipo  atributo.

**attr type**  text  Isto ou é 'caso' ou 'arquivo'

**valor**  texto  Isto armazena o valor do atributo como texto, mesmo que seja um valor numérico. Você pode precisar de cast(valor como real)

**id**  integer  Este campo representa um ID de origem ou um ID de caso.

** proprietário**  texto  O codificador que criou a entrada.

**data**  texto  A data e hora da entrada foi criada, formato `yyyy-mm-dd hh:mm:ss`

## Tabela: tipo  atributo

** nome**  texto  O nome único do atributo.

** proprietário**  texto  O codificador que criou a entrada.

**data**  texto  A data e hora da entrada foi criada, formato `yyyy-mm-dd hh:mm:ss`

**Memo**  text  Contém um memorando sobre o tipo de atributo.

**CaseOrFile**  text  Isto ou é 'caso' ou 'arquivo'

** tipo de valor**  texto  Isto é 'caractere' ou 'numérico'

## Tabela: case text

**id**  integer  Autonúmero único.

**Caseid**  integer  Ligações com os casos.Caseid.

**fid**  integer  links para o source.id. Estes são apenas para arquivos de texto.

**pos0**  integer  A posição do caracter inicial no arquivo de texto. Null se não for um arquivo de texto.

**pos1**  integer  A posição do caracter final no arquivo de texto. Null se não for um arquivo de texto.

**Memo**  text  Contém o texto do memorando.

** proprietário**  texto  O codificador que criou a entrada.

**data**  texto  A data e hora da entrada foi criada, formato `yyyy-mm-dd hh:mm:ss`

## Tabela: code image

## Quadro: projecto

Deve conter uma linha.

** databaseversion**  text  Atualmente v1, v2 ou v3. QualCoder irá atualizar para a versão mais recente (adiciona colunas para tabelas).

**data**  texto  A data e hora da entrada foi criada, formato `yyyy-mm-dd hh:mm:ss`

**Memo**  text  Um memorando sobre o projecto global.

** sobre**  texto  Deve descrever a versão atual QualCoder usada. Por exemplo, QualCoder 2.5

**bookmarkfile**  integer  O ID do ficheiro de texto de origem. Usado para saltar para o marcador.

**bookmarkpos**  integer  A posição do carácter no ficheiro de texto. Usado para saltar para o marcador.

** codername**  text  O nome atual do codificador.

** recentemente used codes**  text  Código ids contidos de códigos de texto usados recentemente, espaço delimitado.

## Tabela: fonte

**id**  integer  Um número automático único.

** nome**  texto  O nome com extensão de arquivo do arquivo. A extensão do arquivo ajuda a determinar se o arquivo é texto, imagem ou A/V. Se o arquivo tiver '.transcribed' como um sufixo, ele está associado com o arquivo A/V correspondente.

** Texto completo**  texto  O texto completo de um arquivo de texto, na codificação UTF-8. Null se uma imagem ou arquivo A/V.

**Memo**  text  Contém o texto do memorando.

** proprietário**  texto  O codificador que criou a entrada.

**data**  texto  A data e hora da entrada foi criada, formato `yyyy-mm-dd hh:mm:ss`

**mediapath**  text

**av text id**  integer  Um link para uma fonte de áudio/vídeo para a transcrição do arquivo de texto correspondente.



Se o mediapath estiver vazio, é um arquivo de texto armazenado internamente dentro da pasta do projeto.

Se o mediapath começa com 'docs:' é um link para um arquivo de texto externo. O texto completo ainda será carregado em 'fulltext' para uso.

Se o mediapath começa com: '/images/' , '/audio/', '/video/' a imagem, áudio ou arquivo de vídeo é armazenado internamente na pasta do projeto.

Se o mediapath começa com: 'imagens:' , 'áudio:', 'vídeo:', o arquivo de imagem, áudio ou vídeo está ligado externamente. O caminho completo para o arquivo é armazenado.
