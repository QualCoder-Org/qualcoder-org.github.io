# Configuração do IA

Note que os recursos de IA no QualCoder são ** opt-in** e desativados por padrão. Após uma nova instalação, um **wizard** aparecerá que poderá guiá-lo através da configuração se optar por habilitá-los. Você pode reiniciá-lo mais tarde selecionando a opção de menu "AI > Assistente de Configuração".

Todas as opções relacionadas com IA estão localizadas na parte inferior da janela de configuração. Desçam quando necessário.

![Configurações da IA da captura de tela](/images/ad3c3467-debd-4632-aada-68e1291ab8f8.png)

**Passos do assistente de configuração:**

1. ** Habilite a integração de IA** clicando na caixa de seleção na janela Configurações.
2. **[Escolha o modelo de IA que deseja usar](#ai-model-selection)** e configurá-lo.
3. O **[memória de IA local](#the-local-ai-memory-setup)** é então configurado e construído automaticamente. Seja paciente, pois isto pode demorar algum tempo.
4. Depois disso, o agente de IA em QualCoder está **pronto para usar.

Você também pode querer ler [como preparar melhor seu projeto para uso de IA](#improve-ai-usability-in-your-project) e o nosso [notas sobre privacidade de dados](#some-notes-on-privacy-and-data-protection) abaixo.


## Seleção do Modelo de IA

Com a QualCoder, você pode escolher entre uma ampla gama de provedores de IA comerciais e não comerciais, e até mesmo usar modelos locais hospedados em sua própria máquina. Selecione uma das opções na lista de "Perfil do IA" na janela de Configuração.


### Modelos de Fronteira do OpenAI, Antrópico ou Google

Estes grandes modelos fornecem a análise mais nuances de seus dados empíricos e proporcionam a experiência global mais suave. Você tem várias opções:

**Acesso via chave API**

- Configure uma conta com um dos provedores, adquira uma chave * API* e cole-a na janela de configurações QualCoder.
    - OpenAI: Ir para o [Plataforma OpenAI](https://platform.openai.com), adicionar detalhes de cobrança, em seguida, abrir `Settings > API keys > Create new secret key`.
    - Antrópico: Criar uma conta na [Console Claude](https://docs.anthropic.com/en/docs/get-started), adicionar créditos API ou detalhes de faturamento, em seguida, ir para `Settings > API Keys > Create Key`.
    - Google Gemini: Iniciar sessão em [Google AI Studio](https://ai.google.dev/aistudio), selecione ou crie um projeto do Google Cloud e, em seguida, escolha Obter chave API. Um nível livre limitado pode estar disponível para alguns modelos.
- Acesso API é pay-per-use. O fornecedor cobrará uma pequena taxa por cada pedido. Normalmente, você compra "créditos" com antecedência, que são consumidos ao longo do tempo. Como a pesquisa qualitativa geralmente envolve conjuntos de dados relativamente pequenos, o custo de usar IA em sua análise é geralmente modesto.
- Privacidade de dados: Qualquer informação enviada através da interface API paga é geralmente excluída do treinamento de modelo futuro e mantida nos servidores apenas por 30 a 50 dias para faturamento e monitoramento de abuso. No entanto, você deve sempre verificar a política atual de proteção de dados do seu provedor, conforme as condições podem mudar.

** Assinatura ChatGPT Plus, Pro ou Team

- Desde a versão 4.0 do QualCoder, você também pode usar sua assinatura do ChatGPT (Plus, Pro ou Team) como provedor de IA dentro do aplicativo. Neste caso, o uso no QualCoder é deduzido da quota geral da sua conta sem custo extra. Como esta é uma característica experimental, a disponibilidade futura pode variar.
- Para activar esta opção, seleccione "OpenAI ChatGPT Login..." no menu suspenso do perfil de IA na janela de Configuração e clique em "Autenticate...". Uma página de login ChatGPT será aberta em seu navegador padrão. Aqui, você deve autorizar o QualCoder a usar modelos de IA desta conta. Isso substitui a chave API necessária para outros perfis de IA.
- Se a sua autenticação expirar após algumas semanas, volte à janela de configuração para a renovar.
- Note que o QualCoder não tem acesso a nenhuma informação na sua conta ChatGPT além dos modelos de IA brutos. Isso também é verdade na outra direção, já que o ChatGPT não pode acessar qualquer dado dentro do QualCoder.
- Ainda assim, é uma boa prática desativar a opção "Melhorar o modelo para todos" nas configurações de "Controles de Dados" do seu perfil ChatGPT. Isso impede que o conteúdo de suas interações com o ChatGPT seja usado para treinamento futuro de modelos de IA.
- QualCoder usa a mesma interface de comunicação que o assistente de programação Codex do OpenAI. Se a sua organização tiver desativado o Codex na sua conta ChatGPT, poderá não ser capaz de utilizar esta integração com o QualCoder.
- Para **As assinaturas antrópicas de Claude ou Google Gemini**, conectá-las ao QualCoder é menos simples. Se você está tecnicamente inclinado, você ainda pode fazê-lo trabalhar usando [CLIProxiAPI](https://github.com/router-for-me/CLIProxyAPI) como uma ponte. Se fores por este caminho, [adicionar um perfil de IA personalizado](#other-models) em QualCoder e usar `http://localhost:8317/v1` como parâmetro "API Base URL".

**Microsoft Azure**

A Microsoft hospeda grandes modelos de IA do OpenAI em sua plataforma de nuvem Azure. Isso é especialmente útil se você quiser garantir que seus dados sejam processados inteiramente na UE ou em outra região geográfica específica. Azure oferece configurações especiais de "Zona de dados" para isso. Os preços são ligeiramente mais elevados do que com o OpenAI diretamente, mas ainda são razoáveis.

Para usar um modelo, você deve primeiro "implantar" com sua conta Azure usando o [Fundição AI do Azure](https://ai.azure.com/). Procure tutoriais sobre como fazer isso, ou dê uma olhada em: https://www.youtube.com/watch?v=a2JtWKSKP4Q

Para prosseguir, você precisará das seguintes informações:
- o seu nome de implantação,
- o URL do endpoint (deve ser algo parecido `https://XXX.openai.azure.com/`), e
- A tua chave da API.

Vá para "Projeto > Configurações > Integração de IA", clique em "Opções de IA avançadas > Novo perfil de IA", e dê-lhe um nome. Em seguida, insira sua chave de API no campo correspondente, seu nome de implantação Azure nos campos "Modelo Grande" e "Modelo Rápido" (estes podem ser idênticos), e o URL de terminal Azure no campo "api base". Você também pode querer ajustar o tamanho da janela de contexto, dependendo do modelo.


### Infraestrutura AI Acadêmica

A infraestrutura de IA acadêmica sem fins lucrativos lhe dá acesso a modelos de médio porte, mantendo padrões de privacidade de dados muito elevados. Estes serviços são geralmente gratuitos para o pessoal elegível.
A qualidade de saída de tais modelos de tamanho médio melhorou muito ultimamente e é bom o suficiente para a maioria das tarefas em QualCoder. No entanto, ainda não está no mesmo nível que as grandes ofertas comerciais. Você também pode encontrar mais soluços ao interagir com o agente de IA, como erros operacionais ou referências de fonte malformadas.

**Blablador - Serviço gratuito de IA fornecido pela agência de pesquisa acadêmica alemã [Sociedade Helmholtz](https://www.helmholtz.de/en/).**

- Este serviço oferece excelente privacidade e é gratuito para uso para fins acadêmicos em todo o mundo. Para mais informações, consulte [apresentação de Alexandre Strube](https://strube1.pages.jsc.fz-juelich.de/2024-02-talk-lips-blablador/).
- Blablador requer uma chave de API pessoal gratuita da Sociedade Helmholtz. Você pode se inscrever na sua conta universitária ou no GitHub, Google ou ORCID. Siga as instruções aqui: [https://sdlaml.pages.jsc.fz-juelich.de/ai/guides/blablador_api_access/](https://sdlaml.pages.jsc.fz-juelich.de/ai/guides/blablador_api_access/).

**Outras opções acadêmicas**

Alemanha:

- **[GWDG SAIA Göttingen](https://docs.hpc.gwdg.de/services/ai-services/saia/index.html#api-request):** O acesso parece ser limitado a universidades no noroeste da Alemanha. Para usá-lo, você deve primeiro configurar uma conta no GWDG e adquirir uma chave API. Em seguida, abra QualCoder, vá para "Projeto > Configurações > Integração de IA", clique em "Opções de IA avançadas > Novo perfil de IA", e dê um nome ao perfil. Depois disso, insira sua chave API no campo correspondente, o URL `https://chat-ai.academiccloud.de/v1` no campo "base API", e selecione um modelo grande e rápido da lista. Você também pode querer ajustar o tamanho da janela de contexto, dependendo do modelo.
- **[Hessian. AL Darmstadt](https://hessian.ai/):** Acesso experimental, apenas para pessoas elegíveis de universidades hessianas na Alemanha. Siga as instruções para GWDG acima, mas use `https://llm-service.ai.tu-darmstadt.de` como URL base da API.


### Modelos médios como Mistral, DeepSeek e outros

O drop-down do perfil "AI" na janela de configuração também oferece opções para [Mistral (França)](https://mistral.ai/), [DeepSeek (China)](https://deepseek.com/), e [OpenRouter](https://openrouter.ai/), uma plataforma através da qual muitos grandes modelos de linguagem em diferentes servidores podem ser acessados.

Para todas essas opções, você precisará de uma chave API e provavelmente também uma conta paga para um trabalho sério. Verifique cuidadosamente as condições de privacidade dos dados antes de utilizar qualquer um destes serviços.


### Modelos de IA locais em sua própria máquina

Os modelos de IA locais oferecem o mais alto nível de proteção de dados, mas também requerem hardware bastante poderoso para funcionar em uma velocidade e qualidade razoáveis. No meu teste, `Gemma-4-31B-it` Funcionou muito bem. Precisa de pelo menos 24 GB de VRAM em quantização de 4 bits com uma janela de contexto aceitável. Para qualquer trabalho sério em QualCoder, eu não seria muito menor do que isso. [Codificação assistida por IA](4.2.-AI-Assisted-Coding), no entanto, ainda pode funcionar com modelos ligeiramente menores.

- [Ollama](https://ollama.com) é uma escolha popular para executar modelos de linguagem localmente e funciona bem com o QualCoder, usando [API compatível com OpenAI](https://ollama.com/blog/openai-compatibility).
- Certifique-se de que Ollama e o modelo de IA estão configurados e funcionando. Em seguida, selecione o pré-configurado `Ollama local AI` perfil na janela de Configuração, que usa `http://localhost:11434/v1/` como base API.
- A chave API não é realmente usada pelo Ollama, mas não deve estar vazia, ou ocorre um erro.
- Selecione um modelo grande e rápido da lista, provavelmente o mesmo para ambos, pois você geralmente terá apenas um modelo carregado de cada vez. Você também pode querer ajustar o tamanho da janela de contexto, dependendo das configurações do Ollama.


### Outros Modelos

Se você tiver acesso a outros modelos de idiomas grandes em plataformas de nuvem, servidores universitários ou sua própria máquina, você também pode tentar integrá-los no QualCoder.
- O serviço que você deseja usar deve fornecer uma interface compatível com a API OpenAI. Este é frequentemente o caso, uma vez que esta API tornou-se um padrão de facto nos últimos anos.
- Clique em "Opções de IA avançadas > Novo perfil de IA" na janela de configurações, insira o endereço de rede API em " URL base API", e insira o nome do modelo nos campos para o modelo grande e rápido (estes podem ser idênticos). Você também pode querer ajustar o tamanho da janela de contexto, dependendo do modelo.
- Se quiser mais opções, edite `config.ini` arquivo, localizado no `.qualcoder` subpasta da pasta pessoal do utilizador. Faça isto apenas quando o QualCoder não estiver a correr. As definições do modelo de IA são listadas no final de `config.ini` e têm o seguinte formato (omite as marcas "<>"):
```
[ai_model_your_model_name]
desc = A description shown in the UI.
       Can have more than one line.
access_info_url = <URL pointing to a website with model info. Can be empty>
large_model = <The exact name of the model in the API>
large_model_context_window = <The maximum number of tokens in a single request>
fast_model = <Can be identical to large_model or name a smaller model, used for simple tasks>
fast_model_context_window = <The maximum number of tokens for the small model>
reasoning_effort = default
api_base = <The URL of the API base, e.g., http://localhost:11434/v1 for a local Ollama>
api_key = <The API key if needed, or "None" instead. Do not leave this field empty.>
```
Note que o nome da seção deve sempre começar com o prefixo 'ai model '.

Se você tiver outros serviços em execução no QualCoder, ou se você tentou e falhou, gostaríamos de ouvir sobre sua experiência.


## Opções avançadas de IA

Na parte inferior da janela de Configuração, irá encontrar um botão "Opções de IA avançadas". Clicar nele revela mais algumas opções.

- Um caso de uso comum é **switch para um novo ou melhor modelo de IA** se seu provedor oferecer um. Você pode fazer isso selecionando o modelo da lista suspensa nos campos "modelo grande" e "modelo rápido", ou digitando o nome exato diretamente. Para encontrar o nome correto do modelo, procure na web por `YOUR MODEL api name`. Os modelos grandes e rápidos podem ser idênticos, mas o modelo rápido também pode ser muito menor porque é usado apenas para tarefas domésticas, como gerar títulos automáticos para novos chats de agentes de IA.
- ** Razão:** Este parâmetro determina quanto "pensar" interno o IA faz antes de responder. Nem todo modelo suporta este parâmetro, então deixe-o em "padrão" se estiver em dúvida. Observe também que o QualCoder já tem muitos loops de "pensamento" incorporados no próprio fluxo de trabalho do agente, então uma configuração de alto raciocínio pode lhe dar menos melhora do que o esperado. No entanto, o alto raciocínio consumirá mais energia, custará mais, e também retardará a IA, então use esta opção com cuidado.
- Quando se trata de outras opções avançadas, provavelmente é melhor deixá-las em seus valores padrão se você não sabe o que elas significam. Note que os parâmetros "temperatura" e "top p" podem ser silenciosamente ignorados por alguns modelos, especialmente no modo de raciocínio.


## A Configuração Local da Memória da IA

* O agente de IA em QualCoder usa uma memória local especial para pesquisar documentos empíricos rapidamente e encontrar passagens relevantes. Isso reduz muito a quantidade de dados enviados para a nuvem, aumentando assim a privacidade, economizando recursos e aumentando a velocidade.
* A memória é alimentada por um pequeno [modelo de IA de código aberto local](https://huggingface.co/intfloat/multilingual-e5-large), aproximadamente 2,5 GB de tamanho, que é baixado automaticamente na primeira vez que você ativa a IA. Modelo de locais de armazenamento:
  * Windows: C:\\ Usuários\\ YOUR USERNAME\\.cache\\ toch\\ sentence  transformers
  * Linux: /home/YOUR USERNAME/.cache/torch/sentence transformers
  * MacOS: /users/YOUR USERNAME/.cache/torch/sentence transformers
* Uma vez que você abre um projeto QualCoder, este modelo IA lê todos os documentos de texto e os incorpora em sua memória interna.
* Este processo ocorre apenas uma vez. Quando você reabrir o projeto mais tarde, a "memória IA" carrega rapidamente do disco. Se você adicionar novos documentos ao seu projeto ou editar os existentes, sua memória de IA local será atualizada em conformidade.
* O processo inicial de leitura e memorização de seus documentos pode levar algum tempo, então, por favor, seja paciente. Acontece em segundo plano, com a barra de status mostrando "AI: reading". Enquanto isso está acontecendo, funções relacionadas a IA não estão disponíveis, mas você pode usar o resto do QualCoder como de costume.

![IA: mensagem de leitura](/images/04f268f9-d05e-431f-b4fd-d4eabf210a0b.png)

Nota técnica: A memória de IA local QualCoder é um sistema híbrido baseado em [Codificador de frases E5](https://huggingface.co/intfloat/multilingual-e5-large) incorporações armazenadas em uma [Armazenagem de vetores FAISS](https://github.com/facebookresearch/faiss) para pesquisa semântica, e a [Índice SQLite BM25](https://sqlite.org/fts5.html) para recuperação rápida de palavras-chave. Além disso, o agente de IA pode usar expressões regulares para pesquisar os dados do projeto.


## Melhore a usabilidade da IA em seu projeto

O agente de IA em QualCoder deve ser capaz de ler e entender a estrutura do seu projeto, seus documentos empíricos, códigos e memorandos. Também deve ter uma imagem clara dos objetivos, perguntas de pesquisa e métodos que impulsionam sua pesquisa. Isto permite-lhe fornecer respostas muito mais específicas. Algumas sugestões:

- **Update your project memo** (menu "Project > Project Memo") com uma breve descrição de seus tópicos de pesquisa, perguntas, objetivos e os dados empíricos coletados. Essas informações acompanharão todos os pedidos enviados à IA, resultando em respostas muito mais úteis.
- **Dê seus documentos empíricos para que o agente de IA possa inferir o tipo de dados, por exemplo, "Entreview Alice.txt". Você pode renomear documentos diretamente na aba "Gerenciar arquivos" sem reimportar.
- Ao trabalhar com transcrições de entrevista, é aconselhável marcar o entrevistador e respondente em cada turno**, por exemplo, com um prefixo como "Entrevistador:" e "Alice:". Isso permite que o agente de IA compreenda os diferentes papéis na entrevista mesmo quando se olha apenas para uma pequena seção da transcrição.
- Se você usa **memos** para gravar notas pessoais e ideias de brainstorming inacabadas que você não quer compartilhar com o agente de IA, coloque essas notas atrás de uma marca "######". Qualquer conteúdo de memorando abaixo desta marca não será enviado para a IA.


## Algumas Notas sobre Privacidade e Proteção de Dados

* Entendemos que o uso de serviços baseados na nuvem como os da OpenAI levanta dúvidas sobre privacidade e proteção de dados.

* No entanto, acreditamos que o uso desses serviços pela QualCoder está alinhado aos princípios éticos que norteiam a pesquisa social qualitativa. Caso contrário, não ofereceríamos tais características.

* A decisão final depende muito do seu projeto específico, do tipo de dados que você lida e do provedor de IA que você decide usar. Pretendemos torná-lo o mais transparente possível o que acontece com seus dados para que você possa tomar uma decisão informada.

QualCoder segue uma abordagem **"Privacy by Design"**:

* O aplicativo enviará o mínimo de dados possível para a nuvem,** usando o processamento local sempre que possível. A maioria dos recursos usa a memória de IA local descrita acima para fazer uma pré-selecção de dados relevantes. Depois, apenas um pequeno número de pedaços de texto selecionados, cada um com cerca de 500 caracteres, são enviados para a nuvem para análise mais profunda.

* Quando você usa a API OpenAI, seus dados são regidos pelo [Regras de privacidade das empresas](https://openai.com/enterprise-privacy)Estes regulamentos são muito mais rigorosos em termos de protecção de dados do que os dos chatbots gratuitos na Internet. **OpenAI garante que os dados enviados através desta interface [NÃO será usado para treinar modelos de IA](https://platform.openai.com/docs/models/how-we-use-your-data#how-we-use-your-data)**, será mantido confidencial, e será excluído dentro de 30 dias. Outros prestadores de serviços de IA oferecem condições semelhantes.

* A QualCoder não se limita a fornecedores comerciais de IA. Por exemplo, fizemos parceria com **"Blablador,"** um serviço que executa grandes modelos de linguagem em hardware acadêmico não comercial que oferece excelente privacidade (veja acima).

* Além disso, é possível [adicione seus próprios modelos ao QualCoder](#other-models), incluindo aqueles rodando inteiramente localmente em sua máquina sem qualquer acesso de rede. A partir de hoje, no entanto, o trade-off na qualidade de saída é tão significativo que os modelos de IA locais têm apenas casos de uso limitados, a menos que você tenha hardware muito poderoso. Espero que esta situação mude no futuro.

* Em geral, recomendamos que você ** anonymize seus dados** com muito cuidado antes de usar qualquer serviço de IA baseado em nuvem para análise.
