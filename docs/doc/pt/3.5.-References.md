# Referências

Ir para Gerenciar > Referências para importar uma bibliografia. Isto deve estar no texto simples formatado RIS ou NBIB. O arquivo pode ter terminações de .txt ou .ris ou .nbib. Você também pode importar referências do Zotero 7 - garantir que o Zotero esteja aberto e rodando primeiro, e habilitar a API local em Configurações do Zotero - para permitir que o QualCoder se comunique com o Zotero. Os arquivos de referência PDF ou EPUB no Zotero também serão importados.

![imagem](/images/gh-c750c125-1214-466c-9d1f-c549c3a1ad15.png)

Pressione o botão de importação e selecione um arquivo de bibliografia (.txt, .nbib., .ris). Este exemplo foi de um arquivo de texto com uma referência em formato ris - veja pasta Exemplos  bibliografia. Ris . As opções são importar todas, novas referências ou referências específicas. Se houver anexos, como com uma importação Zotero, estes também podem ser importados.

![img](/images/650842457-6a209439-d45c-4e13-8138-5c4dae03e8bd.png)


Você pode vincular e desconectar referências a arquivos. Você pode editar manualmente uma referência importada. Você pode excluir uma referência.

Na tela Gerenciar arquivos haverá quatro novas colunas de atributos: Ref Autors, Ref Título, Ref Type, Ref Year

![imagem](/images/3d85d09f-926c-46df-87cb-867ad8dce4c1.png)

Os arquivos ligados a referências terão detalhes nessas colunas.

Referências podem ser exibidas em análise - como Análise - Recuperação de Código

Você pode exportar todas as referências ao formato ris com o botão exportar.
