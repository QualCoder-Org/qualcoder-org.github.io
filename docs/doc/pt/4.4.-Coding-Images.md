#  Codificação de imagens

As imagens podem ser codificadas de forma semelhante à codificação de texto. Selecione um código. Clique com o botão esquerdo e arraste para destacar a área que deseja atribuir ao código. Botão direito do mouse abrirá um menu onde você pode remover o código ou adicionar um memorando. Na parte inferior da tela, existe um controle deslizante para redimensionar a imagem. Os retângulos codificados são coloridos para corresponder à cor do código. Clique com o botão direito da imagem para abrir as opções de rotação.

A parte superior direita do diálogo mostra alguns detalhes de um clique na área codificada - mostrando o nome de código, as posições de pixel e a área percentual de toda a imagem. Passando o mouse sobre este espaço irá mostrar qualquer memorando para a área codificada.

## Áreas codificadas importantes
Áreas importantes codificadas, como exemplos para um relatório, podem ser sinalizadas como Importante usando o menu com o botão direito do mouse quando nas áreas codificadas e selecionando Importante. No topo da tela está um botão com um símbolo de estrela. Este botão alterna entre mostrar todas as áreas codificadas e as áreas codificadas marcadas como Importantes.

## Atalhos

* Atalho H. Pressione h quando na imagem para esconder e desocultar a seção de controles superiores da tela.
* Atalho L. Pressione L para 'Mostrar códigos como', para mostrar uma lista na árvore de códigos.
* Pressione + ou - botões para ampliar ou encolher a imagem.
* Ctrl Z para restaurar a última área de codificação não marcada.

## Botões de conveniência abaixo da lista de arquivos

* Carregar o próximo ficheiro
* Carregar o ficheiro com a última codificação
* Abre o memorando do ficheiro seleccionado
* Use uma função de filtro mostrar apenas os arquivos que atendem a determinados critérios. Estes podem ser de atributos de arquivo ou se os arquivos estão associados a certos casos. (Botão que exibe uma etiqueta)


## Clique com o botão direito na área da imagem para mais opções

As opções incluem rotação e destaque de um código específico ou área codificada.
Estas opções de realce são: acinzentado, borrado, solarizar, e eles abrem em seu programa de visualização de imagem padrão para visualizar e salvar.

O botão legendas adicionará uma legenda a cada seção codificada escolhida:
Pressione uma vez para adicionar o nome de código. Pressione novamente para adicionar quaisquer memorandos. Pressione novamente para desligar as legendas.

## Exportação

A imagem com áreas codificadas pode ser exportada para um arquivo HTML. Depois de abrir o arquivo em um navegador, o mouse pairando sobre as áreas codificadas mostra o nome de código e memorandos.
