# Opções do menu de análise

* Recuperação de codificação - a principal função de comunicação.
* Co- ocorrência de código - para arquivos de texto. Mostra conta onde um código abuts/overlaps/exact-corresponde a outro código.
* Relações de código - para arquivos de texto. Mostra proximidade, correspondência exata, sobreposições, distância entre os códigos selecionados.
* Code texto corresponde exatamente - para arquivos de texto. Mostra a contagem exacta de correspondências entre códigos.
* Códigos por segmentos de texto - Mostra tabela de nomes de arquivos, texto codificado e códigos atribuídos.
* Gráfico. Criar um mapa mental, de objetos e suas ligações.
* Análise assistida por IA - por tópico, por texto, por código.



## Obtenção de Código

Este relatório fornece uma lista, ou matriz, de dados codificados com base em suas seleções. Um ou mais códigos precisam ser selecionados. Se uma categoria for selecionada, todos os códigos dessa categoria também são selecionados. Várias categorias podem ser selecionadas usando o mouse e o botão ‘ctrl’.

O botão Pesquisar (Botão Tocar) apresentará os resultados.

![Relatórios de código Tela com resultados](/images/fc6a6750-1cfe-41c4-b905-1f589876e573.png)

Os resultados da codificação podem ser reduzidos usando os botões de seleção de arquivos, seleção de casos ou seleção de atributos. Somente serão apresentados códigos dentro dos arquivos ou casos selecionados. Quando as seleções de casos são usadas, as seleções de arquivos são ignoradas. Também quando as seleções de arquivos são usadas, as seleções de casos são ignoradas.

Se o texto for inserido no campo Procurar texto, somente serão apresentados códigos que contenham o texto correspondente.
O texto de busca também procura por correspondência de texto em memorandos para áreas de imagens codificadas e segmentos de áudio/vídeo codificados. A função de texto de pesquisa deve ser usada em combinação com a seleção de arquivos, seleção de casos ou seleção de atributos.

## Importante texto codificado, imagens, segmentos
Existe uma caixa de seleção para selecionar apenas os códigos importantes. Isto é útil para encontrar rapidamente aqueles exemplos importantes que você pode usar em um relatório escrito.

## Selecção de atributos nos relatórios

O botão de seleção do atributo abre uma janela onde você pode selecionar atributos para arquivos e casos, por exemplo: apenas arquivos de entrevista para pessoas com > 60 anos. Além disso, as configurações de atributos podem ser salvas, carregadas e apagadas.

![Seleção de atributos](/images/8d349854-7e35-474b-8bba-119b23ed40b0.png)

## Matriz de codificação
Se você estiver criando um relatório e selecionando uma das opções da matriz, então o painel de resultados será dividido em dois painéis. O painel esquerdo mostra os dados codificados em uma lista, e o painel direito mostra uma matriz de linhas e colunas. Os tipos de colunas podem ser códigos, categorias ou categorias de nível superior.

Opções de matriz: ter códigos/categorias por arquivo ou por caso. A matriz pode ser transposta, usando a caixa de seleção.

Os painéis podem ser ampliados ou estreitados arrastando com o mouse na barra que divide cada seção.

Os relatórios podem ser exportados para arquivos de texto, OpenDocument (ODT), HTML ou csv.

![Matriz](/images/fdb2702e-350e-46fe-965a-42c3d8b6652b.png)

Quando os casos são selecionados, outro painel é exibido mostrando uma tabela de casos (em linhas) e categorias ou códigos em colunas

## Caixas de verificação

* Caixa de seleção para mostrar apenas segmentos codificados que foram marcados como importantes.
* Marque a caixa para adicionar estatísticas de resumo ao relatório.
* Caixa de seleção para contexto de texto para segmentos de texto codificados. Isto mostra os cercando 100 a 300 caracteres de texto (configurados em Configurações) para ajudar a colocar a seção codificada em contexto nos resultados. O segmento de texto codificado é mostrado em negrito.
* Marque a caixa para adicionar uma referência ao resultado codificado. Isto é, se uma referência tiver sido importada e vinculada ao arquivo específico.

### Relatórios de exportação

Relatórios podem ser exportados como html, odt, txt, csv, xlsx, (em 3.8+) iramuteq.

**txt** é um arquivo de texto simples

**csv** é um formato de planilha de texto simples

**xlsx** é uma planilha do Microsoft Word, contendo apenas texto.

**odt** é Open Document Text. Este é um formato que pode ser aberto com Microsoft Word ou LibreOffice Writer. Contém texto, cores e imagens. Por exemplo, se você tiver imagens codificadas.

**iramuteq** é uma opção de exportação de texto. Isto permite que o texto seja importado para [Iramuteq](https://pratinaud.gitpages.huma-num.fr/iramuteq-website/) software.

**html** é um formato de navegador web. Para texto simples haverá apenas um arquivo html, por exemplo, coding report.html. Se o seu código contém imagens, áudio ou vídeo, haverá uma pasta suplementar, por exemplo, pasta coding report. Esta pasta contém os arquivos de áudio, vídeo e imagem necessários para exibição html. Para transferir o html para outra pessoa, ou relocando dentro da sua estrutura de pastas, você deve mover ambos os html e a pasta associada, mostrada abaixo.

## Relatório de co-ocorrência do código

Este relatório mostra uma tabela de nomes de código ao longo dos eixos x e y. As células da tabela mostram a contagem de coocorrências codificantes. É aqui que dois códigos se sobrepõem ou se sobrepõem diretamente. Clique na célula para mostrar os detalhes da codificação de texto.

As opções incluem: selecionar arquivos de texto específicos, selecionar arquivos por atributos. Selecionar códigos específicos, ou selecionar categorias. Existe uma opção de exportação para Excel.

## Relatório sobre as relações com os códigos

Este diálogo mostra as relações entre dois ou mais códigos. Isto só pode ser aplicado a ficheiros de texto.
Selecione dois ou mais códigos e pressione o botão Calcular.
Este relatório pode ser útil para mostrar proximidade ou sobreposições entre códigos. Nota, outros relatórios como Co-ocorrência de Código e Texto de Código Correspondências Exatas também fazem isso. Este relatório dá um monte de detalhes finos, como as posições de caracteres de codificação para cada código.
Um arquivo csv pode ser exportado.

As relações são:

* Proximidade – Dois códigos não se sobrepõem. A distância em número de caracteres é mostrada.
* Sobreposição – Dois códigos sobrepõem-se parcialmente. As posições de caracteres mais baixas e mais altas da combinação são mostradas. A união das seções sobrepostas é mostrada em posições de caráter.
* Inclusão – Um código está incluído em outro código. As posições de caracteres mais baixas e mais altas da combinação são mostradas. A união das seções sobrepostas é mostrada em posições de caráter.
* Exatamente – Ambos os códigos correspondem em suas posições inicial e final. As posições de caracteres mais baixas e mais altas da combinação são mostradas. A união das seções sobrepostas é mostrada em posições de caráter.
