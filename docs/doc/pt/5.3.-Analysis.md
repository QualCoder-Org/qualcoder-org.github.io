# Opções do menu de Análise

* Recuperação de segmentos codificados (a principal função de relatório)
* Co-ocorrência de código - para arquivos de texto (conta e mostra onde um código é adjacente/sobreposto/correspondência exata a/de outro código)
* Relações de código - para arquivos de texto (mostra proximidade, correspondência exata, sobreposições, distância entre códigos selecionados)
* Correspondências exatas do texto do código - para arquivos de texto (mostra as contagens exatas de correspondências entre códigos)
* Códigos por segmentos de texto (mostra uma tabela de nomes de arquivos (linhas), texto codificado e códigos atribuídos - denotado por 1).
* Gráfico. Crie um mapa mental, de objetos e suas ligações.
* Análise assistida por IA - por tópico, por texto, por código.



## Recuperação de segmentos codificados {#code-retrieval}

Este relatório fornece uma lista, ou matriz, de dados codificados com base em suas seleções. Um ou mais códigos precisam ser selecionados. Se uma categoria for selecionada, todos os códigos dessa categoria também são selecionados. Várias categorias podem ser selecionadas usando o mouse e o botão ‘ctrl’.

O botão Pesquisar (Botão _Play_) apresentará os resultados.

![Relatórios de código Tela com resultados](/images/fc6a6750-1cfe-41c4-b905-1f589876e573.png)

Os resultados da codificação podem ser reduzidos usando os botões de seleção de arquivos, seleção de casos ou seleção de atributos. Somente serão apresentados códigos dentro dos arquivos ou casos selecionados. Quando as seleções de casos são usadas, as seleções de arquivos são ignoradas. Também quando as seleções de arquivos são usadas, as seleções de casos são ignoradas.

Se o texto for inserido no campo Buscar texto, serão apresentados apenas códigos que contenham o texto correspondente.
A busca de texto também procura por texto correspondente em memorandos para áreas de imagens codificadas e segmentos de áudio/vídeo codificados. A função de buscar texto deve ser usada em combinação com a seleção de arquivos, a seleção de casos ou a seleção de atributos.

## Texto, imagens, trechos codificados como Importante {#important-coded-text-images-segments}
Existe uma caixa de seleção para selecionar apenas os códigos importantes. Isso é útil para encontrar rapidamente aqueles exemplos importantes que você pode usar em um relatório escrito.

## Seleção de atributos nos relatórios {#attribute-selection-in-reports}
O botão de seleção do atributo abre uma janela onde você pode selecionar atributos para arquivos e casos, por exemplo: apenas arquivos de entrevista para pessoas com > 60 anos. Além disso, as configurações de atributos podem ser salvas, carregadas e apagadas.

![Seleção de atributos](/images/8d349854-7e35-474b-8bba-119b23ed40b0.png)

## Matriz de codificação {#coding-matrix}
Se você estiver criando um relatório e selecionando uma das opções da matriz, então o painel de resultados será dividido em dois painéis. O painel esquerdo mostra os dados codificados em uma lista, e o painel direito mostra uma matriz de linhas e colunas. Os tipos de colunas podem ser códigos, categorias ou categorias de nível superior.

Opções da matriz: ter códigos/categorias por arquivo ou por caso. A matriz pode ser transposta, usando a caixa de seleção.

Os painéis podem ser ampliados ou estreitados arrastando com o mouse na barra que divide cada seção.

Os relatórios podem ser exportados para arquivos de texto, OpenDocument (ODT), HTML ou csv.

![Matriz](/images/fdb2702e-350e-46fe-965a-42c3d8b6652b.png)[Matriz](/images/fdb2702e-350e-46fe-965a-42c3d8b6652b.png)

_Quando os casos são selecionados, outro painel é exibido mostrando uma tabela de casos (em linhas) e categorias ou códigos em colunas_

## Caixas de seleção {#check-boxes}

* Marque uma caixa para mostrar apenas segmentos codificados que foram marcados importantes.
* Marque uma caixa para adicionar estatísticas resumidas ao relatório.
* Há uma caixa de seleção para o contexto do texto dos trechos codificados de texto. Isto mostra os cercando 100 a 300 caracteres do texto (definido nas iConfigurações) para ajudar a colocar o trcho codificado em contexto nos resultados. O segmento de texto codificado é mostrado em negrito.
* Marque a caixa para adicionar uma referência ao resultado codificado. Isto se uma referência tiver sido importada e vinculada ao arquivo específico.

### Exportação de Relatórios {#exporting-reports}

Relatórios podem ser exportados como html, odt, txt, csv, xlsx, (em versões 3.8+) iramuteq.

**txt** é um arquivo de texto simples

**csv** é um formato de planilha de texto simples

**xlsx** é uma planilha do Microsoft Excel, contendo apenas texto.

**odt** é Open Document Text. Este é um formato que pode ser aberto com Microsoft Word ou LibreOffice Writer. Ele conterá texto, cores e imagens. Por exemplo, se você tiver imagens codificadas.

**iramuteq** é uma opção de exportação para o texto. Isto permite que o texto seja importado para o [Iramuteq](https://pratinaud.gitpages.huma-num.fr/iramuteq-website/).

**html** é um formato de navegador da web. Para texto simples, haverá apenas um arquivo html, por exemplo, `relatorio-de-codificação.html`. Se o seu código contém imagens, áudio ou vídeo, haverá uma pasta suplementar, por exemplo, a pasta `relatorio-de-codificação/`. Esta pasta contém os arquivos de áudio, vídeo e imagem necessários para exibição html. Para transferir o html para outra pessoa, ou relocando dentro da sua estrutura de pastas, você deve mover ambos os html e a pasta associada, mostrada abaixo.

## Relatório de co-ocorrência do código {#code-co-occurrence-report}

Este relatório mostra uma tabela dos nomes de código ao longo dos eixos x e y. As células da tabela mostram a contagem de co-ocorrências de codificação. É aqui que dois códigos se sobrepõem ou são adjacente diretamente. Clique na célula para mostrar os detalhes da codificação de texto.

As opções incluem: selecionar arquivos de texto específicos, selecionar arquivos por atributos. Selecionar códigos específicos, ou selecionar categorias. Existe uma opção de exportação para Excel.

![img](/images/651895717-c043a401-d066-42ea-affa-912a935b5e60.png)

Clicar em uma célula mostra os detalhes do texto.

![image](/images/fadccf7b-d18b-44a9-8637-650ea3421f66.png)

Você pode clicar com o botão direito em uma célula contendo texto codificado co-ocorrente para fazer um novo código fundido que combina os dois códigos sobrepostos.

Exemplos de gráfico de co-ocorrência e gráfico de agrupamento.

## Relatório sobre as relações com os códigos {#code-relations-report}

Esta caixa de diálogo mostra as relações entre dois ou mais códigos. Isto só pode ser aplicado a arquivos de texto.
Selecione dois ou mais códigos e pressione o botão Calcular.
Este relatório pode ser útil para mostrar proximidade ou sobreposições entre códigos.
Note que outros relatórios como Co-ocorrência de Código e Correspondências Exatas de texto de Código também fazem isso. Este relatório dá um monte de detalhes finos, como as posições de caracteres de codificação para cada código.
Um arquivo csv pode ser exportado.

As relações são:

* Proximidade – Dois códigos não se sobrepõem. A distância em número de caracteres é mostrada.
* Sobreposição – Dois códigos sobrepõem-se parcialmente. As posições mais baixas e mais altas da combinação são mostradas. A união das seções sobrepostas é mostrada em posições de caráter.
* Inclusão – Um código é incluído em outro código. As posições mais baixas e mais altas da combinação são mostradas. A união das seções sobrepostas é mostrada em posições de caráter.
* Exatamente – Ambos os códigos correspondem em suas posições inicial e final. As posições mais baixas e mais altas da combinação são mostradas. A união das seções sobrepostas é mostrada em posições de caráter.
