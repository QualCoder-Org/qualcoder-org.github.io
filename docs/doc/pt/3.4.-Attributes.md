# Atributos

Atributos são variáveis associadas a arquivos, casos ou diários. Eles podem ser úteis para adicionar contexto ao interpretar sua análise. Abra a janela Gerenciar Atributos. Você pode adicionar, excluir, renomear e adicionar notas de memorando aos atributos. Você pode clicar com o botão direito em um atributo numérico para convertê-lo para Caracter, mas não de Caracter para Numérico.

As únicas opções para atributos são numéricps e caracteres. Não há opções para booleanos, data e hora ou tipos numéricos específicos, como inteiros. No entanto, se você estiver executando consultas SQL, via Relatórios > Consultas ao banco de dados, você pode precisar lançar (_cast_) o atributo numérico para um inteiro(_Integer_) ou Real, por exemplo, `cast(my_var as integer)`.

Atributos podem ser adicionados nas seções Gerenciar Atributos, Gerenciar Arquivos, Gerenciar Casos ou Gerenciar Diários clicando no botão _(x)_, mostrado abaixo. Atributos podem ser importados de uma pesquisa, e também de um arquivo de projeto REFI-QDA. Nota que a importação do projeto REFI-QDA não é garantida de ser bem-sucedidada.

Não é intenção do QualCoder realizar análises estatísticas dos atributos. Use _software_ estatístico como a linguagem [R](https://www.r-project.org/).

Atributos também podem ser adicionados ou excluídos usando a opção Gerenciar > Gerenciar Atributos:

![imagem](/images/513af5f1-a94e-4606-b4d0-54011a8607da.png)

Nesta área você pode excluir atributos. Mas mesmo que você possa excluir atributos de referência, recomendamos que você não faça isso, a menos que tenha certeza de que todas as suas referências não são necessárias. Estes são prefixados com `'Ref_'` e estão associados com referências importadas que ligam um arquivo a uma referência específica. Veja [Gerenciar Referências](3.5.-References#referências) para importar e vincular referências a arquivos.
