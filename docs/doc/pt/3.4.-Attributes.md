# Atributos

Atributos são variáveis associadas a arquivos, casos ou periódicos. Eles podem ser úteis para adicionar contexto ao interpretar sua análise. Abre a janela para Gerenciar Atributos. Você pode adicionar, excluir, renomear e adicionar notas de memorando aos atributos. Você pode clicar com o botão direito em um atributo numérico para converter para Caracter, mas não de Caracter para Numérica.

As únicas opções para atributos são numéricas e caracteres. Não há opções para booleanos, data ou hora ou tipos numéricos específicos, como inteiros. No entanto, se você estiver executando consultas SQL, via Relatórios > Consultas de banco de dados, você pode precisar lançar o atributo numérico para um Integer ou Real, por exemplo, cast(my var como inteiro).

Atributos podem ser adicionados nas seções Gerenciar Atributos, Gerenciar Arquivos, Gerenciar Casos ou Gerenciar Diários clicando no botão (x), mostrado abaixo. Atributos podem ser importados de uma pesquisa, e também de um arquivo de projeto REFI-QDA. Nota A importação do projeto REFI-QDA não é garantida para importar com sucesso.

Não é intenção da QualCoder realizar análises estatísticas dos atributos. Usar software estatístico como [R](https://www.r-project.org/).

Atributos também podem ser adicionados ou excluídos usando a opção Gerenciar > Gerenciar Atributos:

![imagem](/images/513af5f1-a94e-4606-b4d0-54011a8607da.png)

Nesta área você pode excluir atributos. Mas mesmo que você possa excluir atributos de referência, recomendamos que você não faça isso, a menos que tenha certeza de que todas as suas referências não são necessárias. Estes são prefixados com 'Ref ' e estão associados com referências importadas que ligam um arquivo a uma referência específica. Consulte Gerenciar Referências para importar e vincular referências a arquivos.
