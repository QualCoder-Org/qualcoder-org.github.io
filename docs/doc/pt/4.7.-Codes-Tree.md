#  Categorias e códigos

As categorias são utilizadas para organizar códigos. As categorias são organizadas hierarquicamente em uma estrutura de árvore. Você pode mover códigos para categorias e mover categorias para categorias maiores. Você pode mover categorias e códigos para fora de sua posição atual. Um código pode ter sub-códigos (novo na versão 4.0). Códigos e categorias podem ser mesclados através da introdução de um código em um código ou categoria em uma categoria. Clique com o botão direito em uma categoria ou código para renomear. Carregue com o botão direito num código para alterar a cor.

Categorias e códigos podem ser atribuídos memorandos. Os memorandos podem conter símbolos como aqueles [mostrado aqui](https://www.alt-codes.net//). Veja o link how-to para inseri-los - Laptop num lock on, segure a tecla Alt para baixo e digite o número usando o teclado número à direita.

!!! note
    A capacidade de atribuir um único código a várias categorias é uma característica frequentemente solicitada. No entanto, decidimos não implementar essa funcionalidade, pois seria excessivamente complicado. Isso é devido ao uso da estrutura de uma árvore pela QualCoder, enquanto o recurso solicitado requer [estrutura de dados do gráfico](https://www.baeldung.com/cs/tree-vs-graph-data-structure)Como alternativa, você pode usar códigos com nomes semelhantes em suas diferentes categorias.

## Redução da quantidade de códigos exibidos na árvore de códigos

Para reduzir o número de códigos mostrados na árvore de código. Nas janelas de codificação (texto de código, código, a/v ou imagem de código), clique com o botão direito na árvore de código e selecione  Mostrar códigos como  no menu, ou quando a árvore de códigos está em foco pressione F9.. Em seguida, digite texto na caixa de texto. Isto só mostrará códigos que contenham esse texto. Para mostrar todos os códigos novamente, digite nada na caixa de texto e pressione OK para mostrar todos os códigos.

Uma segunda opção é  Mostrar códigos de cor . Pressione a tecla F10 quando a árvore de códigos está em foco.

Outro botão sob a árvore de códigos - com um ícone de pesquisa - ao clicar irá procurar o primeiro código que contém o texto correspondente que você inserir.

## Opções do menu da árvore de códigos

Na árvore de códigos à esquerda, clicando com o botão direito em um código abre um menu de contexto para várias opções. Sub-menus incluem modificar um código ou categoria, filtragem e ordenação.

![imagem](/images/4adaa97e-da9c-45bf-88f3-8e0110edf638.png)

###  Mostrar os ficheiros codificados

Uma opção é Mostrar arquivos codificados - isso mostra em qualquer lugar que você tenha codificado com o código selecionado. Clicando em uma seção codificada em particular irá abrir esse código no contexto original para mais informações.

Com arquivos codificados show, você pode clicar com o botão direito na seção de cabeçalho colorido para mais opções, tais como adicionar mais códigos, remover o código e exportar todo o conjunto de segmentos codificados para um arquivo de texto.

![imagem](/images/7f0d079d-c0a8-4966-87bd-a6723f541d8d.png)

Ordenar a árvore de códigos em ascensão (chave F11 quando códigos em foco), ou descendente (chave F12 quando árvore em foco).

## Acessibilidade e cores de código

No menu de codificação existe uma opção chamada ** esquema de cores**.

Você pode aplicar uma gama de cores a uma gama de códigos selecionados, em vez de confiar nas cores geradas aleatoriamente ou uma de cada vez mudança de cores para cada código. Nesta área você também pode ver como as cores do código podem aparecer para alguém que tem uma variedade de cegueira de cor: vermelho-fraco, vermelho-cego, verde-fraco ou verde-cego.
