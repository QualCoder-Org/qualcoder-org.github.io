# KI-gestützte Codierung

## Einführung {#introduction}

Die integrierten KI-Funktionen von QualCoder ab Version 3.6 unterstützen das Codieren auf verschiedene Weise:

- **KI-Suche:** Die KI kann große Textmengen schnell analysieren und bestimmte Themen oder Konzepte in Ihrem Korpus finden und erkunden.
- **Nach Konzepten statt nach Schlüsselwörtern suchen:** QualCoder kombiniert semantische Suche mit großen Sprachmodellen wie GPT-4. Sie können daher auch abstrakte Konzepte wie „veränderte Geschlechterrollen“ oder „Anerkennung am Arbeitsplatz“ suchen, ohne genaue Schlüsselwörter vorzugeben.
- **Daten interaktiv interpretieren:** Die KI schlägt relevante Daten vor und liefert Interpretationen. Diese zusätzliche Perspektive kann Ihr Verständnis bereichern.
- **An Ihre Methode anpassen:** Steuern Sie die Analyse durch vorgegebene oder eigene Prompts.
- **Unterstütztes Codieren:** Anders als beim schlüsselwortbasierten [automatischen Codieren](4.1.-Coding-Text#auto-code) müssen Sie die Vorschläge der KI selbst prüfen.

KI-gestützte Codierung ist keine eigenständige Methode, sondern umfasst Techniken, die sich an verschiedene codebasierte Methoden anpassen lassen, von Grounded Theory bis zur Inhaltsanalyse oder thematischen Analyse. Ein praktisches Beispiel zeigt dieses [Video-Tutorial](https://www.youtube.com/watch?v=FrQyTOTJhCc).

## Voraussetzungen {#preconditions}

- Die KI muss aktiviert, vollständig geladen und für neue Anfragen bereit sein. Die Statusleiste zeigt ihren Zustand an.
- Beschreiben Sie im **Projekt-Memo** kurz Ihre Forschungsthemen, Fragen, Ziele und empirischen Daten. Dies wird dringend empfohlen: Die Angaben begleiten jeden Prompt und helfen der KI, gezieltere Ergebnisse zu liefern. Das Memo erreichen Sie über **Projekt > Projekt-Memo**.

## KI-gestützte Codierung starten {#start-ai-assisted-coding}

Die Funktion ist in den Arbeitsbereich zum Textcodieren integriert. Öffnen Sie **Codierung > KI-unterstütztes Kodieren** oder wählen Sie im bestehenden Textcodierbereich links den Reiter **KI Unterstützung**. Klicken Sie anschließend auf **KI-Suche starten**.

![Reiter für die KI-Unterstützung](/images/1eeca42f-2e4e-48a6-aca7-68e4b13df6c4.png)

Im nächsten Fenster legen Sie (1) den Suchgegenstand fest, (2) geben der KI eine Analyseanweisung und (3) setzen bei Bedarf Datenfilter.

![Dialog zur KI-Suche](/images/0d66baa1-6c60-423a-b4d6-742d387322dc.png)

### 1) Suchgegenstand: Code oder freies Thema {#1-what-to-search-for-code-vs-free-topic-search}

#### Codesuche {#code-search}

Verwenden Sie diese Option, um einen bestimmten Aspekt zu vertiefen und einem bestehenden Code weitere Daten aus dem gesamten Korpus hinzuzufügen.

- **Code oder Kategorie auswählen:** QualCoder übermittelt nicht nur den Codenamen, sondern den vollständigen Pfad im Codebaum, etwa „Arbeit > Bedeutungen von Arbeit > Arbeit als Notwendigkeit“.
- **Memo an die KI senden:** Wenn aktiviert, wird auch das Code-Memo übermittelt. Beschreiben oder definieren Sie darin den Code, um bessere Ergebnisse zu erhalten. Persönliche Notizen können Sie unter einer Zeile mit `#####` ergänzen; dieser Teil wird nicht an die KI gesendet.
- **Codierte Segmente einschließen:** Standardmäßig ist diese Option deaktiviert. Die Suche liefert dann nur Daten, die noch nicht mit diesem Code codiert sind. Aktivieren Sie sie, wenn auch bereits codierte Daten berücksichtigt werden sollen.

#### Freie Themensuche {#free-topic-search}

Suchen Sie im gesamten Korpus nach einem Thema, Phänomen oder Konzept ohne vorgegebenen Code. Geben Sie einen Namen und eine Beschreibung ein, um der KI mitzuteilen, wonach Sie suchen.

### 2) Analyseanweisung: Der analytische Prompt {#2-how-to-analyse-the-data-the-analytic-prompt-for-the-ai}

Der analytische Prompt legt fest, wie die KI Ihre Daten untersuchen soll. Wählen Sie ihn unten links im Fenster aus.

![Analytischen Prompt auswählen](/images/83ab0d49-782d-420d-8088-9dec78e3e28e.png)

**QualCoder bietet Prompts für unterschiedliche Analyseansätze.** Eine offene Suche kann breit, interpretativ und einschließend vorgehen. Der Prompt für die Inhaltsanalyse orientiert sich stärker an den vorab im Code-Memo festgelegten Codierregeln.

Bewegen Sie die Maus über die Einträge der Auswahlliste, um die Prompts kennenzulernen. Über die Bearbeitungsschaltfläche können Sie [Prompts ändern oder eigene erstellen](6.3.-AI-Prompt-Library); dies ist eine erweiterte Option.

### 3) Filter: Die Suche eingrenzen {#3-filter-narrow-your-search-down}

Standardmäßig wird der gesamte Textkorpus des aktuellen Projekts durchsucht. Rechts im Fenster können Sie bestimmte **Dokumente** oder **Fälle** auswählen; mit **Strg+Klick** wählen Sie mehrere aus. Sie können auch anhand von **Attributvariablen** filtern.

## Ablauf der KI-gestützten Codierung {#the-process-of-ai-assisted-coding}

Starten Sie zuerst die KI-Suche. Sie verläuft in zwei Schritten:

1. Die KI sucht in ihrer lokalen Datenbank nach möglicherweise relevanten Passagen Ihres Korpus.
2. Diese Daten werden an das große Sprachmodell gesendet und anhand des gewählten Prompts genauer analysiert.

Bis zu den ersten Ergebnissen kann einige Zeit vergehen. Ein Klick auf einen Treffer lädt das Dokument im Hauptbereich und markiert das zugehörige Zitat. Lesen Sie auch den umgebenden Text, um den Kontext zu verstehen.

### Die Ergebnisse bearbeiten {#working-through-the-results}

Sie können den **ausgewählten Text wie gewohnt codieren**, wie unter [Text codieren](4.1.-Coding-Text) beschrieben. Erweitern oder verändern Sie die Auswahl bei Bedarf.

Die **Interpretation der KI** erscheint als Hinweisfenster, wenn Sie die Maus über einen Treffer in der linken Liste bewegen. Wenn Sie die Passage codieren, können Sie diese Interpretation als Memo zur Codierung übernehmen.

![Interpretation der KI](/images/83e4e641-1e9d-4b2c-b80d-6c6e5b7c2e97.png)

Am **Ende der Liste** erscheint häufig ein Link zum Suchen weiterer Ergebnisse. Dann stehen noch Daten aus dem ersten Suchschritt zur genaueren Analyse bereit. Ein Klick untersucht die nächsten zehn Passagen.

QualCoder sortiert die Treffer nach geschätzter Relevanz. Dieser Algorithmus ist nicht perfekt; auch weiter unten können interessante Passagen stehen.

Mit der Zeit entfernen sich die Treffer meist zunehmend vom ursprünglichen Thema. Wenn sie kaum noch relevant sind, können Sie die Suche beenden und zum nächsten Thema oder Code wechseln. Sie müssen nicht alle im ersten Schritt gefundenen Daten analysieren lassen – ebenso wenig, wie Sie bei einer Websuche jede Ergebnisseite lesen müssen.

### Wenn keine Ergebnisse erscheinen {#what-to-do-if-you-get-no-results}

1. **Schon der erste Schritt findet keine möglicherweise relevanten Daten:** Die Codesuche berücksichtigt standardmäßig nur neue Daten. Wenn Ihr Korpus bereits gründlich codiert ist, gibt es möglicherweise nichts Neues. Prüfen Sie außerdem, ob der Code- oder Themenname zu spezifisch oder unklar formuliert ist.
2. **Der zweite Schritt liefert keine Treffer:** Lassen Sie, sofern verfügbar, weitere Ergebnisse analysieren. Bleiben auch diese aus, beginnen Sie eine neue Suche mit einem offeneren Prompt.

Keine, sehr wenige oder überwiegend irrelevante Treffer deuten darauf hin, dass ein Thema in Ihren Daten wenig ausgeprägt ist. Dennoch ist nicht garantiert, dass die KI alle zu einem Code oder Thema passenden Passagen findet.
