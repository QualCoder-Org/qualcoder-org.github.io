# Bilder codieren

Bilder lassen sich ähnlich wie Texte codieren. Wählen Sie einen Code und ziehen Sie mit gedrückter linker Maustaste ein Rechteck um den gewünschten Bereich. Im Kontextmenü können Sie die Codierung entfernen oder ein Memo hinzufügen. Unten befindet sich ein Schieberegler für die Bildgröße. Codierte Rechtecke haben die Farbe des zugewiesenen Codes. Per Rechtsklick auf das Bild öffnen Sie Optionen zum Drehen.

Oben rechts werden zum angeklickten codierten Bereich der Codename, die Pixelpositionen und sein Anteil an der gesamten Bildfläche angezeigt. Wenn Sie die Maus darüber bewegen, erscheint das zugehörige Memo.

## Wichtige codierte Bereiche {#important-coded-areas}

Besonders aussagekräftige Bereiche, etwa Beispiele für einen Bericht, können Sie im Kontextmenü als **Wichtig** markieren. Die Sternschaltfläche oben wechselt zwischen allen codierten Bereichen und den als wichtig markierten Bereichen.

## Tastenkürzel {#shortcuts}

- **H** im Bildbereich blendet die oberen Bedienelemente aus oder wieder ein.
- **L** filtert den Codebaum anhand von Namen.
- **+** und **−** vergrößern beziehungsweise verkleinern das Bild.
- **Strg+Z** stellt den zuletzt entfernten codierten Bereich wieder her.

## Schaltflächen unter der Dateiliste {#convenience-buttons-underneath-the-files-list}

- Nächste Datei laden
- Zuletzt codierte Datei laden
- Memo der ausgewählten Datei öffnen
- Dateien anhand von Attributen oder Fallzuordnungen filtern; die Schaltfläche zeigt ein Etikettensymbol

## Weitere Optionen im Bildkontextmenü {#right-click-on-the-image-area-for-more-options}

Per Rechtsklick können Sie das Bild drehen oder einen bestimmten Code beziehungsweise codierten Bereich hervorheben. Die Optionen umfassen Ausgrauen, Weichzeichnen und Solarisieren. Das Ergebnis wird im Standardprogramm zur Bildanzeige geöffnet und kann dort gespeichert werden.

Mit der Schaltfläche für Beschriftungen ergänzen Sie die ausgewählten codierten Bereiche: Ein Klick zeigt die Codenamen, ein weiterer die Memos und ein dritter schaltet die Beschriftungen aus.

Beispiel für hervorgehobene codierte Bereiche mit Beschriftungen:

![Hervorgehobene Bereiche mit Beschriftungen](/images/be991d7a-363b-4e5a-a93a-d02ccde42930.png)

## Export {#export}

Ein codiertes Bild kann als HTML-Datei exportiert werden. Im Browser erscheinen Codenamen und Memos, wenn Sie die Maus über die codierten Bereiche bewegen.
