# Importe und Exporte

Die meisten Import- und Exportfunktionen finden Sie im Menü **Projekt**.

![Import- und Exportmenü](/images/gh-c2551513-0bb0-437b-9b24-002b357bcbe1.png)

Projekte und Codebücher lassen sich nach dem REFI-QDA-Standard exportieren. Codebücher können auch als ODT oder reine Textdatei ausgegeben werden.

![Exportoptionen](/images/gh-d2d1f30f-4058-4533-a568-b814a1b72e82.png)

Umfragen importieren Sie über eine Schaltfläche in **Dateien verwalten**; siehe [Umfragen importieren](6.2.-Survey-Imports).

## Codebuch exportieren {#codebook-export}

Die Funktion finden Sie unter **Projekt > Exporte**. Ein Codebuch ist eine Liste Ihrer Codes. Im Memo jedes Codes sollten dessen Zweck und Anwendungsregeln erläutert werden. Der Textexport zeigt auch die Häufigkeit jedes Codes über alle Coder:innen hinweg. Doppelte Minuszeichen kennzeichnen untergeordnete Codes und Kategorien in der Baumstruktur.

## Codebuch importieren {#codebook-import}

Sie können ein Codebuch als reine Textdatei (`.txt`) oder CSV-Datei importieren. Zwei Größer-als-Zeichen `>>` trennen Kategorien und Codes. Drei Größer-als-Zeichen `>>>` kennzeichnen einen Untercode eines Codes.

### Import aus einer Textdatei {#codebook-plain-text-import}

Erstellen Sie eine reine Textdatei. Trennen Sie ein optionales Memo durch einen Tabulator vom Code:

```
Code1

Kategorie1>>Kategorie2>>Code2	Memo

Kategorie1>>Code3

Kategorie3>>Code4

Code5>>>Code6>>>Code7
```

### Import aus einer CSV-Datei {#codebook-csv-file}

Erstellen Sie die CSV-Datei in LibreOffice Calc oder Microsoft Excel. Die erste Spalte enthält Kategorien und Codes im selben Format wie die Textdatei. Code-Memos stehen in der zweiten Spalte.

```
Code1

Kategorie1>>Kategorie2>>Code2

Kategorie3>>Code3
```

## REFI-QDA {#refi-qda}

Die [Rotterdam Exchange Format Initiative (REFI)](https://www.qdasoftware.org) definiert einen offenen Standard für den Austausch von Codebüchern und Projekten zwischen Programmen zur qualitativen Datenanalyse.

QualCoder importiert und exportiert Codebücher in der Version `urn:QDA-XML:codebook:1.0`.

Projektimport und -export sind verfügbar. **Eine vollständige Einhaltung des REFI-QDA-Standards wird nicht garantiert.** Es wurden einzelne Tests mit NVivo, ATLAS.ti, Quirkos und MAXQDA durchgeführt. MAXQDA scheint beim Textimport ein zusätzliches Zeilenendezeichen zu benötigen; dafür bietet QualCoder beim Export eine Option. Beim Import in ATLAS.ti verschoben sich Codierungen nach jedem Zeilenende um ein Zeichen; dieses Problem ist noch ungelöst. Der Attributimport aus QualCoder funktionierte bei ATLAS.ti und MAXQDA nicht; Quirkos übernahm keine Fallattribute.

Funktionen wie Sets und Graphen werden bei diesem Austausch nicht importiert. Weitere Datentypen bleiben nicht erhalten: Datums- und Wahrheitswerte werden beispielsweise in Text umgewandelt.

Der Import von Audio/Video-Transkripten und Synchronisationspunkten sowie von relativ verknüpften Dateien wurde nicht getestet.

Schließen Sie vor dem Import ein geöffnetes Projekt. Wählen Sie einen Namen für das neue QualCoder-Projekt und anschließend die QDPX-Datei.

Wenn keine Codierungen sichtbar sind, wechseln Sie gegebenenfalls in den Einstellungen die aktuelle Coder:in über die Namensauswahl.

Ein älterer Test vom Februar 2021 untersuchte den Import eines von QualCoder erzeugten Projekts in MAXQDA, Quirkos und ATLAS.ti, beschränkt auf Texte und Bilder. Die Ergebnisse finden Sie in diesem [PDF zum REFI-QDA-Projektaustausch](https://qualcoder.files.wordpress.com/2021/02/refi-qda-project-import-quirkos-maxqda-atlas.pdf).

## Taguette importieren {#taguette-import}

Projekte aus [Taguette](https://www.taguette.org/) können aus der SQLite-Datei importiert werden. Die wesentlichen Codierungsdaten werden übertragen.

Schließen Sie ein geöffnetes Projekt und wählen Sie im Menü **Projekt** den Taguette-Projektimport. Geben Sie einen Namen für das neue Projekt ein und wählen Sie die Taguette-Datei, gewöhnlich mit der Endung `.sqlite3`. QualCoder importiert anschließend die Daten.

Falls keine Codierungen angezeigt werden, wechseln Sie gegebenenfalls in den Einstellungen die aktuelle Coder:in.

## Sonal π (Sonal Pi) importieren {#sonal-sonal-pi-import}

Projekte aus [Sonal Pi](https://www.sonal-info.com), einer in Frankreich entwickelten Software für qualitative Datenanalyse, können importiert werden. Wählen Sie dazu die Sonal-Korpusdatei aus.

## RQDA importieren {#rqda-import}

Projekte aus [RQDA](http://rqda.r-forge.r-project.org/) können direkt importiert werden. Alle Daten außer Dateikategorien werden übernommen.

Schließen Sie ein geöffnetes Projekt und wählen Sie im Menü **Projekt** den RQDA-Projektimport. Legen Sie einen Namen für das neue Projekt fest und wählen Sie die RQDA-Projektdatei. Anschließend importiert QualCoder die Daten.

Falls keine Codierungen angezeigt werden, wechseln Sie gegebenenfalls in den Einstellungen die aktuelle Coder:in.

## Hilfe > Besondere Funktionen {#help-special-functions}

### Textinhalte dynamisch aktualisieren {#dynamic-update-text-content}

Diese Funktion aktualisiert Textdateien, die sich im Laufe der Zeit ändern, etwa Auszüge aus Blogbeiträgen, und versucht dabei, vorhandene Codierungen zu erhalten. Wählen Sie die zu ersetzende Textdatei und anschließend die neue Datei aus. Starten Sie die Aktualisierung über die Zahnrad-Schaltfläche. Die Funktion sucht nach identischen Textpassagen in der Ersatzdatei. Dabei können fehlerhafte codierte Segmente entstehen.
