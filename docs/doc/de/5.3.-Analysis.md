# Funktionen im Menü Analyse

- **Code-Retrieval:** Die zentrale Funktion zur Zusammenstellung codierter Daten.
- **Kookkurrenz von Codes:** Zählt für Textdateien, wie häufig Codes aneinandergrenzen, sich überlappen oder dieselbe Passage umfassen.
- **Code-Beziehungen:** Zeigt Nähe, Übereinstimmung, Überlappung und Abstand ausgewählter Codes in Textdateien.
- **Exakte Textübereinstimmungen:** Zeigt übereinstimmende Textcodierungen verschiedener Codes.
- **Codes nach Textsegmenten:** Tabelle mit Dateinamen, codierten Texten und zugewiesenen Codes.
- **Graph:** Eine Mindmap mit Objekten und ihren Verbindungen erstellen.
- **KI-gestützte Analyse:** Nach Thema, Text oder Code analysieren.

## Code-Retrieval {#code-retrieval}

Dieser Bericht stellt codierte Daten anhand Ihrer Auswahl als Liste oder Matrix zusammen. Wählen Sie mindestens einen Code. Bei Auswahl einer Kategorie werden alle enthaltenen Codes mit ausgewählt. Mit **Strg+Klick** können Sie mehrere Kategorien auswählen. Die Suchschaltfläche mit dem Wiedergabesymbol zeigt die Ergebnisse an.

![Code-Retrieval mit Ergebnissen](/images/fc6a6750-1cfe-41c4-b905-1f589876e573.png)

Über die Schaltflächen für Dateien, Fälle oder Attribute können Sie die Ergebnisse eingrenzen. Es erscheinen nur Codierungen innerhalb der ausgewählten Dateien oder Fälle. Dateiauswahl und Fallauswahl werden alternativ verwendet: Bei ausgewählten Fällen wird die Dateiauswahl ignoriert und umgekehrt.

Geben Sie einen Text in das Suchfeld ein, erscheinen nur Codierungen mit passenden Textstellen. Die Suche berücksichtigt auch Memos zu codierten Bildbereichen und Audio/Video-Segmenten. Verwenden Sie die Textsuche zusammen mit einer Datei-, Fall- oder Attributauswahl.

## Wichtige Texte, Bilder und Segmente {#important-coded-text-images-segments}

Mit der entsprechenden Option zeigen Sie nur als **Wichtig** markierte Codierungen an. So finden Sie schnell aussagekräftige Beispiele für einen schriftlichen Bericht.

## Attribute für Berichte auswählen {#attribute-selection-in-reports}

Die Attributauswahl öffnet einen Dialog für Datei- und Fallattribute, etwa zur Auswahl von Interviewdateien mit Personen über 60 Jahren. Attributfilter lassen sich speichern, laden und löschen.

![Attributauswahl](/images/8d349854-7e35-474b-8bba-119b23ed40b0.png)

## Codierungsmatrix {#coding-matrix}

Bei einer Matrixoption teilt sich der Ergebnisbereich: Links stehen die codierten Daten als Liste, rechts eine Matrix. Spalten können Codes, Kategorien oder Kategorien der obersten Ebene darstellen. Zeilen beziehen sich auf Dateien oder Fälle. Mit einer Option können Sie die Matrix transponieren.

Die Größe der Bereiche verändern Sie durch Ziehen der Trennlinie. Berichte lassen sich als Text, ODT, HTML oder CSV exportieren.

![Codierungsmatrix](/images/fdb2702e-350e-46fe-965a-42c3d8b6652b.png)

Bei ausgewählten Fällen erscheint ein weiterer Bereich mit Fällen in den Zeilen und Kategorien oder Codes in den Spalten.

## Anzeigeoptionen {#check-boxes}

- Nur als wichtig markierte codierte Segmente anzeigen
- Zusammenfassende Statistiken ergänzen
- Textkontext anzeigen: 100 bis 300 umgebende Zeichen, je nach Einstellung; das codierte Segment erscheint fett
- Literaturangabe hinzufügen, sofern diese importiert und mit der Datei verknüpft ist

## Weitere Funktionen {#other-functions}

Mit **H** blenden Sie die oberen Bedienelemente aus oder wieder ein.

### Memos {#memos}

Eine Auswahlliste steuert, ob keine Memos, bestimmte Arten von Memos oder die Annotierungen der ausgewählten Textdateien angezeigt werden.

Im Kontextmenü einer Codeüberschrift im Bericht können Sie das Segment im Kontext ansehen, die Codierung entfernen oder den Code ändern.

![Kontextmenü im Bericht](/images/a6d29ccf-2d9f-4faf-a1a6-5aaf3498e9a9.png)

### Berichte exportieren {#exporting-reports}

Verfügbare Formate sind HTML, ODT, TXT, CSV, XLSX und ab Version 3.8 Iramuteq:

- **TXT:** Reine Textdatei.
- **CSV:** Tabellenformat als reine Textdatei.
- **XLSX:** Excel-Tabelle mit Textinhalten.
- **ODT:** OpenDocument-Textdatei für Microsoft Word oder LibreOffice Writer mit Text, Farben und gegebenenfalls codierten Bildern.
- **Iramuteq:** Textexport zur Weiterverarbeitung in [Iramuteq](https://pratinaud.gitpages.huma-num.fr/iramuteq-website/).
- **HTML:** Darstellung im Webbrowser. Bei reinen Textberichten entsteht nur eine HTML-Datei, etwa `coding_report.html`. Bei Bildern oder Audio/Video wird zusätzlich ein Ordner wie `coding_report` mit den Mediendateien angelegt. Zum Weitergeben oder Verschieben müssen Sie **sowohl die HTML-Datei als auch den zugehörigen Ordner** übertragen.

![HTML-Bericht und Medienordner](/images/998a1792-38b1-489e-a459-200819bbbf73.png)

## Kookkurrenz von Codes {#code-co-occurrence-report}

Dieser Bericht zeigt eine Tabelle mit Codenamen auf beiden Achsen. Jede Zelle enthält die Anzahl der Kookkurrenzen, also der Überlappungen oder direkt aneinandergrenzenden Codierungen. Ein Klick auf eine Zelle zeigt die entsprechenden Textstellen.

Sie können Textdateien direkt oder anhand von Attributen auswählen und die Codes beziehungsweise Kategorien eingrenzen. Ein Excel-Export ist möglich.

![Kookkurrenztabelle](/images/651895717-c043a401-d066-42ea-affa-912a935b5e60.png)

Ein Klick auf eine Zelle zeigt die Textdetails:

![Textdetails einer Kookkurrenz](/images/fadccf7b-d18b-44a9-8637-650ea3421f66.png)

Über das Kontextmenü einer Zelle mit überlappenden Textcodierungen können Sie einen neuen Code erstellen, der beide Codes kombiniert.

Beispiele für einen Kookkurrenzgraphen und einen Clustergraphen:

![Kookkurrenz- und Clustergraph](/images/651896887-02b544ba-31f7-4ac8-b0f6-b6c017fd418d.png)

## Beziehungen zwischen Codes {#code-relations-report}

Dieser Bericht untersucht Beziehungen zwischen mindestens zwei Codes und ist nur für Textdateien verfügbar. Wählen Sie die Codes und starten Sie die Berechnung. Anders als die Berichte zu Kookkurrenz und exakten Textübereinstimmungen liefert er detaillierte Angaben, etwa die Zeichenpositionen jeder Codierung. Ein CSV-Export ist möglich.

Die Beziehungen sind:

- **Nähe:** Die Segmente überlappen sich nicht. Ihr Abstand wird in Zeichen angegeben.
- **Überlappung:** Die Segmente überlappen sich teilweise. Die äußeren Grenzen und die Positionen des gemeinsamen Bereichs werden angegeben.
- **Enthaltensein:** Ein Segment liegt vollständig im anderen. Die äußeren Grenzen und der gemeinsame Bereich werden angegeben.
- **Exakte Übereinstimmung:** Start- und Endposition beider Segmente stimmen überein. Die Grenzen und der gemeinsame Bereich werden angegeben.

![Tabelle der Code-Beziehungen](/images/ef6e5e65-3681-4557-bcff-12255aa8c70d.png)

Zusammenfassende Statistiken und Boxplots können erstellt werden.

![Statistiken und Boxplots](/images/a04d7b62-506b-4f05-ba62-5394e5f09748.png)

## Exakte Textübereinstimmungen {#code-text-by-exact-matches-report}

Dieser Bericht zeigt Textsegmente, denen verschiedene Codes mit exakt denselben Grenzen zugewiesen wurden. Wählen Sie Textdokumente und mindestens zwei Codes aus.

![Exakte Textübereinstimmungen](/images/284f388e-f561-416e-accb-ec18ad509944.png)

## Codes nach Textsegmenten {#codes-by-text-segments-report}

Die Zeilen dieser Tabelle enthalten codierte Textsegmente, die Spalten zeigen die zugewiesenen Codes. Dies ist beispielsweise für Benutzer:innen im juristischen Bereich hilfreich, die alle Codes derselben Passage überblicken möchten. Ein Excel-Export ist möglich.
