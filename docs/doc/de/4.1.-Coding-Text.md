# Text codieren

Wählen Sie im Menü **Codierung > Text codieren**. Wenn Sie mit der Maus über ein codiertes Segment fahren oder darauf klicken, wird der Codename angezeigt.

![Text codieren](/images/6f26284e-0802-4bd8-a75d-6b0e6562901c.png)

Codierte Texte können durch Unterstreichungen oder farbige Hervorhebungen gekennzeichnet werden:

![Darstellung der Codierungen](/images/50bb8b05-73e9-41d8-9844-1ada6378d8a7.png)

![Hervorgehobener Text](/images/750bb5f3-5c81-493a-a4ee-85a94874070b.png)

**Eine Datei auswählen:** Wählen Sie oben links eine Datei aus. Die Schaltflächen darunter wechseln zur nächsten Datei, zur zuletzt codierten Datei oder zu einem Lesezeichen. Außerdem können Sie das Datei-Memo öffnen oder die Dateiliste anhand von Attributen filtern. Weitere Optionen, darunter die Sortierung, stehen im Kontextmenü bereit.

**Einen Code erstellen:** Öffnen Sie im unteren linken Bereich das Kontextmenü. Dort können Sie einen neuen Code anlegen. Über das Kontextmenü eines Codes ändern Sie dessen Farbe. Die Schaltfläche mit der Farbpalette im oberen Bereich legt eine gemeinsame Farbe für alle neu angelegten Codes fest; andernfalls werden Farben zufällig zugewiesen.

Das Kontextmenü bietet außerdem Optionen zum Hinzufügen von Code-Memos, Löschen und Umbenennen von Codes, Anlegen von Codes und Kategorien, Filtern nach Namen, Verschieben von Codes oder Kategorien und Sortieren.

**Text codieren:** Markieren Sie eine Passage und klicken Sie mit der linken Maustaste auf einen Code im Codebaum. Alternativ öffnen Sie nach dem Markieren das Kontextmenü und wählen den aktuellen Code, einen zuletzt verwendeten Code, einen neuen Code oder eine In-vivo-Codierung.

Beim Bewegen der Maus über codierten Text werden der Code und vorhandene Memos angezeigt. Um eine Codierung zu entfernen, klicken Sie auf das Segment und verwenden die Schaltfläche zum Entfernen der Markierung.

Ein Memo zu einem codierten Segment fügen Sie über das Kontextmenü, die Taste **M** oder die rechte Schaltfläche mit Notizblock und Stift hinzu. Codierter Text mit einem Memo wird kursiv dargestellt.

Besonders aussagekräftige Passagen, etwa Beispiele für einen Bericht, können Sie im Kontextmenü als **Wichtig** kennzeichnen. Die Sternschaltfläche unter dem Codebaum wechselt zwischen allen Codierungen und den als wichtig markierten Codierungen.

**Überlappende Codes:** Überlappungen werden unterstrichen. Beim Bewegen der Maus darüber werden die beteiligten Codierungen angezeigt. Klicken Sie in die Überlappung und drücken Sie **O**, um zwischen den Codes an dieser Stelle zu wechseln.

## Annotierungen {#annotations}

Eine Annotierung ist eine Notiz zu einer ausgewählten Textpassage, beispielsweise zur Erklärung von Abkürzungen oder Fachbegriffen. Annotierte Stellen erscheinen fett. Zum erneuten Öffnen wählen Sie einen Teil der fett gedruckten Passage und dann **Annotieren** im Kontextmenü. Alternativ verwenden Sie die linke Schaltfläche mit Notizblock und Stift oder die Taste **A**. Um eine Annotierung zu entfernen, öffnen Sie sie und löschen ihren gesamten Inhalt.

![Annotierung](/images/104526a8-1bba-4dae-8bcd-43d2ddc5f9c8.png)

## Automatisch kodieren {#auto-code}

Oben rechts stehen Schaltflächen zum automatischen Codieren bereit:

![Schaltflächen zum automatischen Codieren](/images/d689c833-505f-49e4-938c-e392d4a2cc14.png)

Sie können:

- exakte Texttreffer automatisch codieren; ein zusätzlicher Dialog fragt nach den zu bearbeitenden Dateien,
- ganze Sätze anhand eines Textfragments automatisch codieren; auch hier wählen Sie die Dateien aus,
- die aktuelle Datei anhand von Start- und Endmarkierungen codieren; `\n` steht für einen Zeilenumbruch, und die Startmarkierung gehört zum codierten Bereich,
- den letzten automatischen Codiervorgang rückgängig machen,
- reguläre Ausdrücke (**Regex**) aktivieren, um mit Platzhaltern und anderen Mustern flexibler zu suchen; siehe diese [Regex-Übersicht](https://techearl.com/regex-cheat-sheet).

Beim automatischen Codieren wird die Groß-/Kleinschreibung beachtet. Für die Satzcodierung müssen Sie das Satzende definieren; voreingestellt sind ein Punkt und ein Leerzeichen. Auch `\n` kann als Zeilenumbruch verwendet werden.

Bei exakten Treffern können Sie mehrere Suchbegriffe durch `|` trennen. Beispielsweise ordnet `politics|politicians` beide Begriffe demselben Code zu. Dies gilt nur für exakte Texttreffer. Die Rückgängig-Funktion für automatische Codierungen geht verloren, wenn Sie das Projekt schließen und erneut öffnen.

Die Schaltflächen für exakte Treffer und Textfragmente bieten weitere Optionen im Kontextmenü. Standardmäßig werden alle Treffer codiert. Sie können stattdessen nur den ersten oder letzten Treffer eines Dokuments codieren oder die Suche auf Bereiche innerhalb eines anderen Codes beschränken, etwa auf die Redebeiträge einer bestimmten Sprecher:in. Beide Funktionen fragen nach den zu bearbeitenden Dateien. Die Rückgängig-Schaltfläche entfernt die zuletzt automatisch hinzugefügten Codierungen.

**Emojis und Emoticons:** Ein sichtbares Emoji kann intern mehr als eine Zeichenposition belegen. Dadurch können beim automatischen Codieren die Positionen verschoben werden. Im folgenden Beispiel betrifft dies die Codierung des Wortes „music“:

![Positionsverschiebung durch Emojis](/images/8ac5bcf5-fae4-4da3-a1dd-8dccf12d585b.png)

## Redebeiträge automatisch codieren {#auto-speaker-codings}

**Sprecher:innen markieren** legt für jede Sprecher:in eines Interviews oder einer Gruppendiskussion einen Code an und ordnet die Redebeiträge automatisch zu. Damit können Sie Berichte auf bestimmte Sprecher:innen beschränken. Die Funktion ist über das Dateikontextmenü oder diese Schaltfläche verfügbar:

![Sprecher:innen markieren](/images/645f0a43-4814-466e-a8a0-10758b910bb0.png)

- Der Name muss am Anfang einer neuen Zeile stehen und kürzer als 64 Zeichen sein. Erkannt werden `Name:`, `{Name}` und `[Name]`.
- Sie können auswählen, welche Namen übernommen werden, und die Bezeichnungen bearbeiten.

![Namen auswählen](/images/67c14d0f-2c9a-4e99-8907-9c16a32b6285.png)

- Jede Sprecher:in erhält einen Code in der besonderen Kategorie **📌 Sprecher:innen** ganz unten im Codebaum. Standardmäßig werden unauffällige Grautöne verwendet.
- Um diese Codierungen bei der eigenen Analyse auszublenden, klicken Sie oben links neben dem Namen der Coder:in auf **…**. Setzen Sie im Dialog den Eintrag **📌 Sprecher:innen-Codierung** auf ausgeblendet.
- Die Funktion steht auch unter **Dateien verwalten** bereit.

## Mehr Platz für den Text {#maximise-screen-area}

Klicken Sie in den Text und drücken Sie **H**, um die oberen Bedienelemente auszublenden. Erneutes Drücken blendet sie wieder ein.

## Schnell zwischen Dateien wechseln {#convenience-methods-for-loading-text-files-in-the-files-list-pane}

Bei umfangreichen Projekten können Sie über das Kontextmenü der Dateiliste schnell die alphabetisch nächste Datei, die zuletzt codierte Datei oder die Datei mit dem Lesezeichen öffnen.

Ein Lesezeichen setzen Sie über das Kontextmenü im Text. Es gilt jeweils nur für ein Projekt. Nach dem Wechsel zu einem anderen Projekt kann es deshalb an eine falsche Stelle führen oder nicht funktionieren.

### Schaltflächen unter der Dateiliste {#convenience-buttons-underneath-the-files-list}

- Nächste Datei laden
- Zuletzt codierte Datei laden
- Zum aktuellen Lesezeichen wechseln
- Memo der ausgewählten Datei öffnen
- Dateien anhand von Attributen oder Fallzuordnungen filtern

![Dateifilter](/images/b3c32938-c1df-455c-be3e-3753c813535c.png)

## Grenzen codierter Segmente ändern {#modifying-code-positions}

Wählen Sie im Kontextmenü einer Codierung die Option zur Größenänderung. Die Griffe an beiden Enden des Segments lassen sich verschieben.

![Segmentgrenzen ändern](/images/8b9e09f0-03e0-4ad1-8042-f7aa5ce12b31.png)

Alternativ klicken Sie auf ein codiertes Segment, das an dieser Stelle nicht mit einem anderen Code überlappt, und verwenden:

| Tastenkürzel | Funktion |
| --- | --- |
| Umschalt+Pfeil links | Segment nach links erweitern |
| Umschalt+Pfeil rechts | Segment nach rechts erweitern |
| Alt+Pfeil links | Segment vom rechten Rand her verkürzen |
| Alt+Pfeil rechts | Segment vom linken Rand her verkürzen |

Sichern Sie das Projekt vor Textänderungen, falls sich Codierungspositionen falsch verschieben. Folgende Tasten können bei der Korrektur helfen:

- **#** zeigt die Position des angeklickten Zeichens an.
- **$** verschiebt die nachfolgenden Codierungspositionen um eine angegebene Zeichenzahl. Dies kann nötig sein, wenn Text hinzugefügt oder gelöscht wurde.

## Text suchen {#search-text}

Oben in der Mitte befindet sich die Textsuche mit den Optionen **Groß-/Kleinschreibung beachten** und **Alle Dateien**. Wenn Sie Text markieren und **S** drücken, wird die Auswahl in das Suchfeld übernommen und die Schaltfläche für den nächsten Treffer fokussiert.

Standardmäßig beginnt die Suche ab drei Zeichen. Über das Kontextmenü können Sie fünf Zeichen als Mindestlänge festlegen oder erst nach Drücken der Eingabetaste suchen lassen. **Alle Dateien** setzt die Suche in anderen Textdateien fort.

Die Suche unterstützt reguläre Ausdrücke:

- `.` steht für ein beliebiges Zeichen; `.ears` findet beispielsweise `bears` und `years`.
- `?` nach einem Zeichen macht dieses optional; `bears?` findet `bear` und `bears`.
- `*` erlaubt null oder mehr Wiederholungen des vorangehenden Zeichens.
- `\.` sucht einen Punkt, `\?` ein Fragezeichen und `\n` einen Zeilenumbruch. Weitere Beispiele bietet die [Regex-Kurzübersicht](https://www.rexegg.com/regex-quickstart.html).
- `\b` kennzeichnet eine Wortgrenze; `\bbound\b` findet das ganze Wort `bound`, aber nicht `boundary`.

## Durch die Segmente eines Codes navigieren {#moving-through-the-text-for-one-selected-code}

Unter dem Codebaum befinden sich Vorwärts- und Rückwärtspfeile sowie eine Schaltfläche mit einem Rastersymbol. Wählen Sie einen Code und verwenden Sie die Pfeile, um seine Segmente im aktuellen Dokument durchzugehen. Andere Codierungen werden ausgeblendet. Mit der nun farbigen Rasterschaltfläche zeigen Sie wieder alle Codes an.

!!! note
    Version 4.0 zeigt die gesamte Textdatei an. Frühere Versionen, etwa 3.8.2, konnten Texte in Abschnitten von 50.000 Zeichen laden. Wenn Sie diese Funktion benötigen, können Sie [Version 3.8.2](https://github.com/ccbogel/QualCoder/releases/tag/3.8.2) verwenden. Beachten Sie jedoch, dass sich die PDF-Textextraktion zwischen 3.8.2 und 4.0 geändert hat. Beim Öffnen neuerer Projekte in älteren Versionen können daher die Positionen codierter Segmente ungenau sein.

## Nur wichtige Codierungen anzeigen {#show-only-important-coded-text}

Die Sternschaltfläche unter dem Codebaum wechselt zwischen allen codierten Texten und den als **Wichtig** markierten Segmenten.

## Berichte exportieren {#export-reports}

Sie können Berichte als ODT exportieren, kompatibel mit LibreOffice und Microsoft Word. Codes erscheinen entweder als Hervorhebungen oder als Kommentare am Rand. Der Bericht enthält die verwendeten Codes, Häufigkeiten, Annotierungen, Memos und codierten Texte. Weitere Optionen sind reiner Text, HTML und ein Codebuch-Export.

## Rechter Seitenbereich {#right-hand-pane}

Am rechten Fensterrand befindet sich ein zunächst verborgener Bereich. Ziehen Sie ihn vom Rand aus auf oder verwenden Sie die Schaltfläche neben der Hilfe. Eine Schaltfläche zeigt zu einem angeklickten Code dessen Namen, Codierregel beziehungsweise Memo und zufällig ausgewählte codierte Textbeispiele aus dem Projekt. Die andere zeigt das Projekt-Memo.

## Text im Codierbereich bearbeiten {#editing-text-when-in-coding-code-text}

Auch bereits codierte, annotierte oder vollständig beziehungsweise teilweise einem Fall zugeordnete Texte können bearbeitet werden. Im Bearbeitungsmodus kennzeichnen Unterstreichungen die Zuordnungen **aller Coder:innen**: grün für Fälle, gelb für Annotierungen und rot für Codierungen.

!!! note
    Sichern Sie das Projekt vor der Bearbeitung eines bereits codierten Textes, falls Segmentpositionen falsch angepasst werden.

Im Bearbeitungsmodus wird die ganze Datei geladen; Codebaum, Dateiliste und andere Funktionen sind deaktiviert. Nicht unterstrichene Passagen können Sie problemlos auswählen, kopieren und ersetzen. Ohne Textauswahl können Sie an jeder Position Text eingeben, löschen oder einfügen; dabei verschieben sich die Unterstreichungen.

Vermeiden Sie es, ausgewählte Passagen zu löschen oder zu überschreiben, besonders wenn sie unterstrichene Bereiche enthalten. Die Positionen der Codierungen, Annotierungen und Fallzuordnungen könnten falsch angepasst werden.

Wenn eine Änderung die Zuordnungen beeinträchtigt hat, verlassen Sie den Bearbeitungsmodus und klicken Sie **vor jeder weiteren Aktion** auf den Rückgängig-Pfeil neben der Schaltfläche zur Textbearbeitung.

![Textbearbeitung rückgängig machen](/images/d9496b21-a494-433f-84a5-cbac8419449f.png)

!!! note
    Änderungen betreffen den Text in der Datenbank. Die ursprüngliche Textdatei wird nicht verändert.

![Text im Bearbeitungsmodus](/images/b02d740e-d561-4c3c-aff0-637d45740d03.png)
