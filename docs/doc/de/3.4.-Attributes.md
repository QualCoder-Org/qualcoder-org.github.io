# Attribute

Attribute sind Variablen, die Dateien, Fällen oder Notizbüchern zugeordnet werden. Sie können bei der Interpretation Ihrer Analyse zusätzlichen Kontext liefern. Unter **Attribute verwalten** können Sie Attribute hinzufügen, löschen, umbenennen und mit Memos versehen. Über das Kontextmenü lässt sich ein numerisches Attribut in ein Textattribut umwandeln; die umgekehrte Umwandlung ist nicht möglich.

Es stehen nur numerische Attribute und Textattribute zur Verfügung, keine eigenen Typen für Wahrheitswerte, Datum, Uhrzeit oder Ganzzahlen. Bei SQL-Abfragen über **Berichte > Datenbankabfragen** müssen Sie numerische Attribute gegebenenfalls in `Integer` oder `Real` umwandeln, etwa mit `cast(my_var as integer)`.

Sie können Attribute in der Attribut-, Datei-, Fall- oder Notizbuchverwaltung über die unten gezeigte Schaltfläche `(x)` hinzufügen. Sie lassen sich auch aus Umfragen und REFI-QDA-Projektdateien importieren. Ein erfolgreicher REFI-QDA-Projektimport ist jedoch nicht garantiert.

QualCoder ist nicht für statistische Analysen der Attribute gedacht. Verwenden Sie dafür Statistiksoftware wie [R](https://www.r-project.org/).

Attribute lassen sich auch über **Verwalten > Attribute verwalten** hinzufügen und löschen:

![Attribute verwalten](/images/513af5f1-a94e-4606-b4d0-54011a8607da.png)

Hier können Sie auch Attribute für Literaturangaben löschen. Tun Sie dies nur, wenn Sie sicher sind, dass Sie die Literaturangaben nicht mehr benötigen. Diese Attribute beginnen mit `Ref_` und verbinden Dateien mit importierten Literaturangaben. Informationen zum Import und zur Verknüpfung finden Sie unter [Literaturangaben](3.5.-References).
