# Übersicht

Diese Anleitung beschreibt die Installation und Nutzung der aktuellen Version von QualCoder.

## Was ist QualCoder? {#what-is-qualcoder}

QualCoder ist eine kostenlose Open-Source-Software für die qualitative Datenanalyse. Sie können damit Texte, Bilder und Audio/Video codieren sowie Notizbücher und Memos schreiben. Codes lassen sich in einem hierarchischen Kategoriensystem organisieren. Verschiedene Berichte können erstellt und meist als HTML, ODT, reine Textdateien oder Excel-Dateien exportiert werden.

Neuere Versionen enthalten optionale KI-Funktionen, die GPT-4 oder andere große Sprachmodelle nutzen. Mit der [Themenexploration](5.1.-AI-chat-based-analysis#2-topic-exploration) können Sie neue Daten in einem interaktiven Chat kennenlernen. Die [KI-gestützte Codierung](4.2.-AI-Assisted-Coding) und die [Textanalyse](5.1.-AI-chat-based-analysis#3-text-analysis) helfen Ihnen, einzelne Aspekte zu vertiefen. Zur Zusammenführung und Verdichtung Ihrer Ergebnisse können Sie eine [Codeanalyse](5.1.-AI-chat-based-analysis#4-code-analysis) mit der KI durchführen.

QualCoder ist für die lokale Arbeit jeweils einer Person ausgelegt. Eine zweite Coder:in kann dasselbe Projekt auf demselben Computer bearbeiten, oder Sie können den Projektordner auf deren Computer übertragen. Gleichzeitiger Zugriff auf dasselbe Projekt ist nicht vorgesehen. Arbeiten Sie nicht direkt mit einem Projekt in einem Cloud-Ordner: Geht die Datenbankverbindung während einer Aktualisierung verloren, kann die Datenbank beschädigt werden.
