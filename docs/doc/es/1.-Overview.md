# Vista general

Las instrucciones describen cómo instalar y usar QualCoder. La información aquí presentada corresponde a la versión más reciente de QualCoder.

## ¿Qué es QualCoder? {#what-is-qualcoder}

QualCoder es un software libre y de código abierto para el análisis de datos cualitativos.
Con QualCoder puede codificar texto, imágenes, audio y video, escribir notas de diario y memos. Puede organizar los códigos en un esquema de categorización en forma de árbol. Se pueden generar diversos informes. La mayoría de los informes se pueden exportar como archivos html, texto de documento abierto (ODT), texto plano o Excel.

Las versiones recientes incluyen funciones opcionales asistidas por IA que utilizan GPT-4 u otros grandes modelos de lenguaje para ayudar a explorar, analizar e interactuar con los datos de maneras innovadoras. Familiarícese con datos nuevos [explorando temas o conceptos amplios](5.1.-AI-chat-based-analysis#2-topic-exploration) en un chat interactivo con la IA. Profundice en aspectos específicos con la [codificación asistida por IA](4.2.-AI-Assisted-Coding) y el [análisis de texto](5.1.-AI-chat-based-analysis#3-text-analysis). Y si llega al punto en el que debe sintetizar y consolidar sus resultados, [discútalos en un chat de códigos](5.1.-AI-chat-based-analysis#4-code-analysis) con la IA.

QualCoder está diseñado para usarse como software de cliente, para ser utilizado por una persona a la vez. (Un segundo codificador puede usar el mismo proyecto en la misma computadora, o la carpeta del proyecto puede transferirse a la computadora del segundo codificador). QualCoder no está diseñado para el acceso múltiple simultáneo. No se recomienda acceder al proyecto en una ubicación en la nube, ya que puede corromper la base de datos si se pierde la conexión con ella durante algún proceso de actualización.
