# Cómo contribuir

## Contribuir al código {#contributing-to-the-code}

Por favor, lea las [pautas de contribución](https://github.com/ccbogel/QualCoder/blob/master/docs/CONTRIBUTING.md)

### Reglas clave de un vistazo {#key-rules-at-a-glance}

- **Elija primero un issue.** Busque un issue existente o cree uno, y comente en él antes de abrir un Pull Request. Espere a que el issue se le asigne antes de empezar a trabajar.
- **Un Pull Request, un commit.** Reúna su trabajo en un único commit con un mensaje descriptivo que refleje sus cambios.
- **Nombres.** Cree una rama dedicada con el nombre del issue que está atendiendo.
- **Licencia.** Al enviar un Pull Request, usted otorga a su contribución la licencia LGPLv3 del proyecto ("Inbound = Outbound").

### Contribuciones asistidas por IA {#ai-assisted-contributions}

Puede usar herramientas de IA para asistir sus contribuciones, pero sigue siendo plenamente responsable de todo lo que envía.

- **Entiéndalo**: debe poder explicar cada línea de su código.
- **Pruébelo**: el código generado por IA debe superar todas las pruebas y comprobaciones de seguridad.
- **Declárelo**: elija un nivel de asistencia de IA (0–5) en la plantilla del Pull Request.
- **Asúmalo**: usted es el autor. Si un revisor pregunta "¿por qué?", responde usted, no la IA.

Las herramientas de IA **no** deben usarse para resolver issues etiquetados como `good first issue`. Estos existen para el aprendizaje humano.


## Contribuir a la traducción {#contribute-to-the-translation}
### Traducir la documentación {#translate-the-documentation}

Puede traducir la documentación creando o modificando los archivos markdown en docs/doc del [repositorio del sitio web](https://github.com/QualCoder-Org/qualcoder-org.github.io).

### Traducir el software {#translate-the-software}

QualCoder admite funcionalidad multilingüe mediante dos tipos de archivos de traducción:

- Archivos Gettext (.po o .mo), que contienen la traducción del software;
- Archivos de idioma de QT (.ts o .qm) correspondientes a la interfaz de usuario.

Para traducir:

 1. Cree un archivo de idioma (si no existe ya) con este comando: ```python rebuild_lang.py --create --lang LANGUAGE_CODE``` Tenga en cuenta que los nombres de sus archivos de idioma deben ajustarse al formato [ISO 639-1](https://fr.wikipedia.org/wiki/Liste_des_codes_ISO_639-1).
 2. Si ya existe un archivo de idioma, puede actualizar las traducciones usando ```python rebuild_lang.py --update --lang LANGUAGE_CODE```.
 3. Puede editar las traducciones de los archivos  .po y .ts de la carpeta src/i18n con el software [Poedit](https://poedit.net/).
 4. Una vez terminado el trabajo, compile al formato de máquina con este comando: ```python rebuild_lang.py --compile --lang LANGUAGE_CODE```.
