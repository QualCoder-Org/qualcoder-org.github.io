# Importaciones y exportaciones
El menú Project contiene la mayoría de las importaciones y exportaciones.

![image](/images/gh-c2551513-0bb0-437b-9b24-002b357bcbe1.png)

Los proyectos y los libros de códigos pueden exportarse usando el estándar REFI-QDA. Los libros de códigos pueden exportarse a ODT o a texto plano.

![image](/images/gh-d2d1f30f-4058-4533-a568-b814a1b72e82.png)

Las encuestas se importan mediante un botón de la ventana Manage Files. [Vea Importar encuestas](6.2.-Survey-Imports)

##  Exportar el libro de códigos {#codebook-export}

Esta es una opción del menú Project > Exports.

Un libro de códigos es una lista de sus códigos. El memo de cada código debería detallar las razones de la finalidad de cada código. El libro de códigos puede exportarse a un archivo de texto. El libro de códigos también muestra la frecuencia de uso de los códigos (de todos los codificadores). Como los códigos y las categorías se disponen en una estructura de árbol, el doble guion '–' indica los códigos y categorías subordinados dentro de una categoría.

## Importar el libro de códigos {#codebook-import}

Importe un libro de códigos como archivo de texto plano (.txt) o como archivo .csv. Use dos símbolos de mayor que para separar categoría y código. Use tres símbolos de mayor que para definir un código bajo otro código.

### Libro de códigos: importación de texto plano {#codebook-plain-text-import}

Cree un archivo de texto plano (.txt). Use el tabulador para añadir luego un memo.

```
code1

category1>>category2>>code2	memo

category1>>code3

category3>>code4

code5>>>code6>>>code7
```

### Libro de códigos: archivo CSV {#codebook-csv-file}

Cree un archivo CSV en LibreOffice Calc o en Microsoft Office Excel. Las categorías y los códigos van en la primera columna y se disponen del mismo modo que en un archivo de texto plano. Los memos de los códigos, si los hay, van en la segunda columna.
```
code1

category1>>category2>>code2

category3>>code3
```

## REFI-QDA {#refi-qda}
[Rotterdam Exchange Format Initiative (REFI)](https://www.qdasoftware.org)  es un estándar abierto para exportar e importar libros de códigos y proyectos desde y hacia distintos programas de análisis cualitativo de datos asistido por computadora.

Actualmente, QualCoder puede importar un libro de códigos siempre que use la versión "urn:QDA-XML:codebook:1.0". QualCoder exporta también en esta versión.

La exportación y la importación de un proyecto son funcionales. **No garantizamos que QualCoder cumpla plenamente el estándar REFI-QDA.** Se ha experimentado un poco con archivos de proyecto REFI_QDA de Nvivo, Atlas.ti, Quirkos y MAXQDA. La importación en MAXQDA parece requerir un carácter adicional de fin de línea en lo relativo a la codificación de texto: esta es una opción en la exportación de proyectos REFI-QDA de QualCoder. La importación en Atlas.ti desplazó las codificaciones un carácter después de cada fin de línea, y aún no se ha resuelto. La importación de atributos desde QualCoder no funciona en Atlas.ti ni en MAXQDA; los atributos de caso no se importaron en Quirkos.

Características como los conjuntos y los grafos no pueden importarse, ya que esa funcionalidad no está en QualCoder. Otros formatos de datos no se conservan; por ejemplo, una fecha o un booleano se convertirían en datos de texto.

Para audio y video, la importación de transcripciones y puntos de sincronización no está probada. La importación o vinculación de archivos con vínculos relativos no se ha probado.

Para importar, cierre primero cualquier proyecto que esté abierto. Luego elija un nombre nuevo de proyecto de QualCoder y seleccione el archivo qdpx que va a importar.

Si no se ve ningún dato codificado, puede que necesite cambiar el nombre del codificador actual en la Configuración. Pruebe con la lista desplegable de nombres de codificador.

Esto ya es antiguo (febrero de 2021), pero un usuario probó la importación de un archivo de proyecto REFI-QDA generado por QualCoder e importado en MAXQDA, Quirkos y Atlas.ti. Solo se probaron texto e imágenes. Aquí hay un PDF con los resultados de la prueba: [Testing importation of REFI-QDA Project files into Atlas, MAXQDA, Quirkos PDF](https://qualcoder.files.wordpress.com/2021/02/refi-qda-project-import-quirkos-maxqda-atlas.pdf)

## Importar desde Taguette {#taguette-import}
Los proyectos creados con [Taguette](https://www.taguette.org/) pueden importarse desde el archivo sqlite. Todos sus datos básicos de codificación se transferirán.

Cierre cualquier proyecto abierto. Luego, en el menú principal, en Project, haga clic en Taguette Project import. Se le pedirá crear un proyecto nuevo, así que introduzca un nombre. Después se le pedirá seleccionar el archivo de proyecto de Taguette (normalmente con extensión .sqlite3). QualCoder procederá entonces a importar los datos.

Si no ve ningún dato codificado, puede que necesite cambiar el nombre del codificador actual en la Configuración. Pruebe usando la lista desplegable de nombres de codificador.

## Importar desde Sonal π (Sonal Pi) {#sonal-sonal-pi-import}

Pueden importarse los proyectos creados con  [Sonal Pi](https://www.sonal-info.com), un software de análisis de datos cualitativos desarrollado en Francia.

## Importar desde RQDA {#rqda-import}
Los proyectos creados con [RQDA](http://rqda.r-forge.r-project.org/) pueden importarse directamente. Se importan todos los datos salvo las categorías de archivos.

Cierre cualquier proyecto abierto. Luego, en el menú principal, en Project, haga clic en RQDA Project import. Se le pedirá crear un proyecto nuevo, así que introduzca un nombre. Después se le pedirá seleccionar el archivo de proyecto de RQDA. QualCoder importará entonces los datos.

Si no se ve ningún dato codificado, puede que necesite cambiar el nombre del codificador actual en la Configuración. Pruebe con la lista desplegable de nombres de codificador.

## Ayuda - Funciones especiales {#help-special-functions}

### Actualización dinámica del contenido de texto {#dynamic-update-text-content}

Esto es útil para actualizar archivos de texto, como extractos de entradas de blog, que cambian con el tiempo. Actualiza un archivo de texto intentando conservar los segmentos de texto codificados existentes. Seleccione el archivo de texto que debe reemplazarse y seleccione el archivo de reemplazo. Haga clic en el botón de los engranajes para ejecutar la actualización. Esta función opera localizando el texto idéntico coincidente en el archivo de reemplazo a medida que recorre el texto del archivo. Puede producir segmentos codificados de forma errónea.
