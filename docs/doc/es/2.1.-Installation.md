# Instrucciones de instalación y ejecución de QualCoder

## INSTALACIÓN 

Para las instalaciones manuales (mediante la línea de comandos o la terminal) puede mencionarse una versión concreta, por ejemplo la 3.8.2. Consulte la [página de versiones](https://github.com/ccbogel/QualCoder/releases) para conocer la más actual, ya que puede ser más reciente. 

### Requisitos previos
VLC es opcional, pero necesitará tenerlo instalado si va a realizar cualquier codificación de audio o video. En ocasiones, en algunos sistemas operativos (por ejemplo Fedora) QualCoder no logra encontrar VLC para utilizarlo. De forma opcional, instale ffmpeg para la visualización de la forma de onda, vea [phoenixnap.com/kb/ffmpeg-windows](https://phoenixnap.com/kb/ffmpeg-windows).

=== "Windows"
    
    Elija la [última versión](https://github.com/ccbogel/QualCoder/releases/latest).
    
    Tiene dos opciones de ejecutables creados en Windows 11:
    
    Opción 1: En la página de la versión hay un instalador para Windows llamado: **QualCoder.Win.exe**
    
    Opción 2: Hay una carpeta exe independiente, no instalable, llamada: **QualCoder.Win.Portable.zip** Descárguela y descomprímala. Está en una carpeta junto a una carpeta interna. Ambas deben permanecer juntas o el exe no se ejecutará. Haga doble clic en el exe de QualCoder para ejecutarlo, tarda hasta 20 segundos en iniciar. 
    
    Versión independiente y portable: <img width="100" height="60" alt="QualCoder portable" src="https://github.com/user-attachments/assets/6be1de98-8b47-4d57-b4b5-c34375e44959" />
    
    Al usar el exe por primera vez, Windows le pedirá que permita la ejecución de QualCoder. Esto se debe a que procede de un editor desconocido. Obtener un certificado de editor de confianza cuesta mucho dinero, así que no será posible en el futuro previsible. Si estas advertencias le incomodan, instale desde el código fuente como se detalla a continuación.
    
    Como alternativa, instale desde el código fuente:
    
    Use un entorno virtual (comandos en el punto 6 más abajo). No usar un entorno virtual puede afectar a otro software de Python que tenga instalado.

    1. Descargue e instale el lenguaje de programación Python. Por favor use una versión reciente en Windows.  [Python3](https://www.python.org/downloads/). Descargue el "Windows installer (64-bit)" más reciente (o el que corresponda a su arquitectura) para alguna de las versiones de Python mencionadas.

    IMPORTANTE: en la primera ventana de la instalación marque la opción "Add Python to PATH"

    2. Descargue el software QualCoder desde: https://github.com/ccbogel/QualCoder con el botón verde Code. Este es el código más nuevo, pero aún no publicado oficialmente (en ocasiones se cuelan errores de programación).  Haga clic en el botón verde "Code" y luego en "Download ZIP". **Como alternativa**, elija el zip de la versión más reciente, vea el lado derecho de esta página para el enlace a Releases.

    3. Descomprima la carpeta en una ubicación (por ejemplo, descargas). (Consejo: elimine la duplicación de carpetas en la extracción QualCoder-master\QualCoder-master cuando se le pregunte dónde extraer. Solo QualCoder-master). 

    4. Use el símbolo del sistema de Windows. Escriba "cmd" en el buscador del menú Inicio de Windows y haga clic en el programa negro "cmd.exe", la consola de comandos de Windows. En la consola escriba o pegue, usando el copiar y pegar con el botón derecho del ratón (ctrl+v no funciona)

    5. En el símbolo del sistema, muévase (con el comando `cd`) a la carpeta de QualCoder. Debe estar dentro de la carpeta QualCoder-master o, si usa una versión publicada, la carpeta Qualcoder-3.8.2. Por ejemplo 

    ```bash
    cd Downloads\QualCoder-master
    ```

    5a. En lugar de los comandos siguientes, ejecute el archivo bat que ejecutará todos estos comandos, escribiendo esto y presionando Enter: 

    `run_from_source_Windows.bat`

    Si obtiene errores al usar un archivo bat, ejecute entonces los comandos siguientes.

    6. Instale el entorno virtual y los módulos de python requeridos. 



    La instalación puede tardar hasta 10 minutos. En algunos sistemas Windows es posible que deba reemplazar el comando _python_ por _py_ o _python3_ a continuación: 

    ```bash
    python -m venv env
    env\Scripts\activate
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt
    ```

    7. Inicie QualCoder, moviéndose primero a la carpeta interna src:

    ```bash
    cd src
    python -m qualcoder
    ```


    8. Si ejecuta QualCoder en un entorno virtual, para salir del entorno virtual escriba:

    `deactivate`

    El símbolo del sistema quitará entonces la palabra  *(env)*.

    **Para iniciar QualCoder de nuevo**

    Si no está usando un entorno virtual, mientras se encuentre en la misma letra de unidad, por ejemplo C:

    `python -m qualcoder`

    Si está usando un entorno virtual:

    `cd` a la carpeta src dentro de Qualcoder-master (o de la carpeta de la versión de Qualcoder):

    ```
    env\Scripts\activate
    cd src
    python -m qualcoder
    ``` 

=== "MacOS"

    **Instalación desde los paquetes de la aplicación:**
    
    Asegúrese de haber instalado todas las actualizaciones de macOS antes de comenzar la instalación. Vaya a la aplicación Configuración del Sistema en su Mac. Haga clic en General en la barra lateral (puede que necesite desplazarse hacia abajo) y luego en Actualización de software.
    
    Instale QualCoder: haga doble clic en el archivo dmg descargado. Arrastre QualCoder al enlace a sus aplicaciones.
    
    Inicie QualCoder desde el Launchpad o haciendo doble clic en la aplicación dentro de su carpeta de aplicaciones.
    Actualmente no podemos firmar los paquetes de la aplicación, así que al intentar ejecutar el programa por primera vez puede aparecer una advertencia de que QualCoder procede de un desarrollador no registrado o de que "QualCoder can't be opened because Apple cannot check it for malicious software." Según su procesador, puede que vea alguna de estas:
    
    Si ve "Show in Finder" u OK.  Haga clic en Ok.
    
    Si ve "Done" o "Move to trash". Haga clic en Done.
    
    A continuación, vaya a Configuración y seleccione Privacidad y seguridad.  Desplácese hacia abajo hasta ver un mensaje que indica que se impidió el inicio de QualCoder. Haga clic en "open anyway". Es posible que se le pida introducir su contraseña y que deba hacer clic en "Open" de nuevo.  Tras introducir la contraseña, solo espere a que el programa se abra. Puede tardar varios segundos.
    
    A partir de entonces, QualCoder debería iniciarse sin problemas.
    
    Puede instalar QualCoder sin permisos de administrador. Debe copiar los binarios en el directorio /Users/mylogin/Applications. Debe eliminar el atributo del directorio de la aplicación, escribiendo en la terminal:
    ```xattr  -d com.apple.quarantine /Users/mylogin/Applications/QualCoder.app```
    
    **Instalación desde el código fuente:**
    
    Use un entorno virtual (comandos en el punto 6 más abajo). No usar un entorno virtual puede afectar a otro software de Python que tenga instalado.

    1. Descargue e instale el lenguaje de programación Python. Por favor use Python 3.10, 3.11 o 3.12 en Windows, otras versiones pueden causar problemas  [Python3](https://www.python.org/downloads/macos/). Descargue el "macOS 64-bit universal2 installer" más reciente para alguna de las versiones de Python mencionadas y ábralo para instalar Python.

    2. Descargue el software QualCoder desde: https://github.com/ccbogel/QualCoder con el botón verde Code. Este es el código más nuevo, pero aún no publicado oficialmente (en ocasiones se cuelan errores de programación).  Haga clic en el botón verde "Code" y luego en "Download ZIP". **Como alternativa**, elija el zip de la versión más reciente, vea el lado derecho de esta página para el enlace a Releases.

    3. Descomprima la carpeta en una ubicación (por ejemplo, descargas) haciendo doble clic en ella. 

    4. Use la aplicación Terminal (`Applications -> Utilities -> Terminal`).

    5. En la terminal, muévase (con el comando `cd`) a la carpeta de QualCoder. Debe estar dentro de la carpeta QualCoder-master o, si usa una versión publicada, (por ejemplo la carpeta Qualcoder-3.8.2). Por ejemplo 

    ```bash
    cd Downloads/QualCoder-master
    ```

    6. Instale el entorno virtual y los módulos de python requeridos. 

    El comando `python3` utiliza la versión de Python instalada más reciente. Puede usar una versión concreta en su macOS, si tiene muchas versiones de Python instaladas, por ejemplo `python3.10`. Para verificar que está usando la versión correcta de Python escriba `which python3`, que debería devolver: `/Library/Frameworks/Python.framework/Versions/3.<version>/bin/python3`. Si la salida es `/usr/bin/python3`, no continúe, ya que es el Python de su sistema y se desaconseja usarlo.

    La instalación puede tardar hasta 10 minutos. 

    ```bash
    python3 -m venv env # this creates the virtual environment with the name "env" in your current directory
    source env/bin/activate # this activates the virtual environment "env", (env) should appear in front of your prompt
    pip3 install --upgrade pip # optionally; pip and pip3 are equivalent withing a virtual environment
    pip3 install -r requirements.txt
    ```

    7. Ejecute QualCoder desde el símbolo del sistema

    ```bash
    cd src
    python3 -m qualcoder # python and python3 are equivalent withing a virtual environment
    ```

    8. Si ejecuta QualCoder en un entorno virtual, para salir del entorno virtual escriba:

    ```bash
    deactivate
    ```

    El símbolo del sistema quitará entonces la palabra *(env)*.

    **Para iniciar QualCoder de nuevo**

    Si no está usando un entorno virtual:

    ```bash
    cd Downloads/QualCoder-master
    cd src 
    python3 -m qualcoder
    ```

    Si está usando un entorno virtual:

    ```bash
    cd Downloads/QualCoder-master
    source env/bin/activate
    cd src 
    python3 -m qualcoder
    ```


=== "Linux"

    Si usa un sistema basado en Debian (Debian, Ubuntu / Lubuntu / ZorinOS, Linux Mint), hay un archivo ejecutable disponible en la página de la versión. Descárguelo y haga doble clic para ejecutarlo. Puede que primero deba hacer clic derecho en el archivo, ir a Propiedades y marcar la casilla Ejecutable.

    Si usa otro sistema operativo, por favor instale desde el código fuente. El procedimiento se detalla a continuación.

    Nota: Fedora usa Wayland, que puede no funcionar bien con la interfaz gráfica Qt. Se sugiere que instale también Xwayland.

    Para instalar desde el código fuente a continuación, dentro de un entorno virtual.

    Según su sistema operativo, necesitará descargar Python y sus dependencias. Estos son los comandos para su sistema operativo:

    - Si está en un **sistema basado en Debian (Debian, Ubuntu / Lubuntu / ZorinOS, Linux Mint)** :
      Instale pip. Es una herramienta que descarga módulos adicionales de python:  `sudo apt install python3-pip`
      Si va a usar audio o video, instale VLC (descárguelo del sitio) o: `sudo apt install vlc`
      Si usa el gestor de escritorio alternativo de Ubuntu **Xfce** puede que necesite ejecutar esto: `sudo apt install libxcb-cursor0`
    - Si está en **Fedora** : **Hay un problema al usar VLC desde python. El software se bloquea y no hemos podido encontrar una solución. Por lo tanto, el audio y el video no se pueden usar dentro de un proyecto de QualCoder en Fedora.**
    - Si está en **Arch/Manjaro Linux** : Si va a usar audio o video, instale VLC (descárguelo del sitio) o: `sudo pacman -S vlc` e instale pip y venv: `sudo pacman -S python python-pip python-virtualenv`

      
    1. Descargue y descomprima la carpeta de Qualcoder. 

    2. Luego haga `cd` a la carpeta de QualCoder.

    Por ejemplo, ahora puede estar en esta carpeta, donde descomprimió QualCoder: 

    yourcomputer:~Downloads/QualCoder-3.8.2

    3a. En lugar de los comandos desde el punto 3b en adelante, ejecute el archivo de shell que ejecutará todos los comandos siguientes. Haga que este archivo sea ejecutable (clic derecho y vaya a Propiedades), luego escriba el siguiente comando y presione Enter: 

    `./run_from_source_Linux.sh`

    3b. Configure el entorno virtual e instale los módulos de python. El entorno virtual estará en su propia carpeta llamada env. Instalar los módulos requeridos toma un rato.

    ```
    python3 -m venv env
    source env/bin/activate
    pip install --upgrade pip
    pip install -r requirements.txt
    ```

    5. Muévase a la carpeta interna src y luego:
    ```
    cd src
    python3 -m qualcoder
    ```

    6. Después de usar QualCoder, desactive el entorno virtual.

    `deactivate`

    **Uso en cualquier momento después de la instalación: muévase a la carpeta de QualCoder y luego:**

    ```
    source env/bin/activate
    cd src
    python3 -m qualcoder
    ```

    Para salir del entorno:

    `deactivate`

    También puede crear un archivo .desktop para iniciar QualCoder:

    Cree un archivo .Desktop para el lanzamiento, introduzca este comando (adáptelo según la ubicación de la carpeta del código fuente):

    `bash -c 'cd ~/.local/share/qualcoder/src/ && ~/.local/share/qualcoder/env/bin/python3.12 -m qualcoder'`
