# Configuración

La pantalla de configuración le permite cambiar varias características, entre ellas el idioma, el nombre del codificador y el tipo y tamaño de fuente, así como las opciones de la integración de IA. 

### Nombre del codificador

Varios codificadores pueden codificar y anotar el mismo texto. Su nombre de codificador actual se muestra en la parte superior del diálogo de configuración. 

<img width="400" alt="grafik" src="https://github.com/user-attachments/assets/cd0aab19-5f2b-43de-b6f0-08ab171fbb91" />

Este nombre se usará para identificar sus aportaciones al proyecto. Haga clic en el botón "Change" para modificar su identidad o para crear, renombrar o fusionar otros codificadores dentro del proyecto actual. [Vea aquí para más información.](2.4.-Working-in-a-Team.md/#important-considerations-regarding-coder-names) 

### Configuración general

El idioma predeterminado de QualCoder es el inglés. El francés, el alemán y el español son idiomas alternativos que se actualizan con regularidad. Otros idiomas no se han revisado a fondo para comprobar la exactitud de sus traducciones (chino, japonés, portugués, rumano, sueco). 

Marcar la casilla Show IDs muestra los identificadores numéricos de códigos, archivos, casos y más. Estos identificadores pueden ser útiles al escribir consultas sql.

Hay algunas opciones para cambiar el aspecto general de QualCoder.

Para transcribir audio y video, se pueden seleccionar el formato de tiempo y el tipo de corchetes.

Los archivos de texto muy grandes pueden ralentizar el modo de codificación en QualCoder. Por eso, una opción del menú contextual en Codificar texto es cargar fragmentos de texto de menor tamaño. El tamaño predeterminado es de 50 000 caracteres, pero puede cambiarse en la Configuración a tamaños menores para computadoras más lentas.

### Copias de seguridad

La copia de seguridad del proyecto puede configurarse para realizarse automáticamente cada hora, o para no realizarse. QualCoder conserva las copias de seguridad más recientes con una marca de fecha y hora. El nombre de la copia de seguridad es: _projectname_BKP_yyyymmdd_hh.qda_  donde _hh_ es la hora en formato de 24 horas. Esto también significa que no se realizan varias copias de seguridad dentro de una misma hora. Por lo tanto, una nueva copia de seguridad no puede sobrescribir otra creada dentro de la misma hora. Se conserva un número limitado de copias de seguridad, **las copias más antiguas se eliminan**. La opción de configuración le permite elegir entre 1 y 10 copias de seguridad.

Recomiendo que haga una copia de seguridad antes de realizar cualquier cambio sustancial, como reorganizar códigos y categorías, fusionar proyectos o fusionar códigos. QualCoder sí realiza copias de seguridad cada hora (conservando hasta las cinco más recientes) si las copias de seguridad están activadas en la configuración.

Renombre o mueva a otra ubicación aquellas copias de seguridad concretas que necesite conservar. Cuando las copias de seguridad están configuradas, una opción adicional es elegir respaldar los archivos de audio y video. Para que las copias de seguridad sean completas se recomienda respaldar el audio y el video, sin embargo esto puede ralentizar la apertura del software si tiene muchos archivos grandes. Como alternativa, puede vincular los archivos grandes de audio y video en lugar de importarlos a la carpeta del proyecto. El directorio de proyectos predeterminado es donde se ubicarán por defecto muchas operaciones de archivo, para exportar o para buscar archivos que importar.

En su carpeta de usuario QualCoder creará una carpeta .qualcoder con un archivo QualCoder.log para el registro de eventos y un archivo config.ini que contendrá muchos ajustes, como el nombre del codificador actual, las fuentes preferidas, el idioma y un directorio de trabajo preferido. No guarde ningún dato ni proyecto dentro de la carpeta .qualcoder. El único archivo que debería colocar aquí es un archivo stopwords.txt, únicamente si necesita aplicar un conjunto distinto de palabras vacías para las funciones de nube de palabras y conteo de palabras. Esta carpeta es solo para uso del software QualCoder mientras se ejecuta.
