# Desarrollo de QualCoder

## Estructuras de datos

La carpeta de datos qda contiene carpetas para los documentos, imágenes y audio y video importados. También contiene la base de datos sqlite, llamada data.qda, para almacenar los datos de codificación.

QualCoder crea los archivos QualCoder.log y QualCoder_settings.txt en una carpeta .qualcoder dentro de su directorio de usuario. El archivo de configuración contiene el nombre del codificador actual, un directorio de trabajo predeterminado y la elección de fuente. El archivo de registro recoge los errores del programa y algunas acciones del usuario.

Cuando la IA está activada: hay una carpeta ai_data que contiene una base de datos sqlite con el historial de chats y un almacén vectorial. Un almacén vectorial es una representación numérica de palabras, frases y oraciones que usa el modelo de lenguaje de IA. El almacén vectorial usa faiss, que se emplea para las búsquedas de similitud de la IA.

QualCoder está escrito en python 3 usando Qt6 para la interfaz gráfica.

La carpeta del proyecto qda

La carpeta de datos qda contiene carpetas para los documentos, imágenes y audio y video importados. También contiene la base de datos sqlite, llamada data.qda, para almacenar los datos de codificación, y la carpeta ai_data, que contiene la base de datos sqlite para las necesidades de la IA.

La carpeta de configuración .qualcoder

QualCoder crea los archivos QualCoder.log y QualCoder_settings.txt dentro de una carpeta .qualcoder en su directorio de usuario. El archivo de configuración contiene el nombre del codificador actual, un directorio de trabajo predeterminado, la fuente, los idiomas y otras opciones. El archivo de registro recoge los errores del programa y algunas acciones del usuario. Puede haber varios archivos de registro rotatorios. No debería colocar ningún archivo dentro de esta carpeta, ya que se usa como área de almacenamiento de configuración de trabajo del programa QualCoder. Sin embargo, sí puede colocar un archivo stopwords.txt en esta carpeta. El archivo de palabras vacías anulará la lista integrada de palabras vacías en inglés.

Se recomienda una resolución mínima de pantalla de 1024x600 píxeles.

**Sistemas operativos utilizados:**

QualCoder se ha utilizado en Ubuntu 24, Fedora, Linux Mint, Arch Linux, Fedora, Windows 10, Windows 11 y MacOS. El desarrollo se realiza en Windows 11. Fedora puede tener problemas con el uso de audio y video: esto aún no se ha resuelto.

A veces, para las distintas distribuciones de Linux, pueden ser necesarias instrucciones de instalación diferentes. No tenemos capacidad para identificarlas y corregirlas, y dependemos de los usuarios finales para obtener comentarios o instrucciones mejoradas que resuelvan estos problemas.
