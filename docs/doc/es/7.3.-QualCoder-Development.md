# Otra información y licencias

Actualmente QualCoder se desarrolla en Windows 11. QualCoder está escrito en python 3 usando Qt6 para la interfaz gráfica.

Después de la versión 4.0, una de las áreas de desarrollo será revisar la presencia visual de QualCoder, su interfaz de usuario. El objetivo es hacer la interfaz más moderna y atractiva. Otra área de mejora será ofrecer más documentación de gobernanza, para apoyar el uso de QualCoder en grandes instituciones.

## Sistemas operativos utilizados {#operating-systems-used}

QualCoder se ha utilizado en Windows 11, macOS, Ubuntu 24, Lubuntu, Fedora, Linux Mint, Arch Linux, Fedora, NixOS y ZorinOS.

* Usar audio o video con QualCoder en Fedora hace que QualCoder se bloquee.
* Debian con Gnome y la opción de ventanas en mosaico reduce el tamaño de la ventana de QualCoder. La mejor opción es desactivar las ventanas en mosaico en la configuración de Gnome.

## Estructuras de datos {#data-structures}

**La carpeta del proyecto qda** contiene carpetas para los documentos importados y la base de datos sqlite que almacena los datos de codificación. Cuando la IA está activada, hay una carpeta ai_data que contiene una base de datos sqlite con el historial de chats y un almacén vectorial. Un almacén vectorial es una representación numérica de palabras, frases y oraciones que usa el modelo de lenguaje de IA.
**La carpeta de trabajo .qualcoder** está en su carpeta de usuario. QualCoder crea en ella QualCoder.log y archivos de configuración. No coloque ningún archivo dentro de esta carpeta, ya que QualCoder la usa como área de trabajo para la configuración y el almacenamiento. La **carpeta .qualcoder_ai** de la carpeta de usuario contiene los detalles de configuración para el uso de la IA.
