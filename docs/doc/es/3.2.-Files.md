#  Gestionar archivos

## Importar archivos

Importe texto desde documentos de texto plano, docx, epub, md, odt, pdf y rtf (3.8+). Importe imágenes desde: jpg, jpeg y png. Importe formatos de audio y video: mp3, m4a, mp4, wav, mov, ogg. Los PDF pueden codificarse como texto o como imágenes. Como alternativa, puede vincular archivos ubicados localmente en el sistema de archivos de su computadora. Esta puede ser una buena opción si tiene una estructura de carpetas concreta que es importante para su proyecto.

Los archivos de texto que contienen emoticonos pueden importarse y visualizarse. Sin embargo, los emoticonos pueden 'desplazar' las franjas de codificación posteriores, en 1 carácter por emoticono. Esto ocurre principalmente al usar el botón de autocodificar texto exacto.

Botones de importar y vincular: <img width="92" height="43" alt="Import and link buttons" src="https://github.com/user-attachments/assets/dc98a9ef-0d0c-4365-b444-9b2c3f145cab" />

Los archivos vinculados pueden importarse a la carpeta del proyecto y, a la inversa, los archivos almacenados en la carpeta del proyecto pueden exportarse fuera de ella y quedar vinculados. 

Botones de importar vinculado y exportar a vinculado: <img width="88" height="45" alt="Import linked file, export to linked file buttons" src="https://github.com/user-attachments/assets/81951366-1a88-4069-b82d-8d959cf2aaf4" />

Puede añadir atributos de archivo haciendo clic en el botón `(x)`. Por ejemplo, cree una variable de tipo carácter llamada `location` y complétela con nombres de ciudades.

Si está empezando con QualCoder, abra la carpeta `Examples` e importe `ID1.docx`, `ID2.odt` y `seascape.jpg`.

Tras la importación, abra cada archivo haciendo doble clic en él o mediante el menú contextual. Puede probar la seudonimización (vea más abajo) eliminando `ID2.odt`, añadiendo `Joe Bloggs` mediante el botón Pseudonymise y volviendo a importar el archivo.


### PDF: extracción de texto plano

La importación de PDF puede ser problemática y quizá requiera edición, ya que se pierde el formato. Los archivos PDF grandes tardan mucho en importarse. QualCoder extrae el texto de los archivos PDF usando pdfminer.six, pero usted puede optar por usar otro programa de extracción para el texto plano; algunas sugerencias son: [PDF2Go](https://www.pdf2go.com), [PDFMate](https://www.pdfmate.com/pdf-converter-free.html), [Pandoc](https://pandoc.org) y luego copiar el texto plano. Sin embargo, si quiere usar la función _Code Pdf_ dentro de QualCoder, que permite codificar texto con el texto del PDF mostrado en su lugar como en el PDF original, debe usar la extracción de texto plano de QualCoder y no editar el texto plano extraído.

### Seudonimización (desidentificación de datos)

En la versión 3.8+ está disponible la seudonimización para reemplazar palabras o frases.
Para muchos idiomas (posiblemente salvo el chino, el japonés y el coreano), siempre que el carácter anterior y el posterior a la frase no sean alfabéticos ni numéricos, este es un corte fácil de aplicar. La seudonimización distingue entre mayúsculas y minúsculas. Las palabras originales deben tener al menos 2 caracteres y los seudónimos al menos 3 caracteres. Como alternativa, deje en blanco la entrada del seudónimo para obtener un término generado aleatoriamente.

En Gestionar archivos se accede a un botón 'Anonymise on import'. Este le permite introducir una lista de términos originales y sus seudónimos, y debe estar en su sitio antes de importar cualquier documento de texto. No se aplica retroactivamente a los documentos ya importados.

<img width="43" height="42" alt="image" src="https://github.com/user-attachments/assets/c595539d-e1cb-41d5-a78c-7e987f9d5490" />
El botón abre una ventana que permite al usuario añadir a la lista, o quitar de ella, las palabras o frases que se van a anonimizar. Además, por cada nueva frase que se vaya a seudonimizar, compruebe que el término de reemplazo no se haya utilizado ya en la lista de anonimización.

La lista que cree se almacena dentro de la carpeta del proyecto, la carpeta qda. La lista se guarda en formato json. Una vez terminada toda la importación, el investigador puede trasladar el archivo a otra ubicación segura, como referencia cuando sea necesario. El archivo json puede abrirse en un editor de texto como NotePad.

Se seudonimizarán los archivos de texto importados y las columnas cualitativas de las encuestas importadas.

Los archivos PDF no se seudonimizan por dos razones. La página del PDF puede visualizarse tal cual en _Code Images_. Además, se necesita el texto exacto para la correspondencia entre el texto plano y el texto del PDF en el área Code PDF.

## Archivos de texto grandes

Al codificar archivos de texto realmente grandes, QualCoder se vuelve lento. En _Code Text_, QualCoder puede dividir los archivos en fragmentos de 50 000 caracteres para reducir la lentitud del programa. Sin embargo, la mejor opción al importar archivos de texto grandes es dividirlos en secciones separadas y cargar esas secciones más pequeñas como archivos independientes. Dé también a cada nombre de archivo alguna lógica ordenada, por ejemplo, book_chap01.txt, book_chap02.txt.

## Filtrar columnas y filas

### Filtrar filas

El menú contextual con el botón derecho también le permite reordenar los archivos por nombre, fecha y tipo de archivo, al hacer clic derecho en las columnas de nombre o de fecha. Puede mostrar solo determinados tipos de atributo: elija la opción Show this value
También puede seleccionar Show values like. Show values like puede aplicarse varias veces para acortar aún más la lista de filas mostradas.

### Visibilidad de columnas

A veces pueden mostrarse muchas columnas, lo que puede resultar abrumador. Puede ocultar columnas haciendo clic derecho en la fila de encabezado de la tabla para obtener opciones para ocultar esa columna u ocultar las columnas que comiencen con un texto concreto. O para mostrar las columnas cuyo nombre comience con un texto concreto.

### Guardar y cargar filtros de columnas y filas

## Abrir URL de atributos

Haga clic derecho en una URL dentro de un atributo y abra la URL con el navegador web predeterminado. Esto solo funciona si el atributo es una URL y supera la validación de URL.

## Copiar referencia al portapapeles

Use la opción del menú contextual para las columnas de referencia (Ref_Authors, Ref_Title, Ref_Journal, Ref_Type, Ref_Year). Esto permite copiar la referencia al portapapeles en estilo Vancouver o APA.

## Asignar un archivo seleccionado a un caso

Puede asignar un archivo a un caso mediante el menú contextual cuando esté en la columna de casos.

## Inteligencia artificial

Si ha activado la integración de IA en QualCoder, los archivos de texto recién importados serán leídos por el modelo de IA local y almacenados en su memoria local. Esto ocurre en segundo plano (la barra de estado muestra "AI: reading"). Puede seguir usando QualCoder, pero las funciones mejoradas con IA no estarán disponibles hasta que la IA termine de actualizar su memoria. Esto también sucede si edita en QualCoder un archivo de texto ya importado.

Si alguna vez tiene la impresión de que la memoria de la IA está desincronizada y ha pasado por alto alguna actualización de sus datos (lo que no debería ocurrir en circunstancias normales), puede reconstruir la memoria desde cero seleccionando "AI > Rebuild Internal Memory". Esto releerá todos los documentos, lo que puede tardar un rato. 

## Creación y edición de archivos de texto

Puede crear e introducir texto en la base de datos presionando el icono del lápiz. 

Botón para crear una entrada de texto: <img width="57" height="47" alt="Pencil icon button, to create a plain text file" src="https://github.com/user-attachments/assets/3e25677d-56de-48b5-81e3-e292979672be" />

Los archivos de texto pueden editarse siempre que no se haya realizado ninguna codificación, anotación o asignación a casos con ese archivo de texto.

!!! tip "Buena práctica"
    Guarde una copia del proyecto antes de editar el texto de un archivo de texto codificado.

Las secciones del archivo de texto o del archivo transcrito de audio o video tendrán fragmentos de texto subrayados en verde (asignado a caso), amarillo (anotación) o rojo (codificado). El texto puede editarse incluso después de haber sido codificado, anotado o asignado (total o parcialmente) a un caso. 

Puede seleccionar texto que no esté subrayado y copiarlo o reemplazarlo sin problemas. Puede hacer clic en una posición (**sin seleccionar una sección de texto**) para luego escribir, borrar o pegar texto. Esto puede ocurrir en ubicaciones de texto subrayado (codificado, anotado, asignado a caso) o no subrayado (no codificado, no anotado, no asignado a caso). Verá cómo los subrayados se desplazan a medida que se añade o se elimina texto.

!!! info
    Existen algunas limitaciones: es mejor evitar seleccionar secciones de texto para eliminarlas (o para escribir o pegar encima) si esas secciones combinan partes no subrayadas (no codificadas, no anotadas, no asignadas a caso) y subrayadas (codificadas, anotadas, asignadas a caso). La razón es que las posiciones de los códigos, anotaciones o asignaciones de caso subyacentes pueden no coincidir correctamente con lo previsto. Si ha hecho un cambio que cree que ha afectado gravemente a esas posiciones codificadas, anotadas o asignadas a caso, salga de la ventana de edición de texto presionando el botón Cancel.

## Archivos de audio y video

Pueden importarse archivos de video (mov, mp4, wmv, ogg) y de audio (wav, mp3, m4a). Al cargar un archivo de audio o de video también se creará automáticamente un archivo de texto transcrito en blanco. Este archivo tendrá el mismo nombre que el archivo de audio o video, pero con el sufijo '.txt'. Inicialmente, esta transcripción de texto estará vacía. Puede transcribir el archivo usted mismo o encargar la transcripción profesional y copiar y pegar el texto en este archivo.

Puede abrir un archivo de audio o de video para verlo. En el caso del video, se abren dos ventanas: una para ver el video y otra con los controles y una transcripción, como se muestra abajo. Cuando se carga un archivo de audio o de video en QualCoder se crea automáticamente un archivo de transcripción de texto en blanco. El nombre del archivo de transcripción es de forma predeterminada videoname.txt. 

El archivo de texto transcrito se crea y se almacena dentro de la base de datos, y puede exportarse a un archivo de texto. El archivo puede editarse.

!!! warning
    Nota importante: las ediciones ocurren dentro de la base de datos. El archivo de texto original NO se modifica. Las transcripciones no pueden vincularse como archivo externo.

Si tiene un archivo .srt (un archivo de transcripción que lee VLC), puede colocarlo junto al video dentro de la carpeta del proyecto, en la carpeta de video, como se muestra en la imagen siguiente. Cuando se reproduzca el video, el texto de la traducción se mostrará como subtítulos en el video. Además, si abre el archivo .srt en un editor de texto, copie y pegue su contenido en el archivo de texto asociado al video. Entonces ese texto se mostrará como transcripción del video. 

![image](https://github.com/user-attachments/assets/221aac54-1907-41a7-95cc-26899250b13a)

Si tiene ffmpeg instalado se muestra una forma de onda. Si los archivos de audio tienen varias pistas de audio, solo se muestra la primera pista en la forma de onda.

### Transcribir audio y video

Para transcribir, abra la opción de menú Manage files y luego visualice el archivo de audio o de video. El audio o video se cargará y habrá un área de texto para introducir el texto transcrito. 

QualCoder no tiene una función automatizada de audio a texto. Use otros servicios como: Microsoft Word Transcribe, [otter.ai](https://otter.ai/), [Vosk](https://alphacephei.com/vosk/install), [audapolis](https://github.com/audapolis/audapolis), [noScribe](https://github.com/kaixxx/noScribe), un transcriptor sin conexión para 99 idiomas distintos, o [SocioTranscribe](https://framagit.org/justinmponcet/whisper).

Las transcripciones pueden contener marcas de tiempo que indican cuándo se pronuncia el texto durante el video. QualCoder reconoce los siguientes formatos, donde SSS son milisegundos:

```
[hh:mm:ss] , [mm:ss] , [hh.mm.ss] , [mm.ss] 
```

Para lo anterior, los corchetes pueden ser []  o {}. Esto puede cambiarse en el menú de Configuración.

```
#hh:mm:ss.SSS# , hh:mm:ss,SSS --> hh:mm:ss,SSS
```

El archivo de video puede contener varias pistas de audio. Hay una lista desplegable que le permite elegir otra pista de audio.

Las transcripciones pueden contener nombres de hablante que indican quién habla. Los nombres de hablante se delimitan con este formato: [name] o {name} o name: .

La transcripción manual de audio y video se facilita con algunos atajos de teclado. La transcripción y la adición o edición de texto solo pueden realizarse si el texto existente no tiene códigos ni anotaciones.

Los atajos de teclado son:

Ctrl R		Retroceder 5 segundos

Alt R	Alt Menos (versión 3.3+)	Retroceder 30 segundos

Alt F	Alt Más (versión 3.3+)	Avanzar 30 segundos

Ctrl S o Ctrl P	Alternar detener/iniciar audio o video. Al pasar de detener a reproducir se retroceden 2 segundos.

Ctrl Shift > Aumentar la velocidad de reproducción hasta 2 veces

Ctrl Shift < Reducir la velocidad de reproducción hasta 0,1 

Los controles anteriores también están disponibles en los iconos de la barra de herramientas.

Ctrl T		Insertar marca de tiempo con este formato: [hh.mm.ss]

Ctrl + N		Añadir un nombre de hablante. Esto también pausa el audio o video.

Ctrl D		Eliminar uno o más nombres de hablante.

Ctrl 1 a 8	Insertar nombre de hablante con este formato: [name]

## Gestionar vínculos rotos a archivos

Si su proyecto contiene archivos vinculados externamente, esos archivos pueden moverse, renombrarse o eliminarse.

La función Manage bad links le permite editar el vínculo existente y sustituirlo por uno nuevo, localizando el archivo correcto y su ubicación. Los vínculos rotos sí afectan a las imágenes y a los archivos de audio y video. El texto no se ve afectado, salvo que necesite revisar un documento de texto original. Esto se debe a que el texto plano, sobre el que se realiza la codificación, se importa a la base de datos de QualCoder.

La búsqueda automatizada lleva tiempo y recorre el directorio de usuario en busca de hasta 2 nombres de archivo coincidentes. Su finalidad es acelerar la localización del vínculo a los archivos cuando el vínculo actualmente no apunta a nada.
