# Estructura de datos SQLite

Se describe la estructura de datos actual v8 para ayudar en el desarrollo de consultas sql. Esta estructura la usa QualCoder 3.2. Las estructuras de base de datos más antiguas se modifican al abrirse para ajustarse a este formato.

Las tablas se listan alfabéticamente.

## Tabla: annotation

**anid** _integer_  Autonumeración única

**fid** _integer_ Enlaza con source.id para identificar el archivo de texto. Las anotaciones son solo para archivos de texto.

**pos0** _integer_  La posición del carácter inicial en el archivo de texto.

**pos1** _integer_  La posición del carácter final en el archivo de texto.

**memo** _text_  Contiene el texto de la anotación.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

## Tabla: attribute

**attrid** _integer_  Autonumeración única.

**name** _text_ El nombre del atributo. Coincidirá con el nombre en attribute_type.

**attr_type** _text_  Es 'case' o 'file'

**value** _text_ Almacena el valor del atributo como texto, incluso si se pretende que sea un valor numérico. Puede que necesite hacer cast(value as real)

**id** _integer_ Este campo representa un id de fuente o un id de caso.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

## Tabla: attribute_type

**name** _text_  El nombre único del atributo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**memo** _text_  Contiene un memo sobre el tipo de atributo.

**caseOrFile** _text_  Es 'case' o 'file' 

**valuetype** _text_  Es 'character' o 'numeric'

## Tabla: case_text

**id** _integer_ Autonumeración única.

**caseid** _integer_  Enlaza con cases.caseid.

**fid** _integer_ enlaza con source.id. Son solo para archivos de texto.

**pos0** _integer_  La posición del carácter inicial en el archivo de texto. Null si no es un archivo de texto.

**pos1** _integer_  La posición del carácter final en el archivo de texto.  Null si no es un archivo de texto.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

## Tabla: cases

**caseid** _integer_  Autonumeración única.

**name** _text_   El nombre del caso.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

## Tabla: code_av

**avid** _integer_  Autonumeración única.

**id** _integer_  Enlaza con source.id para identificar el archivo de A/V de origen.

**pos0** _integer_  La posición inicial en milisegundos en el archivo de A/V.

**pos1** _integer_  La posición final en milisegundos en el archivo de A/V.

**cid** _integer_  El id de code_name para identificar el código.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**important** _integer_  Si tiene asignado 1 es un código importante.

## Tabla: code_cat

**catid** _integer_  Autonumeración única.

**name** _text_  El nombre de la categoría.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**supercatid** _integer_  Representa la categoría madre de esta categoría. Es Null si es una categoría de nivel superior.

## Tabla: code_image

**imgid** _integer_  Autonumeración única.

**id** _integer_  Enlaza con source.id para identificar el archivo de imagen de origen.

**x1** _real_  La posición x izquierda en píxeles en el archivo de imagen. Se almacena como valor decimal.

**y1** _real_  La posición y superior en píxeles en el archivo de imagen. Se almacena como valor decimal.

**width** _real_  El número de píxeles a lo ancho. Se almacena como valor decimal.

**height** _real_ El número de píxeles a lo alto. Se almacena como valor decimal.

**cid** _integer_  El id de code_name para identificar el código.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**important** _integer_  Si tiene asignado 1 es un código importante.

**pdf_page** _integer_ Null o un número que representa la página del pdf

## Tabla: code_name

**cid** _integer_  Autonumeración única.

**catid** _integer_ El code_cat.catid si este código forma parte de una categoría. Null si no forma parte de una categoría.

**name** _text_  El nombre único del código.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**color** _text_  Un valor hexadecimal que va de '#000000' a '#FFFFFF' QualCoder reconoce 120 colores, de modo que puede aplicar texto claro u oscuro encima. 

## Tabla: code_text

**ctid** _integer_  Autonumeración única.  (añadido en v3).

**cid** _integer_  El id de code_name para enlazar el código.

**fid** _integer_  El id de la fuente del archivo para enlazar el archivo de texto.

**seltext** _text_  Una copia del texto de este segmento de texto codificado.

**pos0** _integer_  La posición del carácter inicial en el archivo de texto. Null si no es un archivo de texto.

**pos1** _integer_  La posición del carácter final en el archivo de texto.  Null si no es un archivo de texto.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**avid** _integer_  Enlace a la posición temporal de un segmento de A/V codificado. Vea la tabla code_av.

**important** _integer_  Si tiene asignado 1 es un código importante.

## Tabla: journal

**jid** _integer_  Autonumeración única.

**name** _text_  Nombre del diario.

**jentry** _text_  Contiene el texto del diario.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

## Tabla: project

Debería contener una sola fila.

**databaseversion** _text_  Actualmente v1, v2 o v3. QualCoder actualizará a la versión más reciente (añade columnas a las tablas).

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**memo** _text_  Un memo sobre el proyecto en su conjunto.

**about** _text_  Debería describir la versión de QualCoder utilizada.  Por ejemplo, QualCoder 2.5

**bookmarkfile** _integer_  El id del archivo de texto de origen. Se usa para saltar al marcador.

**bookmarkpos** _integer_  La posición del carácter en el archivo de texto. Se usa para saltar al marcador.

**codername** _text_ El nombre del codificador actual. 

**recently_used_codes** _text_ Contiene los code_ids de los códigos de texto usados recientemente, delimitados por espacios.

## Tabla: source

**id** _integer_  Autonumeración única.

**name** _text_  El nombre con la extensión del archivo.  La extensión del archivo ayuda a determinar si el archivo es de texto, imagen o A/V. Si el archivo tiene '.transcribed' como sufijo, está asociado al archivo de A/V correspondiente.

**fulltext** _text_  El texto completo de un archivo de texto, en codificación UTF-8. Null si es un archivo de imagen o de A/V.

**memo** _text_  Contiene el texto del memo.

**owner** _text_  El codificador que creó la entrada.

**date** _text_  La fecha y hora en que se creó la entrada, formato `yyyy-mm-dd hh:mm:ss`

**mediapath** _text_  

**av_text_id** _integer_ Un enlace de una fuente de audio o video a la transcripción del archivo de texto correspondiente.



Si mediapath está vacío, es un archivo de texto almacenado internamente dentro de la carpeta del proyecto.

Si mediapath comienza con 'docs:' es un enlace a un archivo de texto externo. El texto completo seguirá cargándose en 'fulltext' para su uso.

Si mediapath comienza con: '/images/' , '/audio/', '/video/' el archivo de imagen, audio o video se almacena internamente en la carpeta del proyecto.

Si mediapath comienza con: 'images:' , 'audio:', 'video:' el archivo de imagen, audio o video está vinculado externamente. Se almacena la ruta completa al archivo.

## Tabla: stored_sql

**title** _text_  El título de la sql.

**description** _text_  Una descripción detallada de la función de la sql.

**grouper** _text_  Posibilidad de organizar la sql en grupos.

**ssql** _text_  La sql generada por el usuario.

## Tabla: ris

Se usa para la bibliografía RIS

**risid** _integer_  Identificador de esta entrada bibliográfica.

**tag** _text_  Etiqueta RIS corta.

**longtag** _text_  Etiqueta RIS de texto largo.

**value** _text_  datos de texto de la etiqueta.

## Tablas de visualización del grafo

Varias tablas para almacenar los detalles de los grafos guardados y luego los elementos dentro de los grafos.

## Tabla: graph

**grid** _integer_  Identificador único.

**name** _text_  Nombre único del grafo.

**description** _text_  Descripción de texto.

**date** _text_  Fecha de creación.

**scene_width** _integer_  Se usa para establecer el tamaño de la escena al cargar.

**scene_height** _integer_  Se usa para establecer el tamaño de la escena al cargar.

## Tabla: gr_av_item

Muestra un icono de flecha para un segmento de A/V codificado reproducible.

**gr_avid** integer primary key

**grid** integer

**avid** integer

**x** integer

**y** integer

**pos0** integer

**pos1** integer

**filepath** text

**tooltip** text

**color** text

**y** integer

**font_size** integer

**bold** integer

**displaytext** text

Muestra la imagen codificada.

**y** integer
