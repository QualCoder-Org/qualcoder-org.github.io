# Referencias

Vaya a Manage > References para importar una bibliografía. Esta debe estar en texto plano con formato RIS o NBIB. El archivo puede tener las extensiones .txt, .ris o .nbib. También puede importar referencias desde Zotero 7: asegúrese primero de que Zotero esté abierto y en ejecución, y active la API local en la configuración de Zotero, para permitir que QualCoder se comunique con Zotero. También se importarán los archivos PDF o EPUB de las referencias en Zotero.

![image](/images/gh-c750c125-1214-466c-9d1f-c549c3a1ad15.png)

Presione el botón de importar y seleccione un archivo de bibliografía (.txt, .nbib., .ris). Este ejemplo procede de un archivo de texto con una referencia en formato ris; vea _bibliography.ris_ en la carpeta Examples. Las opciones son importar todas, las referencias nuevas o referencias concretas. Si hay archivos adjuntos, como en una importación desde Zotero, también pueden importarse.

![img](/images/650842457-6a209439-d45c-4e13-8138-5c4dae03e8bd.png)


Puede vincular referencias a archivos y desvincularlas. Puede editar manualmente una referencia importada. Puede eliminar una referencia.

En la pantalla Manage Files habrá cuatro nuevas columnas de atributos: Ref_Authors, Ref_Title, Ref_Type, Ref_Year

![image](/images/3d85d09f-926c-46df-87cb-867ad8dce4c1.png)

Los archivos vinculados a referencias tendrán sus datos en esas columnas.

Las referencias pueden mostrarse en el análisis, por ejemplo en Analysis - Code Retrieval

Puede exportar todas las referencias a formato ris con el botón de exportar.
