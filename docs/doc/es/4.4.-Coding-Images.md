#  Codificar imágenes

Las imágenes pueden codificarse de forma similar a la codificación de texto. Seleccione un código. Haga clic izquierdo y arrastre para resaltar el área que desea asignar al código. Con el clic derecho se abrirá un menú donde puede eliminar la codificación o añadir un memo. En la parte inferior de la pantalla hay un control deslizante para redimensionar la imagen. Los rectángulos codificados se colorean para coincidir con el color del código. Haga clic derecho en la imagen para abrir las opciones de rotación.

La parte superior derecha del diálogo muestra algunos detalles de un área codificada en la que se ha hecho clic, indicando el nombre del código, las posiciones en píxeles y el porcentaje del área respecto de la imagen completa. Al pasar el ratón sobre este espacio se mostrará cualquier memo del área codificada.

## Áreas codificadas importantes
Las áreas codificadas importantes, como los ejemplos ilustrativos para un informe, pueden marcarse como Important usando el menú contextual sobre las áreas codificadas y seleccionando Important. En la parte superior de la pantalla hay un botón con un símbolo de estrella. Este botón alterna entre mostrar todas las áreas codificadas y las áreas codificadas marcadas como Important.

## Atajos

* Atajo H. Presione h cuando esté sobre la imagen para ocultar y volver a mostrar la sección superior de controles de la pantalla.

* Atajo L. Presione L para 'Show codes like', para mostrar una lista reducida en el árbol de códigos.

* Presione los botones + o - para agrandar o reducir la imagen.

* Ctrl Z para restaurar la última área de codificación desmarcada.

## Botones prácticos debajo de la lista de archivos

* Cargar el archivo siguiente
* Cargar el archivo con la codificación más reciente
* Abrir el memo del archivo seleccionado
* Usar una función de filtro para mostrar solo aquellos archivos que cumplan ciertos criterios. Estos pueden provenir de atributos de archivo o de si los archivos están asociados a determinados casos. (Botón que muestra una etiqueta)


## Haga clic derecho en el área de la imagen para más opciones 

Las opciones incluyen la rotación y el resaltado de un código o área codificada concretos.
Estas opciones de resaltado son: en escala de grises, desenfoque, solarizar, y se abren en su programa predeterminado de visualización de imágenes para verlas y guardarlas.

## Exportar

La imagen con las áreas codificadas puede exportarse a un archivo HTML. Tras abrir el archivo en un navegador, al pasar el ratón sobre las áreas codificadas se muestran el nombre del código y los memos.

#  Categorías y códigos

Las categorías se usan para organizar los códigos. Las categorías se organizan jerárquicamente en una estructura de árbol. Puede mover códigos dentro de categorías y mover categorías dentro de categorías mayores. Puede sacar categorías y códigos de su posición actual. Los códigos y las categorías pueden fusionarse soltando un código sobre otro código o una categoría sobre otra categoría. A las categorías y códigos se les pueden asignar memos. Haga clic derecho en una categoría o código para renombrarlo. Haga clic derecho en un código para cambiar su color.

Para reducir el número de códigos mostrados en el árbol de códigos. En las ventanas de codificación (code text, code a/v o code image), haga clic derecho en el árbol de códigos y seleccione Show codes like en el menú. Luego introduzca texto en el cuadro de texto. Así solo se mostrarán los códigos que contengan ese texto. No introduzca nada en el cuadro de texto y presione OK para volver a mostrar todos los códigos.

En el árbol de códigos de la izquierda, al hacer clic derecho en un código se abre un menú contextual con diversas opciones.
Una de las opciones es Show coded files: muestra todos los lugares donde ha codificado con el código seleccionado. Al hacer clic en una sección codificada concreta se abrirá ese código en su contexto original para profundizar en su comprensión.
Con show coded files, puede hacer clic derecho en la sección coloreada del encabezado para obtener más opciones, como añadir más códigos, eliminar el código y exportar el conjunto completo de segmentos codificados a un archivo de texto.

## Accesibilidad y colores de los códigos

En el menú Coding hay una opción llamada **Colour scheme**.

Puede aplicar una gama de colores a una serie de códigos seleccionados, en lugar de depender de los colores generados aleatoriamente o de cambiar el color de cada código uno por uno. En esta área también puede ver cómo pueden percibirse los colores de los códigos por alguien con distintos tipos de daltonismo: debilidad al rojo, ceguera al rojo, debilidad al verde o ceguera al verde.
