# Atributos

Los atributos son variables asociadas a archivos, casos o diarios. Pueden ser útiles para añadir contexto al interpretar su análisis. Abra el diálogo Manage Attributes. Puede añadir, eliminar, renombrar y agregar notas de memo a los atributos.

Puede hacer clic derecho en un atributo numérico para convertirlo a Character.

Las únicas opciones para los atributos son numérico y carácter. No hay opciones para booleano, fecha u hora ni para tipos numéricos concretos como entero.  Sin embargo, si ejecuta consultas SQL, puede que necesite convertir el atributo numérico a Integer o Real: cast(my_var as integer).

Los atributos pueden añadirse en las secciones Manage Files, Manage Cases o Manage Journals haciendo clic en el botón (x). 

Los atributos pueden importarse desde una encuesta, y también desde un archivo de proyecto REFI-QDA. Tenga en cuenta que no se garantiza que la importación de un proyecto REFI-QDA sea exitosa.

No es la intención de QualCoder realizar análisis estadísticos de los atributos. Es preferible usar software estadístico como [R](https://www.r-project.org/).

Los atributos también pueden añadirse o eliminarse mediante la opción Manage > Manage Attributes:

En esta área puede eliminar atributos. Pero aunque puede eliminar atributos de referencia, recomendamos que no lo haga, a menos que tenga la certeza de que no necesita ninguna de sus referencias. Estos llevan el prefijo 'Ref_'.
