# Importar encuestas

Abra la página **Manage** > **Files** y presione el botón Import Survey.

![image](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

Una encuesta puede importarse desde un archivo CSV (valores separados por comas) o un archivo de Microsoft Excel (xlsx). **La primera fila debe contener los encabezados de los atributos y de los datos de texto libre. La primera columna debe contener los identificadores únicos de cada persona encuestada.**

Hay algunas encuestas de ejemplo en la carpeta Examples. Se usarán en un recorrido paso a paso por la importación de encuestas:

Arriba se ve la carpeta Examples, con varios archivos de encuesta.

Arriba se ven los datos de _survey456.csv_

## Importar el archivo survey456.csv {#importing-the-file-survey456csv}

Presione el botón de importar encuesta y seleccione el archivo en la carpeta Examples.

![image](/images/gh-c777dc45-5aec-4c2e-a705-8ef8abc7418a.png)

El asistente de encuestas lee el archivo CSV y muestra los nombres de las columnas a la izquierda.

![image](/images/gh-a17388a6-db2f-423b-8b6d-69f8c59d172a.png)

El identificador del participante, llamado Case en esta encuesta, puede asignarse a la sección Cases/Participants. Las columnas de datos Age, Gender e Interests pueden asignarse a los atributos. La columna freetext puede asignarse a Qualitative Texts. En este ejemplo asignaremos los atributos a los archivos y no autocodificaremos el texto cualitativo con el nombre de columna 'freetext'. QualCoder determinará si las columnas de atributos son numéricas (Numeric) o de tipo carácter (Character). Para las columnas numéricas, cada celda debe contener un número o estar vacía; de lo contrario, las entradas se tomarán como Character de forma predeterminada.

![image](/images/gh-44838a3e-5d0b-4aac-aef5-ae6b6b6c4758.png)

Presione OK para realizar la importación.

![image](/images/gh-e806f734-8b04-4487-bc0d-7a3fe3c0eca6.png)

Los atributos se asignaron a cada archivo de texto. Al abrir el archivo de texto se muestra el detalle del texto. El texto aparece subrayado en verde, lo que significa que todo el texto está asignado a un caso coincidente. En la imagen siguiente, Survey_ID4.txt se ha asignado a un caso recién creado llamado ID4.

![image](/images/gh-5cc455fe-a401-47cc-ba1f-08d0c752ba8b.png)

En la pantalla Manage > Cases se muestra así, con un archivo de texto asignado por caso:

![image](/images/gh-a35b341a-40e6-4d38-9647-179f6bc25d5e.png)

### Añadir más datos {#adding-more-data}
Con el botón de importar encuesta, seleccione e importe el archivo survey789.xlsx. Deje las casillas sin marcar.

![image](/images/gh-03a07b75-d7bf-496d-952c-cb397ebab8f7.png)

Este archivo tiene dos columnas cualitativas distintas:

![image](/images/gh-f48d1b04-26a9-45eb-a88a-f86ffb8716f4.png)

Presione OK

![image](/images/gh-79b7a8e5-0bf6-4a80-9acf-ace6965acca7.png)

Se han añadido los nuevos archivos cualitativos, y los atributos de archivo ahora se amplían con las tres nuevas respuestas de la encuesta.
La diferencia aquí es que los nuevos archivos tenían componentes cualitativos distintos. Ambas columnas de respuestas cualitativas se han reunido en un solo archivo de texto para cada caso.

![image](/images/gh-e5920d18-10e5-47d5-af59-dfd7dced11e1.png)

Desde la carpeta Examples, importe survey789_more_data.xlsx, usando los mismos parámetros de importación que antes. Este archivo contiene más atributos, State, Pet y PetAge, para ID7, ID8 e ID9.

![image](/images/gh-84d108ea-e7ea-4bd4-bb87-5ab72efd182b.png)

La información adicional se importa y se añade a los casos correctos

![image](/images/gh-7445de6b-7c72-4598-9f78-35be4f272c35.png)

Desde la carpeta Examples, importe survey789_replace_data.xlsx, usando los mismos parámetros de importación que antes. Este archivo contiene los atributos Pet y PetAge para ID7, ID8 e ID9. Cada uno de estos atributos contiene ahora datos distintos, que reemplazarán a los datos originales.

![image](/images/gh-0dd5c404-0a5c-484c-84cf-2c89d04bebc9.png)
