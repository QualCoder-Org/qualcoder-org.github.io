# Crear un proyecto nuevo

Puede **crear un proyecto nuevo desde el menú 'Project'.**

Si lo llama "Test", el proyecto se guardará como Test.qda. Test.qda es en realidad una carpeta con subcarpetas que contienen la base de datos, los documentos empíricos y otros archivos. Si quiere enviar el proyecto por correo a otra persona, comprima la carpeta completa. 

## Pantalla principal

La pestaña Action Log de la ventana principal muestra diversos cambios realizados al usar QualCoder. La ventana principal tiene en la parte superior una barra de menú llena de opciones. Hay cinco pestañas: _action log_, _manage_, _reports_, _coding_ y _AI chat_. Cambiar directamente entre pestañas suele estar bien. Pero si está añadiendo, renombrando o eliminando archivos en Manage Files, o cambiando códigos o categorías de códigos en el área de codificación, es mejor actualizar cada pestaña seleccionando la opción correspondiente en la barra de menú de la parte superior de la pantalla. Por ejemplo, si cambia archivos en Manage files y luego va a codificar o a los informes, seleccione una opción del Menú para codificación o informes, en lugar de hacer clic directamente en la pestaña de codificación o de informes. Esto se debe a que algunos cambios de gestión pueden no actualizarse.

![image](https://github.com/user-attachments/assets/847f5523-5b5c-4a89-b116-3d3e54812558)

**No ejecute su proyecto desde una ubicación en la nube** (OneDrive, Dropbox, etc.). Las razones son: a veces los archivos no pueden importarse al proyecto. Acceder a un proyecto almacenado en la nube desde distintas computadoras es especialmente peligroso, ya que puede causar problemas de sincronización e incluso corromper la base de datos. Vea [esta página con estrategias seguras para trabajar en equipo y en varias computadoras](https://qualcoder.org/doc/es/2.4.-Working-in-a-Team). De igual modo, **no ejecute su proyecto desde una memoria USB**, ya que puede producirse la corrupción de la base de datos.

!!! tip "Buenas prácticas de gestión de datos"
    Para cualquier proyecto, mantenga buenas prácticas de gestión de datos, como conservar copias de seguridad de forma regular y, en lo posible, almacenadas en distintas ubicaciones (por ejemplo, la nube, distintas carpetas de la computadora, discos duros, memorias USB).

## Escribir un memo del proyecto

Esto es **especialmente importante si desea usar las funciones basadas en IA** de QualCoder. El memo del proyecto se usa para aportar información contextual sobre el proyecto actual y el tipo de documentos empíricos con los que estamos trabajando. Esta información, que se incluye en cada consulta, ayuda a la IA a producir respuestas mucho más precisas y útiles. Puede acceder al memo del proyecto desde el menú Project > Project Memo. 

<img src="https://github.com/user-attachments/assets/c4c44cbe-9195-4cd3-a1f6-e9efccceb45d" width=500em alt="Screenshot Example Project Memo">

QualCoder ofrece una plantilla para la información más importante. No tiene que seguir esta plantilla al pie de la letra, pero procure **mantener corta la descripción del proyecto** (entre 300 y 700 caracteres). También puede añadir notas sobre su marco teórico, pero tenga cuidado de no "preformatear" demasiado la perspectiva de la IA. 

Si además desea usar el memo del proyecto para otras notas que no deberían compartirse con la IA, puede introducir la etiqueta "#####" en el texto. Todo lo que esté por debajo de esa marca no se enviará a la IA (esto funciona con cualquier memo en QualCoder). 

Si no quiere que el memo del proyecto se envíe a la IA en absoluto, desactívelo en el diálogo de Configuración.
