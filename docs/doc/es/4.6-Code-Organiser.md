# Organizador de códigos

El organizador de códigos le permite cambiar la estructura del árbol de codificación.

La primera vez que lo abra se le pedirá que haga una copia de seguridad de su proyecto antes de realizar o aplicar cualquier cambio. Los cambios hechos aquí no pueden deshacerse.

![image](https://github.com/user-attachments/assets/ae81b366-54e8-457f-9afe-abb7f76d2a41)

Con el botón situado más a la izquierda, seleccione todas las ramas de códigos de su proyecto, o solo una rama de códigos concreta.

![image](https://github.com/user-attachments/assets/57b82319-1145-4872-a6c7-63cbc807b370)

Se mostrarán todas las subcategorías y códigos de su selección.

![image](https://github.com/user-attachments/assets/303ddd26-605c-4963-9db4-ba7c50c40250)

**Códigos:**

Haga clic derecho en un código para obtener opciones de: quitar de la categoría, mover a otra categoría, fusionar con otro código, ver o editar el memo, renombrar, ver el material codificado, mostrar el memo bajo el nombre del código.

**Categorías:**

Hay un botón en la parte superior de la pantalla para añadir una categoría nueva. 

Haga clic derecho en una categoría para: fusionar una categoría con otra categoría, mover una categoría bajo otra categoría, quitar una categoría de debajo de otra categoría, renombrar una categoría, ver y editar el memo, o simplemente mostrar el memo bajo el nombre de la categoría.

Mostrar el memo bajo el nombre de la categoría

![image](https://github.com/user-attachments/assets/92fee31b-1b70-4bdf-bb15-51b0485e4739)

Hay un botón para exportar la imagen como archivo PNG.

El botón Apply aplica los cambios a la estructura del árbol de codificación. Si no se presiona, los cambios no se llevan a cabo.
