# Diarios
Puede registrar sus reflexiones mientras codifica sus datos en los diarios. Úselos para desarrollar ideas y temas. 
Los diarios pueden exportarse de forma individual, o bien todo el texto de los diarios puede reunirse y exportarse como un único archivo.
Los diarios pueden eliminarse. Los diarios pueden tener atributos.

Existe una opción de búsqueda para buscar en el texto de los diarios. La búsqueda usa símbolos de expresiones regulares (regex) para mayor flexibilidad.

* Un punto '.' se usa como comodín, por ejemplo, '.ears' coincidirá con 'bears' y 'years'
* Un '?' tras un carácter coincidirá con una o ninguna aparición de ese carácter, por ejemplo, 'bears?' coincidirá con 'bear' y 'bears'
* Un '*' tras un carácter coincidirá con cero o más apariciones. 
* '\.' coincidirá con el símbolo de punto, '\?' coincidirá con el signo de interrogación. '\n' coincidirá con el símbolo de fin de línea.

!!! tip
    [Chuleta de Regex](https://www.rexegg.com/regex-quickstart.html).

Puede ordenar los diarios por nombre o por fecha. Puede añadir atributos a los diarios. Puede mostrar las filas de diarios cuyo nombre, codificador o valor de atributo coincidan con un texto, usando la función del menú contextual.

La ventana de diarios será flotante, de modo que pueda introducir notas mientras codifica o genera informes.

## Resaltar el texto del diario con markdown

Hay algo de markdown disponible para resaltar palabras en un diario.
Use de uno a tres símbolos de almohadilla para los niveles de encabezado. Un asterisco simple rodeando las palabras para texto en cursiva. Doble asterisco rodeando el texto para texto en negrita.
