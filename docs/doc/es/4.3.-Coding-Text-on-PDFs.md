# Codificar PDF

Los PDF pueden mostrarse de forma similar al PDF original. El texto del PDF puede codificarse. Los PDF que se muestran con QualCoder no son réplicas exactas, sino que se vuelven a representar con algunas limitaciones descritas más abajo. Los documentos PDF tardan mucho en leerse, y los PDF más grandes tardarán aún más en cargarse, así que puede esperar unos segundos para PDF pequeños y muchos minutos para PDF grandes. Recomendaría codificar únicamente el texto plano de los PDF muy grandes, mediante la opción de codificar texto. En segundo lugar, recomendaría no tener PDF de más de unas 20 páginas. 

La pantalla se divide en 3 paneles ajustables. El panel del lado izquierdo contiene la lista de archivos y el árbol de códigos. El panel central muestra la representación del PDF. El panel derecho muestra el texto plano extraído del PDF.

## Tamaño de fuente y zoom

No se usan las fuentes originales del texto; es demasiado difícil extraerlas y aplicarlas desde el PDF. En su lugar, se utiliza la fuente estándar de QualCoder en los cuadros de texto del PDF mostrado. Hay un ajustador del tamaño de fuente para reducirlo y tratar de evitar el solapamiento del texto. Está establecido en -2, y -3 también puede resultar bastante bueno. Se puede acercar y alejar el PDF mediante botones o pulsaciones de teclas: Ctrl - y Shift +

## El extracto de texto plano debe coincidir

El texto plano cargado al importar un PDF mediante Manage files debe coincidir exactamente con el texto plano que se vuelve a cargar cuando el PDF se abre para mostrarse aquí. Esto significa que los PDF cargados antes de la versión 3.4 no harán coincidir el texto correctamente, y la codificación mediante la selección de cuadros de texto queda desactivada si las longitudes del texto no coinciden. De igual modo, si el texto plano se edita de cualquier manera y las longitudes del texto no coinciden, la codificación mediante la selección de cuadros de texto del PDF queda desactivada. La visualización de las franjas de codificación dentro de la página del PDF presentada también puede verse incorrecta.

## Funciones adicionales 

En la parte superior de la ventana hay varios botones. Uno exporta una imagen de la página del PDF. El botón de la lupa abre una ventana que muestra los elementos del PDF usados en la página.

También en la parte superior de la ventana hay varias casillas para mostrar u ocultar elementos del PDF de Texto e Imágenes. Una casilla mostrará todo el texto en negro, lo que puede ser útil cuando se muestra texto de color claro sobre un fondo claro.

## Panel derecho

El panel del lado derecho muestra el texto plano del mismo modo en que se mostraría en Code text. Aquí puede marcar, desmarcar, poner memos al texto codificado, marcar la codificación como importante y anotar texto.

## Panel central

Para codificar, haga clic izquierdo y arrastre el ratón para seleccionar cuadros de texto del PDF. Esto puede resultar complicado según el tamaño y la posición de los cuadros. Luego haga clic en un código para asignarle la selección. Se pueden hacer más ajustes en el panel de texto plano de la derecha usando las flechas shift izquierda o derecha para ampliar, o alt izquierda y derecha para reducir la sección de texto codificado.

Haga clic derecho para abrir el menú contextual sobre un segmento codificado. Este menú le permite añadir un memo, marcar como importante o desmarcar el segmento codificado.

### Pulsaciones de teclas

H Mostrar u ocultar las secciones superiores de la pantalla.

Ctrl F salta al cuadro de búsqueda de texto.

Ctrl Z deshace el último código desmarcado.

Ctrl 1 Ir al archivo siguiente.

Ctrl 2 Ir al último archivo codificado.

Ctrl 4 Ver y editar el memo del archivo.

Ctrl 5 Obtener la lista de archivos a partir de los atributos.

Ctrl 8 

Ctrl 9 Mostrar los segmentos codificados importantes. Se activa y desactiva.

Ctrl 0 Mostrar la página de Ayuda en el navegador.

#### En el área de visualización del PDF:

Puede acercar y alejar haciendo clic en el PDF mostrado y presionando las teclas + o -.
Presione Q para marcar rápidamente la selección con el código reciente.
Presione R para marcar rápidamente la selección eligiendo entre los códigos usados recientemente.

#### En el área de texto plano:

A anotar, para la selección actual, solo edición de texto

Q Marcar rápido con código, para la selección actual

I Etiquetar como importante

M poner memo al código, en la posición en la que se hizo clic

O Atajo para recorrer los códigos solapados, en la posición en la que se hizo clic

R abre un menú contextual con los códigos usados recientemente para marcar texto

U Desmarcar en la ubicación seleccionada

V asignar código 'in vivo' al texto seleccionado
