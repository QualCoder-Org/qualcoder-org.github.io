# References

Go to Manage > References to import a bibliography. This must be in RIS or NBIB formatted plain text. The file can have endings of .txt or .ris (forris format) or .nbib. You can also import references from Zotero - ensure that Zotero is open and running first, and enable the local API in Zotero Settings -to allow QualCoder to communicate with Zotero.

![image](/images/caff300e-f3e6-47c1-a8a1-ff4ff74281b2.png)


Press the import button, and select a bibliography file (.txt, .nbib., .ris).

This example was from a text file with a refernce in ris format. Options are to import all, new references, or specific refernces. If there are attachments, such as with a Zotero import, these can be imported also.

![img](/images/650842457-6a209439-d45c-4e13-8138-5c4dae03e8bd.png)


Now you can link (and unlink) references to files. You can manually edit an imported reference. You can delete a reference.

In the Manage Files screen there will be four new attribute columns: Ref_Authors, Ref_Title, Ref_Type, Ref_Year

![image](/images/3d85d09f-926c-46df-87cb-867ad8dce4c1.png)

Files linked to references will have details in those columns.

References can be displayed in analysis - such as the Analysis - Code Retrieval
