# References

Go to Manage > References to import a bibliography. This must be in RIS or NBIB formatted plain text. The file can have endings of .txt (for.ris) .ris or .nbib

<img width="1361" height="704" alt="image" src="https://github.com/user-attachments/assets/caff300e-f3e6-47c1-a8a1-ff4ff74281b2" />


Press the import button, and select a bibliography file (.txt, .nbib., .ris).

The Action Log will show how many references were imported.

Now you can link (and unlink) references to files. You can manually edit an imported reference. You can delete a reference.

In the Manage Files screen there will be four new attribute columns: Ref_Authors, Ref_Title, Ref_Type, Ref_Year

<img width="840" height="162" alt="image" src="https://github.com/user-attachments/assets/3d85d09f-926c-46df-87cb-867ad8dce4c1" />

Files linked to references will have details in those columns.

References can be displayed in analysis - such as the Analysis - Code Retrieval
