# Survey Imports

Open the **Manage** > **Files** page and press the Import Survey button.

![image](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

A survey can be imported from a CSV file (comma separated values) or Microsoft Excel file (xlsx). **The first row must contain the headings for attributes and for the free text data. The first column must contain the unique identifiers for each survey respondent.**

## SECTION UNDER REVIEW

QualCoder will determine if the other columns (attributes) are Numeric or Character. For Numeric columns, every cell must contain a number, as even blank entries will default to Character.

QualCoder cannot determine if an attribute is qualitative data. You must right-click and change the field type from character to qualitative for those fields that need to be qualitative.

![image](/images/ae540730-b58c-484e-9beb-8aa40093e94d.png)

The default option is that each qualitative response for each row will be stored in its own text file entry in the QualCoder database. This file will be attached to each case (each survey row entry, with the unique ID)

When you click on the OK button, the cases and their attributes will be added.

## Understanding CSV files

Survey files in a CSV format are comma delimited, another delimiter can be chosen. For tab-delimited files type ta, tb, or tab in the Delimiter box so that QualCoder knows the csv file is tab delimited.

CSV quoting format can be NONE, MINIMAL or ALL. examples of each are shown below, please open your CSV file with a text editor or similar to check how it has been prepared.

```
NONE

colin, 44, male

MINIMAL

"colin", 44, "male"

ALL

"Colin", "44", "male"
```

### Older versions of QualCoder, e.g. QualCoder 3.5.
Each qualitative question answer was appended to ONE text file. Preceding the answer was additional QualCoder-added text to show which case the answer was relevant to.

In this format: _[unique id] The qualitative text._

Open Manage Files, then View that file, and you will see the case-assignment text underlined in green.
