# Survey Imports

Open the **Manage** > **Files** page and press the Import Survey button.

![image](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

A survey can be imported from a CSV file (comma separated values) or Microsoft Excel file (xlsx). **The first row must contain the headings for attributes and for the free text data. The first column must contain the unique identifiers for each survey respondent.**

There are some example surveys in the Examples folder. These will be used in a walk-through of importing surveys:

## Importing survey456

Press the import survey button and select the file from the Examples folder.

<img width="240" height="120" alt="image" src="https://github.com/user-attachments/assets/c777dc45-5aec-4c2e-a705-8ef8abc7418a" />

The survey assistant reads the CSV file and shows the column names on the left. 

<img width="600" height="370" alt="image" src="https://github.com/user-attachments/assets/a17388a6-db2f-423b-8b6d-69f8c59d172a" />

The participant identifier, called Case in this survey, can be assigned to the Cases/Participants section. The Age, Gender and Interests data columns can be assigned to the attributes. The freetext column can be assigned to Qualitative Texts. In this example we will assign the attributes to files, and we will not autcode the qualitative text with the 'freetext' column name. QualCoder will determine if the attribute columns are Numeric or Character. For Numeric columns, every cell must contain a number, as even blank entries will default to Character.

<img width="600" height="370" alt="image" src="https://github.com/user-attachments/assets/44838a3e-5d0b-4aac-aef5-ae6b6b6c4758" />

Press OK to enact the import.

<img width="700" height="180" alt="image" src="https://github.com/user-attachments/assets/e806f734-8b04-4487-bc0d-7a3fe3c0eca6" />

The attributes were assigned to each text file. Opening the text file shows the text detail. The text is underlined in green, this means the entire text is assigned to a matching case. In the image below, Survey_ID4.txt has been assigned to a newly created case called ID4.

## SECTION BEING DEVELOPED




### Older versions of QualCoder, e.g. QualCoder 3.5.
Each qualitative question answer was appended to ONE text file. Preceding the answer was additional QualCoder-added text to show which case the answer was relevant to.

In this format: _[unique id] The qualitative text._

Open Manage Files, then View that file, and you will see the case-assignment text underlined in green.
