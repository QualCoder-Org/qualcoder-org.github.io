# Survey Imports

Open the **Manage** > **Files** page and press the Import Survey button.

![image](/images/gh-4b49aacf-fd58-4fe1-a860-a037001e3a2f.png)

A survey can be imported from a CSV file (comma separated values) or Microsoft Excel file (xlsx). **The first row must contain the headings for attributes and for the free text data. The first column must contain the unique identifiers for each survey respondent.**

There are some example surveys in the Examples folder. These will be used in a walk-through of importing surveys:

## Importing the file survey456.csv

Press the import survey button and select the file from the Examples folder.

![image](/images/gh-c777dc45-5aec-4c2e-a705-8ef8abc7418a.png)

The survey assistant reads the CSV file and shows the column names on the left.

![image](/images/gh-a17388a6-db2f-423b-8b6d-69f8c59d172a.png)

The participant identifier, called Case in this survey, can be assigned to the Cases/Participants section. The Age, Gender and Interests data columns can be assigned to the attributes. The freetext column can be assigned to Qualitative Texts. In this example we will assign the attributes to files, and we will not autcode the qualitative text with the 'freetext' column name. QualCoder will determine if the attribute columns are Numeric or Character. For Numeric columns, every cell must contain a number or be empty, otherwise entries will default to Character.

![image](/images/gh-44838a3e-5d0b-4aac-aef5-ae6b6b6c4758.png)

Press OK to enact the import.

![image](/images/gh-e806f734-8b04-4487-bc0d-7a3fe3c0eca6.png)

The attributes were assigned to each text file. Opening the text file shows the text detail. The text is underlined in green, this means the entire text is assigned to a matching case. In the image below, Survey_ID4.txt has been assigned to a newly created case called ID4.

![image](/images/gh-5cc455fe-a401-47cc-ba1f-08d0c752ba8b.png)

In the Manage > Cases screen it is shown like this, with one text file assigned per case:

![image](/images/gh-a35b341a-40e6-4d38-9647-179f6bc25d5e.png)

### Adding more data
Using the survey import button, select and import the survey789.xlsx file. Leave the checkboxes unchecked.

![image](/images/gh-03a07b75-d7bf-496d-952c-cb397ebab8f7.png)

This has two different qualitative columns:

![image](/images/gh-f48d1b04-26a9-45eb-a88a-f86ffb8716f4.png)

Press OK

![image](/images/gh-79b7a8e5-0bf6-4a80-9acf-ace6965acca7.png)

The new qualitative files have been added, and the file attributes are now extended with the three new survey responses.
The difference here is that the new files had different qualitative components. Both qualitative response columns have been collated into one text file for each case.

![image](/images/gh-e5920d18-10e5-47d5-af59-dfd7dced11e1.png)
