As we are doing a lot of updates, then next version will jump form 3.8.2 to 4.0. We have no definite date for this release yet, as there are still a few changes to work through. As a core team of 4 developers and with additional functionality requests and occasional bugs uncovered we will take some time to work through getting ready for the next version.

However, there are some very exciting changes coming changes. They are already available in the 4.0 “in development” code.

The major data structure change is to allow codes to be sub-codes of codes, as shown below. The second change, visible in the image, is the option to select between the “highlighter” coding stripes on the text, to also have more coding visibility options: vertical stripes beside the text, and also to have coloured underlining of the text.

![](https://qualcoder.org/images/img1.png)

These changes have also been tested with exports via the REFI-QDA export and subsequent import into Atlas.ti, MAXQDA, Nvivo, as shown below. It is important to state that we do not guarantee that exports and imports via REFI-QDA will work to and from QualCoder.

![](https://qualcoder.org/images/atlasti.png)

![](https://qualcoder.org/images/maxqda.png)

Muchas gracias to Lorenzo who has spent a lot of time and effort to make these changes to QualCoder.
