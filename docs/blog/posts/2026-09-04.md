We are pleased to announce the beta release of the next version of QualCoder. This version has a lot of changes and improvements throughout. These are detailed on the pre-release page.

The pre-release can be found here: <https://github.com/ccbogel/QualCoder/releases/tag/4.0-Beta>

The pre-release also contains executables for Windows, macOS and Linux.

The beta release will be available for around 6 weeks to everyone, to identify any unexpected issues, before the final 4.0 release is made available.

In summary, changes include:

-   Arificial intelligence features

-   User interface changes

-   Survey import changes

-   PDF coding changes which displays PDFs in a much improved way for both text and image area coding. (This will break compatibility with older QualCoder project versions. However we have tried to make this version import older PDF coded proejcts with minimal negative affect).

-   File imports now includes LaTeX.tex files.

-   Co-occurence report also have option to export proximity graphs.

-   The code retrieval section can produce more detailed exports of reports.

-   The Graph (mind map) is now more user-friendly with more options availble.

-   The codes tree codes can now have sub-codes.
